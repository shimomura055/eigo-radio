# コーヒー値上がり事件――値札の時計を巻き戻せ！

いつものコーヒーを買おうとして、手が止まる。「君、いつの間に高級路線へ？」。思い当たるのは関税。「犯人はお前か！」と言いたくなるが、名探偵ならここで一呼吸。事件の時計を巻き戻そう。

アメリカでは、挽いたコーヒーの平均価格が前年同月より41％上がったと、米政府の統計をもとに報じられた。カフェの一杯ではなく、粉のコーヒーの話だ。眠気覚ましを買う前に、財布が衝撃で目を覚ます。

ところが、ロイターによると、小売価格上昇の大部分は、夏の関税より前からの豆の供給不足と、原料の豆の値上がりによるものだった。おっと。事件は、目をつけた容疑者の登場前から始まっていた。

捜査の舞台はブラジルへ。そこで起きていたのは干ばつ。その後の収穫が回復するという見通しも弱まっていた。「豆、ちゃんと足りる？」。いれ方にこだわる前に、いれる豆があるのか。それが問題だった。

さらに記録をめくると、夏より前の２月、ニューヨークでアラビカ種コーヒーの先物価格が史上最高値をつけていた。これは店頭の粉の値段ではなく、豆を取引する市場の価格。市場の警報は、すでに鳴っていたのだ。

「では、関税は無罪放免？」。いや、それも早とちり。ロイターは、夏にアメリカがかけた関税が、原料の豆の価格を押し上げたとも報じている。出番はある。ただし、登場順を間違えてはいけない。

肝心なのは、その報道の時点では、関税による値上がりが、流通を経て消費者の買う価格にまだ十分には反映されていなかったこと。原料が上がった瞬間、店の値札も「了解！」と跳ね上がるわけではない。値上がりには時差がある。

つまり、値札はニュースの生中継ではない。少し遅れて届く手紙だ。今日開封しても、中身が今日の出来事とは限らない。以前の干ばつや供給不足、市場の高値が書かれていることもある。最新の見出しだけでは、差出人を読み違える。

次に売り場で値札を二度見したら、「なぜ高い？」に「いつの出来事が届いた？」を足してみよう。コーヒーは苦くても、推理はすっきりさせたい。まずは一杯――の前に、時計の針を少し戻すのだ。
