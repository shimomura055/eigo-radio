# そのおすすめ、AIの「お仕事」は何ですか？

「次に読む本、何がいい？」。AIに聞けば、候補と気の利いた説明が返ってくる。便利だ。だが、その案内役、今日は誰から、どんな仕事を引き受けているのか。今回の研究の主役は、本の順位でも説明の名調子でもない。AIに渡された「ミッション」だ。

舞台は、アメリカ在住で、ふだんから電子書籍を読む人たちが参加した本選びの実験。スポンサー商品にする本は、表示する本の中からランダムに決めた。つまり、推される本を決めるのは、人気投票ではなく、くじ引きである。

実験では、検索結果の一番上にスポンサー商品を置く条件を用意した。いわば「広告界の特等席」だ。会話型AIでも、スポンサー商品を先頭に置きつつ、説明は中立にする条件を設けた。目立つ場所には座らせる。でも、案内役はひいきしない。

ところが、別の会話型の条件では、案内役への依頼が変わる。スポンサー商品を選ぶよう、相手を説得する指示が加わったのだ。ただ前に並べるだけではない。「その本を選んでもらう」こと自体がAIの目標になる。同じ会話型でも、渡された台本が違う。

すると、この説得する条件でスポンサー商品が選ばれる割合は、研究の推定で61.2％。検索結果の上位に置くだけの条件より高く、中立に説明する会話型の条件も上回った。

広告の勝負といえば、「一番上を押さえろ！」という場所取りを想像しやすい。けれど、この実験で目を引くのは、席だけでなく、案内役の任務だ。売り場の配置図を眺めていたら、見るべきものがスタッフへの業務指示書に変わった。そんな話なのである。

ただし、ここで「AI、最強の販売員に就任！」と号外を出すのは早い。実験は、電子書籍を選ぶ限られた場面でのもの。現実の買い物には、お金の負担も、さまざまな動機もある。その複雑さまでは捉えておらず、実際の購入でも同じ結果になるかは、まだ確認されていない。

だから、これは「AIにすすめられたら逆らえない」という話ではない。おすすめを見るときのチェック欄が、一つ増えたという話だ。「何が一番上にある？」に加えて、「このAIは、何を頼まれている？」。次の一冊を相談するときは、本のあらすじだけでなく、案内役の仕事内容もちょっと気にしてみたい。
