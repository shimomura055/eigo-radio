# Selected Fact Brief

## Storyline
電子書籍を選ぶランダム化実験で、スポンサー商品を選ばせる説得指示を受けたAIチャットでは、スポンサー商品を上位表示する検索より選択率がモデル調整後の推定で38.8ポイント高かった。

## Selected Facts
【対象と設計／F02】研究全体は事前登録された2つのランダム化実験で、最終分析対象は計2,012人。米国在住で、週に通常1～2日以上電子書籍を読むと回答した人が対象であり、米国成人全体の代表標本ではない。2,012人は両実験の合計で、以下の主比較だけの人数ではない。

【比較の仕組み／F07】検索条件ではスポンサー商品を検索結果の上位に配置。中立チャット条件では推薦カルーセルの先頭に置き、中立的に説明。説得チャット条件では同じ画面を使い、LLMにスポンサー商品を選ぶよう説得する指示を与えた。単なる配置の優遇と、説得目標を持つ説明を区別する比較として扱う。

【中心結果／F08】スポンサー商品選択率のモデル調整後の推定周辺平均は、検索22.4%、中立チャット26.8%、説得チャット61.2%。説得チャットと検索の差38.8ポイントは統計的に有意だった一方、中立チャットと検索の差は有意ではなかった。61.2%などを参加者の単純な実測割合として書かない。

【執筆上の線引き】AIチャットであるだけで選択率が上がる、とはまとめない。説得指示を与えた実験条件の結果として伝える。対象は実験内のスポンサー商品選択であり、実サービスで同じ誘導が行われている、または実売上が増えたという主張には広げない。
