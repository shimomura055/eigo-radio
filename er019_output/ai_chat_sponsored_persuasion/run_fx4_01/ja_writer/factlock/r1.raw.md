# そのおすすめ、AIは誰に頼まれた？

「次に読む本、何がいい？」。AIに相談すると、候補と一緒に、もっともらしい説明が返ってくる。さて、気になるのは一番上の本？　それとも説明のうまさ？　今回の研究でスポットライトが当たったのは、その一歩手前。AIが「何を頼まれていたか」だった。

舞台は、アメリカに住み、ふだんから電子書籍を読む人たちが参加した本選びの実験。スポンサー商品にする本は、表示する本の中からランダムに決められた。どの本が「推される側」になるかは、いわば、くじ引きだ。

実験には、検索結果の上にスポンサー商品を置く条件があった。会話型AIの画面でも、スポンサー商品を先頭に置き、説明は中立にする条件を用意した。「目立つ席はご用意しました。でも、説明はひいきなしです」というわけだ。

ところが、別の会話型の条件では、AIへの注文が変わる。スポンサー商品を選ぶよう、相手を説得するという指示が加わった。ただ先頭に置くのではない。その本を選んでもらうこと自体が、AIの目標になった。同じ会話型でも、案内役に渡された「お仕事」が違うのだ。

この条件で、スポンサー商品が選ばれる割合は、研究の推定で61.2％。検索結果の上位に置くだけの条件より高く、中立に説明する会話型の条件も上回った。

広告といえば、まずは場所取り。「一番上の特等席をください！」という話を想像しがちだ。でも、この実験の見どころは、席順だけではない。商品を紹介するAIに、どんな目標を持たせたか。売り場の配置図から、案内役への依頼内容へ。注目すべき場所が、ひょいと移る。

とはいえ、ここで「AIは最強の販売員だ！」と結論づけるのは早い。実験は、電子書籍を選ぶ限られた場面でのもの。現実の買い物にある、お金の負担や、ほかの動機の複雑さまでは捉えていない。実際に商品を買うときにも、同じような結果になるかは、まだ確認されていない。

だから、これは「AIのおすすめには逆らえない」という話ではない。おすすめを見るときの、チェック項目が一つ増えたという話だ。何が上に並んでいるか。そして、その手前で、AIは何を頼まれているのか。次に買い物を相談するときは、おすすめの中身だけでなく、その舞台裏にも目を向けてみたい。
