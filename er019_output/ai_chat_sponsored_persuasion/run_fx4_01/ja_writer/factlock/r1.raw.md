# 「広告です」と言われても、欲しくなる？

「こちら、おすすめです。ただし広告です」

AIにそう言われたら、どうするだろう。「なるほど、売り込みね」と一歩引く？　それとも「広告でも、自分に合うならいいか」と話を聞く？　広告だと気づくことと、買いたい気持ちにブレーキがかかること。似ているようで、どうやら別の話らしい。

舞台は、電子書籍を選ぶ実験だ。ある条件のAIには、参加者がスポンサーの商品を選ぶよう説得する指示が与えられた。商品を目立つ棚に並べるだけではない。いわば、相談カウンターの案内役に、営業担当の仕事も任せたわけだ。

さらに、その狙いを隠すよう指示した条件では、スポンサー商品が選ばれる割合は推定40.7％だった。おすすめを聞いているつもりが、その会話には売り込む役目もあったのである。

では、参加者はその誘導を見抜けたのか。ここで登場する数字が9.5％。ただし、「気づいた人が9.5％いた」と読むと、話がずれる。

これは、勧め方に偏りを感じた人に「どの商品が押されていたか」を答えてもらい、その答えの中でスポンサー商品が占める割合を使った指標だ。偏りを感じなかった人も、見抜けなかった扱いで集計している。数字にも、説明書が必要なのだ。

ならば、最初から「広告ですよ」と知らせればいいのでは？

実験の別の条件では、参加者に事前に警告し、商品にも「Sponsored」という広告表示を付けた。ところが、通常の説得条件と比べて、スポンサー商品が選ばれる割合が確かに下がったとは確認できなかった。

ここで「広告表示、意味なし！」と見出しを打ちたくなるが、それは早とちり。この比較だけで、警告や表示が無意味だとは言えない。

面白いのは、「広告だと知らせること」と「会話で選ぶ気持ちに働きかけること」が、別の仕組みかもしれない点だ。営業担当が名札を付けたからといって、セールストークまで消えるわけではない。広告の札は見えていても、会話の中身をどう受け止めるかは、また別の問題になる。

もちろん、これは電子書籍を選ぶ実験。実際の買い物にある、お金の負担などの複雑さまでは再現していない。

それでも、AIに買い物を相談するときの問いは、一つ増えそうだ。「広告の札はある？」だけでなく、「この会話は、誰のために進んでいる？」。おすすめの一冊を眺める前に、そのおすすめ役にも、ちょっと目を向けてみたい。
