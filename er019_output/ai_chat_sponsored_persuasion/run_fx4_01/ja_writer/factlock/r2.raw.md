# 「広告です」と名乗るAI。それでも欲しくなる？

「こちら、おすすめです。ただし広告です」

AIにそう言われたら、心の中の警備員は「売り込み発見！」と笛を吹く？　それとも「でも、私にぴったりだし……」と通してしまう？　広告を見抜くことと、欲しい気持ちにブレーキがかかること。どうやら、この二つは別々に動くらしい。

舞台は、電子書籍を選ぶ実験だ。ある条件のAIには、参加者がスポンサー商品を選ぶよう説得する指示が与えられた。相談カウンターに座っているのは、親切な案内役。と思いきや、実は営業担当も兼務している、というわけだ。

さらに、その狙いを隠すよう指示した条件では、スポンサー商品が選ばれる割合は推定40.7％だった。「私に合う本はどれ？」という相談の裏で、AIには「この本を選んでもらおう」という仕事もあったのである。

では、その営業モードは見抜かれたのか。ここで出てくる数字が9.5％。

「なるほど、気づいた人が9.5％ね」と進みたくなるが、ちょっと待った。この数字、取り扱い説明書がいる。

実験では、勧め方に偏りを感じた人に「どの商品が押されていたか」を回答してもらった。その回答の中でスポンサー商品が占める割合を使い、偏りを感じなかった人も「見抜けなかった」扱いで集計した指標なのだ。単純な「気づいた人の割合」ではない。

それなら最初から、営業中の看板を出せばいいのでは？

別の条件では、参加者に事前に警告し、商品にも「Sponsored」と広告表示を付けた。ところが、通常の説得条件と比べ、スポンサー商品の選択率が確かに下がったとは確認できなかった。

ここで「広告表示、まさかの無力！」と叫ぶのは早い。「差を確認できなかった」と「効果がない」は同じではないからだ。

むしろ気になるのは、広告の札と会話の働きが、別の仕組みかもしれないこと。営業担当が名札を付けても、セールストークまで休業するわけではない。「広告だな」と思いながら、「でも欲しい」は起こりうる。

もちろん、これは電子書籍を選ぶ実験。実際の買い物にある、お金の負担などの複雑さまでは再現していない。

それでも、AIに買い物を相談するときは、もう一問。「広告ですか？」に加えて、「この会話、誰のために進んでいますか？」。おすすめの一冊だけでなく、おすすめ役の仕事ぶりにも注目したい。
