# Selected Fact Brief

## Storyline
対象を事前選別しないJWST/NIRSpecのHUDF観測で、深い画像に対応天体が見えない輝線が繰り返し検出されたが、一般的な輝線の候補では十分に説明できず、正体の確定には追観測が必要となった。

## Selected Facts
・【F02／発見を可能にした方法】MOCSSは、NIRSpecのマイクロシャッターで既知の低赤方偏移天体に重なる部分を閉じ、それ以外をほぼすべて開けて輝線を探す方法。事前に対象を選ばない探索だが、対象範囲はHUDF内の調査視野であり、全天ではない。
・【F06／検出の根拠】未同定の輝線の観測波長は約1.6004 μm。4スタックと2観測方向で検出され、著者らはこの再検出を人工的な検出ではない根拠としている。線の検出は、天体の正体や赤方偏移の確定を意味しない。
・【F08／何が説明を難しくするか】輝線位置にはJADESの深いNIRCam画像でも対応する点状天体が検出されない。この連続光の非検出から、連続光に対する輝線の強さを表す観測系等価幅は≥7620 Åと見積もられた。これは下限であり、対応天体が存在しない証明ではない。
・【F09／通常の同定が決まらない理由】観測波長と等価幅の制約、さらに観測したスペクトル範囲で他の輝線が検出されないことから、著者らは[O II]、[O III]、Hα、Lyαのいずれも完全には満足な説明にならないと評価した。これらの候補を全面的に否定したという意味ではない。
・【F10／結論と次の確認】物理的起源と赤方偏移は未確定。より深い分光観測やJWST/NIRSpec IFU観測によって追加の輝線を探し、正体を判定する必要がある。候補仮説を確定した発見として扱わない。
