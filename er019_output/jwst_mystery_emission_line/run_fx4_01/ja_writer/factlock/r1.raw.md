# 光は届くのに、写真にはいない。宇宙の「名簿外」を追え！

宇宙の観測は、まず写真から調べたい相手を選び、その光を詳しく調べる——。では、その順番をひっくり返したら？　今回の研究は、いわば「招待客リストを作らず、届いた声から相手を探す」試みです。すると、ちょっと奇妙な手がかりが現れました。

使ったのは、JWSTの観測装置「ニアスペック」。調査する空の領域で、対象を先に選ぶのではなく、特定の波長に現れる「光の線」を探しました。すでに知られた一部の天体に重なる小さな窓は閉じ、それ以外はほぼ全部開放。空全体の捜索ではありませんが、その範囲では「写真に載っている相手だけ」という条件を外したのです。

そして、光の線を発見。さっそく、その場所を深い画像で確認すると……対応する点状の天体が見つかりません。声は聞こえた。けれど、顔写真がない。宇宙の名簿をめくっても、相手の姿を確認できないわけです。

しかも、この線は観測の向きが違うデータでも繰り返し検出されました。ただし、ここで「姿なき天体だ！」と飛びつくのは早計。画像に写らないことと、天体が存在しないことは別です。確認できていないのは、あくまで線の位置に対応する画像上の姿です。

面白いのは、この「写っていない」も捜査資料になること。著者たちは画像での非検出を使い、光の線の特徴を示す「等価幅」の下限を7620 Åと見積もりました。これは「値は7620 Åです」という確定測定ではなく、「少なくとも、ここまではある」という境界線。写真にいないからお手上げ、ではないのです。空欄にも、情報がありました。

では、正体は？　ここで謎解き完了、といきたいところですが、まだ幕は下りません。よく知られた種類の光の線を候補にしても、波長や等価幅、ほかの線が見つからないことを十分には説明できませんでした。著者たちの結論は、さらに詳しく光を調べる追観測が必要、というものです。

今回の収穫は、正体の判明だけをゴールにすると見落としそうです。「誰を調べるか」を先に決めすぎなければ、名簿の外から手がかりが届く。私たちの情報探しでも、いつもの候補だけを見ていないか、少し気になります。宇宙の謎は持ち越し。でも、その探し方には、もう次の扉を開ける面白さがあります。
