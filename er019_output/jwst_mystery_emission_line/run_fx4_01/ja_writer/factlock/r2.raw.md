# 写真にはいない。でも光は届く！ JWSTの「宇宙捜査ファイル」

「声はする。なのに、顔が見えない」。宇宙でそんな探偵泣かせの謎が浮かびました。手がかりは、JWSTの観測装置「ニアスペック」が拾った「光の線」。ただし今回、研究者たちは、いつもの捜査手順をひっくり返しています。

通常は、まず写真から調べたい天体を選び、その光を詳しく分析します。いわば「招待客名簿を作ってから、一人ずつ話を聞く」方式。今回は逆です。名簿に頼らず、届いた声から相手を探そうというのです。

観測する領域では、すでに知られた一部の天体に重なる小さな窓を閉じ、それ以外はほぼ全開。特定の波長に現れる光の線を探しました。宇宙全体の一斉捜索ではありませんが、その範囲では「写真に載った相手限定」の条件を外したわけです。

すると、線を発見。ところが、その位置を深い画像で確認しても、対応する点状の天体が見当たりません。声は届いた。顔写真はない。これは、いったい誰の声？

しかも、この線は観測の向きが異なるデータでも繰り返し検出されました。とはいえ、「姿なき天体、発見！」と号外を出すのは待った。画像に写らないことと、天体が存在しないことは別です。確認できていないのは、線の位置に対応する画像上の姿なのです。

ここで捜査は意外な展開へ。「写っていない」こと自体が、捜査資料になるのです。著者たちは画像での非検出を使い、線の特徴を示す「等価幅」の下限を7620 Åと見積もりました。「7620 Åと確定」ではなく、「少なくとも7620 Å」。空欄が、相手を絞り込む手がかりに変わりました。

では、正体は？　よく知られた種類の光の線を候補にしても、波長や等価幅、ほかの線が見つからないことを十分には説明できませんでした。謎解きの決めぜりふは、まだお預け。著者たちの結論は、さらに詳しく光を調べる追観測が必要、というものです。

事件は未解決。でも、収穫はあります。最初から「調べる相手」を決めすぎなければ、名簿の外から届く手がかりも拾える。名簿は便利。でも、名簿が宇宙のすべてとは限らない。次の観測は、この声の主にどこまで迫れるでしょうか。
