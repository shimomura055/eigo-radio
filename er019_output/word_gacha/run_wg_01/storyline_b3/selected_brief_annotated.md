# Selected Fact Brief

## Storyline
使用頻度の低い英単語ほど高レアになり、UR以上で連続開封が始まる「ドパ英単語ガチャ」を、「覚えるより珍しい単語を引きたくなりそう」という報酬設計の逆転から紹介する。

## Selected Facts
- 【事実1】カードのレア度は低い順にC、UC、R、SR、SSR、UR、LRの7【中核数値】段階。GIGAZINEは、使用頻度が高い単語ほどレア度が低く、頻度が低い単語ほどレア度が高い仕組みと説明している。（範囲：ゲーム内の英単語カード。条件：GIGAZINEの説明するゲーム内ルール）
- 【事実2】GIGAZINEは、レア度UR以上のカードを引くとジャックポットが始まり、ジャックポット中は10【周辺数値】連パックを続けて開封できると報告している。（範囲：ゲーム内の抽選・ボーナス機能）
