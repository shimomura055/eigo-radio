# Selected Fact Brief

## Storyline
使用頻度の低い英単語ほど高レアになり、UR以上で連続開封が始まる「ドパ英単語ガチャ」を、「覚えるより珍しい単語を引きたくなりそう」という報酬設計の逆転から紹介する。

## Selected Facts
【採用素材】
・F03：GIGAZINEの2026年10月23日付プレイレビューによると、カードのレア度はC・UC・R・SR・SSR・UR・LRの7段階。使用頻度が高い単語ほど低レア、低い単語ほど高レアになる。
・F06：同レビューによると、UR以上のカードを引くとジャックポットが始まり、その間は10連パックを続けて開封できる。継続可能回数や遭遇確率は、このFactからは特定しない。

【つなぎ方と表現の範囲】
『低頻度の単語ほど高レア』と『UR以上で連続開封』をつなぎ、珍しい単語を当てること自体が報酬につながる設計を説明する。『覚えるよりレアを引きたくなりそう』はこの設計への見立てにとどめ、利用者一般の行動として断定しない。レア度を学習上の重要度・難易度と同一視せず、学習効果やドーパミン増加の主張へ広げない。
