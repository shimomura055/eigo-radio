# 決算なのに「次回予告」が気になる。Broadcomの数字を読む

決算発表は、企業の「成績表」。そう聞くと、数字を確認して「よくできました」で終わりそうだ。でも、今回のBroadcomの発表は、それだけではもったいない。成績表をめくったら、次回予告までついてきた。しかも、その予告にも数字がある。

まずは実績から。連結売上高は295億9,100万ドル、AI半導体の売上高は167億ドルだった。大きな数字が並ぶと、つい「AIがすごい話ね」とまとめたくなる。けれど、ここで一度、数字の名札を確かめておきたい。

167億ドルは、あくまで「AI半導体」の売上高。「半導体部門全体」の売上高ではない。会社全体、半導体部門、AI半導体。この三つをひとまとめにすると、話の輪郭がぼやけてしまう。派手な数字ほど、何の数字なのかが大事だ。

では、会社はその先をどう見ているのか。CEOは、カスタムAIアクセラレーターとネットワーキングへの需要が、引き続き非常に強いと述べた。数字だけの成績表に、経営トップの需要への見立てが加わる。ここから決算は、少し先の話になる。

そして登場するのが、次の四半期の連結売上高「約348億ドル」という見通しだ。295億9,100万ドルが今回の実績なら、約348億ドルは会社が次に見込む数字。同じ売上高でも、片方は結果、もう片方は予想。並べて読むと面白いが、同じ扱いにはできない。

ここは、映画の予告編と本編の違いに近い。予告を見て期待はできても、そのとおりの展開が約束されたわけではない。会社も、実際の結果は見通しと異なる可能性があり、その差が重要になることもあると説明している。「約348億ドル達成」と、先回りして拍手するのはまだ早い。

今回の読みどころは、現在のAI半導体の売上、CEOの需要評価、次の四半期の売上見通しが、ひと続きになっていることだ。ただし、次の見通しも会社全体の数字であって、AI半導体だけの予想ではない。この線引きを忘れなければ、会社が見ている「次」がぐっと読みやすくなる。

決算は、終わった四半期を振り返るだけのものではない。会社が次をどう予想しているかを読む楽しみもある。あなたが気になるのは、AIへの需要は非常に強いというCEOの言葉か。それとも、約348億ドルという次回予告の数字だろうか。
