# 決算書を開いたら、予告編が始まった。Broadcomの「次」が気になる

決算発表と聞いて、まぶたが重くなった人。まだ寝ないでほしい。今回のBroadcomは、成績表を渡して「はい、解散」ではなかった。ページをめくると、次の四半期の予告編が始まる。しかも、主役級の数字を連れて。

まずは本編、つまり今回の実績だ。連結売上高は295億9,100万ドル。AI半導体の売上高は167億ドル。桁が大きすぎて、脳内の電卓がそっと閉店しそうになる。「要するに、AIがすごいんでしょ？」と言いたくなるが、ここで早送りは禁物だ。

167億ドルは「AI半導体」の売上高であり、「半導体部門全体」の売上高ではない。会社全体、半導体部門、AI半導体。似た名前が並ぶが、数字の範囲はそれぞれ違う。名札を外すと、たちまち話が迷子になる。

そこへ登場するCEO。カスタムAIアクセラレーターとネットワーキングへの需要は、引き続き非常に強いという。実績の数字に、経営トップの需要評価が重なる。ここで物語は「今」から「次」へ動き出す。

予告編の目玉は、次の四半期の連結売上高「約348億ドル」という見通しだ。今回の295億9,100万ドルと並べると、確かに目を引く。ただし、二つの数字は立場が違う。前者はこれからの予想、後者はすでに出た結果。同じ売上高でも、出演している時間軸が違うのだ。

だから、「約348億ドル達成！」と脳内でくす玉を割るのは、まだ早い。映画の予告編で名場面を見ても、本編の展開まで保証されたわけではない。期待するのは自由。でも、予想を実績の席に座らせてはいけない。

会社も、実際の結果は見通しと異なる可能性があり、その差が重要になることもあると説明している。ここは小さな注意書きとして読み飛ばさず、予告編とセットで押さえておきたい。

もう一つ、退場前に確認を。約348億ドルも「会社全体」の売上見通しであって、AI半導体だけの予想ではない。AIへの強い需要という話から、そのまま「全部AIの数字」に変換すると、別の映画が始まってしまう。

今回の見どころは、AI半導体の実績、CEOの需要評価、次の四半期の全社売上見通しという三つのつながりだ。決算は、過去を採点して終わりではない。「次はどうなる？」まで楽しめる。ただし、拍手の前に名札を確認。本編と予告編を見分ければ、数字はもっと面白くなる。
