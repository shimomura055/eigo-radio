# Selected Fact Brief

## Storyline
ニュージーランドの家庭への質的調査は、服用を忘れないよう物を出しておくといった生活上の理由から、散らかりが単なる片づけの失敗ではなく、暮らしを支える資源にもなり得ると報告した。

## Selected Facts
- 【事実1】研究は、ニュージーランドの複数人世帯を対象にした質的研究で、写真を使った聞き取り（photo-elicitation interviews）を用いた。（範囲：ニュージーランドの家庭内の物質的な秩序・散らかり。条件：対象は複数人世帯。世帯の散らかりを実践している人が選定対象とされ、家庭の片づけに積極的に関わっていない人は除外された）
- 【事実2】論文は、家庭の秩序・散らかりが家族、物、空間、日々の時間的リズムの相互関係を通して変化すると捉え、散らかりが個人の失敗とは限らず、家庭内で役立つ資源として機能する場合を報告している。（範囲：調査対象となった22【周辺数値】のニュージーランド世帯の語りと写真。条件：著者らの質的分析・理論的枠組みに基づく解釈）
- 【事実3】論文中の参加者の例では、ある人がサプリメントを見える場所に置いたのは、収納すると服用を忘れる可能性があるためだった。（範囲：論文中の個別参加者の台所の例。条件：一人の参加者の説明であり、物を見える場所に置けば一般に忘れ物が減るという効果の測定ではない）
- 【事実4】参加者は主に筆頭著者のLinkedInページ経由で募集され、参加者は高学歴者が多かった。著者らは、標本が主として中流から上位中流の世帯を反映していると記し、社会経済的により多様な集団での追加研究が必要としている。（範囲：ニュージーランドの22世帯【中核数値】からなる質的標本。条件：著者らによる標本特性と研究上の限界の記述）
