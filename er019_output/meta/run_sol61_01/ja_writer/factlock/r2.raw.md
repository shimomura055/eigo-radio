# AIに電話を頼んだら、舞台裏で人間が「もしもし」

「電話、お願い」。AIに用事を託して、こちらはひと息。ところが舞台裏では、人間が受話器を取っていた――。そんな仕組みを、Metaが社内で試していた。「AIじゃなかったの？」と驚く話だが、本当に気になるのは、その人に何が渡るのかだ。

Metaが行ったのは、Museを通じてかける電話の一部を、人間の契約スタッフに任せるテスト。訓練を受けたスタッフが依頼を引き継ぎ、AIの代わりに電話をかけ、相手とのやり取りを終える仕組みだった。

つまり、AIの看板の裏に人間の助っ人がいたわけだ。助っ人そのものが悪いとは限らない。込み入った用件なら、人間のほうがうまく対応できるかもしれない。ただし、頼もしさと説明不要は別の話である。

電話の用件によっては、ユーザーの情報が必要になる。そこで渡されるのは、「これをお願いします」という依頼だけなのか。それとも個人情報まで付いてくるのか。「用事のお任せセット」に、情報の受け渡しまで勝手に盛り込まれては困る。

実際、Metaの従業員からも社内で懸念が出た。電話にユーザー情報が必要な場合、大事な個人情報がコールセンターの契約スタッフに、意図せず伝わる可能性があるという。情報が漏れたと断定する話ではない。問われているのは、誰に情報が渡る仕組みなのか、という点だ。

たとえば、「私が電話しておくよ」と言われた場合と、「別の人に頼んでおくね」と言われた場合。同じ用事でも、こちらの返事は変わりうる。「それなら、この情報は伝えないで」「今回は自分でかける」。その選択肢は、相手を知って初めて使える。

Metaの担当部門の副社長は、契約スタッフが電話をかけるテストを、きちんと知らせずに始めたことを「ミス」だったと認めた。社内への投稿では、人間に電話を任せる機能を、いったん引っ込めたと説明している。

だから、この話のオチは「AIの正体、人間でした！」ではない。黒子がいるなら、いると知らせてほしい。どこまで情報を渡すのかも知りたい。そのうえで頼むか、頼まないかを選べることが大切だ。便利さへの拍手と、情報の扱いへの確認は、両立する。

電話が無事に済めば、一件落着――と言いたい。けれど、自分の情報まで知らない舞台裏へ運ばれる可能性があるなら、幕が下りる前にひと言。「その用件、誰が担当するんですか？」。AIに任せたいのは用事であって、お願いの範囲を決める権利までではない。
