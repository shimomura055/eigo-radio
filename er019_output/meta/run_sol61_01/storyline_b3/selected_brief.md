# Selected Fact Brief

## Storyline
MetaはMuseの一部の電話を人間の契約スタッフが担う社内実験で、機微情報の共有に懸念が出る中、適切な開示なしの開始を「ミス」と認め、人間コンシェルジュ機能を当面ロールバックした。

## Selected Facts
採用素材（Reuters報道に基づく）：
・MUSE-HC-006：Metaは、Muse経由の電話の一部をAIではなく訓練済みの人間の契約スタッフがかけ、相手とのやり取りを完了させる「人間コンシェルジュ」のテストを実施した。全ての電話を人間が担当したわけではない。
・MUSE-HC-010：Meta従業員は、この運用では電話の遂行に必要なユーザーの機微情報が契約スタッフへ意図せず共有される可能性があるとして、社内でプライバシー上の懸念を示した。確認されたのは懸念の存在であり、実際の情報漏えいを示す事実ではない。
・MUSE-HC-012：2026年9月22日までに、MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに契約スタッフによる電話のテストを開始したことを「ミス」と認め、人間コンシェルジュ機能を当面ロールバックしたと社内投稿で説明した。Muse全体や電話機能全体の停止ではない。

因果関係の留意点：人間が電話を担当する仕組みと情報共有への懸念を結び付け、ロールバックは開示不足を認めた幹部の説明とともに示す。従業員のプライバシー懸念がロールバックの直接原因だったとまでは断定しない。
