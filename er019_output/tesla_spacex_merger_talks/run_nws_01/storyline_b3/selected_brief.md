# Selected Fact Brief

## Storyline
マスク氏がTeslaとSpaceXの統合を支持しても合併は未決定で、両社の特別委員会による検討と株主承認要件への対応が残り、公的支持が交渉を遅らせる可能性も懸念されている。

## Selected Facts
【発言と検討手続き：F01・F02】Reutersの2026年10月21日報道によると、マスク氏は20日のSpaceX決算説明会で統合を「良い考え」と支持した一方、判断は両社の特別委員会に委ねると述べた。両社はそれぞれ、独立取締役で構成されると説明された特別委員会を設置した。支持表明も委員会設置も合併の決定・承認を意味しない。委員会の法的独立性や交渉権限が十分だとまでは断定しない。

【承認上のハードル：F05・F07】Teslaの定款は、Texas法上許される範囲と優先株の権利等を条件に、基本的事業取引を含む事項について、その事項に議決権を持つ発行済み株式の過半数の賛成で足りると定める。分母は投票参加株式ではない。個別の取引構造に適用される法令・取引所規則上の追加要件は別途確認が必要。SpaceXでは、定款で定義された、合併・統合を含む「Combination Transaction」に、他の必要承認に加えてClass B普通株保有者によるクラス単独の承認が必要。両社の承認要件を同一視せず、承認結果も推定しない。

【公的支持が交渉を妨げる可能性：F04】Reutersの10月22日報道では、協議に直接詳しい人物1人が、マスク氏の公的支持と協議の公表によって株主の監視が強まり、交渉過程が数週間遅れる可能性への懸念を示した。これは関係者の予測であり、実際の遅延や、その因果関係が確認されたという意味ではない。
