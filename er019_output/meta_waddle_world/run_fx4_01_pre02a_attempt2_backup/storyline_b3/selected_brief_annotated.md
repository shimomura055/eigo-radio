# Selected Fact Brief

## Storyline
Metaが日記生成機能を掲げるAIペットをフィリピン向けに公開し、TechCrunchは将来のペット型端末の先駆けとなる可能性を挙げたが、他地域展開や端末との具体的関連は未確認で、たまごっちに続くブームになるかはまだ判断できない。

## Selected Facts
- 【事実1】Meta Platforms, Inc.名義のアプリ「Waddle World: AI Pet Journal」が、フィリピン向けのApp StoreおよびGoogle Play掲載ページで確認できる。TechCrunchは、iOS・Androidでフィリピン向けに提供されたと報じた。（範囲：フィリピン向けのストア掲載。Appleの掲載情報はiPhone専用と表示。日本・米国を含む他地域での提供はこの事実の範囲に含めない。条件：ストア掲載およびTechCrunchの報道に基づく。掲載・提供状況は確認時点のもの）
- 【事実2】App StoreとGoogle Playの説明は、利用者が音声またはテキストで一日の出来事を伝え、ペットが自身の声による日記エントリーと手描き風の落書きを作る機能を説明している。（範囲：公式ストア説明に記載された機能。条件：音声入力またはテキスト入力が可能と記載）
- 【事実3】TechCrunchは、Waddle Worldのより広い地域での提供についてMetaに問い合わせたと報じたが、記事掲載時点で他地域への提供時期は示していない。（範囲：TechCrunch記事で報じられたMetaへの問い合わせと掲載内容。条件：記事掲載時点での情報。後日の発表の有無は含まない）
- 【事実4】TechCrunchはWaddle Worldについて、MetaのMuse搭載ペット型端末の先駆けとなる可能性を示した。一方、記事は可能性として記述しており、Waddle WorldとMuse Charmの具体的な技術・製品上の関連を確認したとは述べていない。（範囲：TechCrunchによるWaddle Worldの報道・見立て。条件：記者による可能性の提示であり、Metaによる公式発表ではない）
