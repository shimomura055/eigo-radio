日記の語り手が、ペットだったら

日記って、自分の言葉で自分の一日を残すものだと思っていない？　そこにペットの声が入ったら、どうだろう。今回、面白いと思ったのは、ペットの新しさよりも、日記の「語り手」を変えるという見方だ。

メタのアプリ「ワドル・ワールド」が、フィリピン向けに公開されたと、テッククランチが報じた。【事実1】ストアの説明によると、音声か文字でその日の出来事を伝えると、ペットが自分自身の声による日記と、手描き風の落書きを作るという。【事実2】

つまり、日記の材料を渡すのは利用者で、それをペットの声にする、という説明だ。【事実2】ここを「文章を作ってくれる機能」と見るか、「自分の一日を、別の声で返してくれる仕組み」と見るか。私は後の見方が気になる。同じ出来事でも、語る声が自分ではないなら、日記との距離が少し変わりそうじゃない？

自分の記録なのに、自分だけで完成させるわけではない。そんな日記を想像すると、きれいな文章になるかどうかより、どんな声で返ってくるのかを聞いてみたくなる。

うまい文章を書きたいのか。それとも、今日のことを誰かに話したいのか。似ているようで、欲しいものは違う気がする。私たちの暮らしに引き寄せるなら、日記を「ちゃんと書く時間」から「今日のことを話す時間」へ、少し近づける道具になるのかもしれない。

もちろん、ここで紹介されているのは、ストアに書かれた機能だ。【事実2】実際に聞いたらどう感じるのか。その声をまた聞きたいと思うのか。そこは、説明を読むだけで決めずにおきたい。

テッククランチは、将来のメタのペット型端末の先駆けになる可能性も挙げているが、アプリと端末の具体的なつながりを確認したとは述べていない。【事実4】だから、手に持てるペットが登場する話として先走るより、まずは、この日記の仕組みを面白がりたい。

たまごっちに続くブームになるのか。今は答えを急ぐより、「ペットに何をさせるか」ではなく、「ペットの声で自分の一日をどう聞くか」を考えるほうが、面白くない？
