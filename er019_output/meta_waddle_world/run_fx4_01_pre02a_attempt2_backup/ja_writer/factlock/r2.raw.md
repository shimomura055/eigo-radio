# 今日の日記、語り手をペットに交代します。

日記を書こうとすると、なぜか脳内に国語の先生が現れる。「今日は何を学びましたか」。いや、今日はただ疲れたんです。そんな夜、白紙の前で固まる自分に代わって、ペットが語り始めたらどうだろう。

メタのアプリ「ワドル・ワールド」がフィリピン向けに公開されたと、テッククランチが報じた。ストアの説明では、音声か文字でその日の出来事を伝えると、ペットが自身の声による日記と、手描き風の落書きを作るという。

つまり、こちらは一日の材料係。ペットはナレーター担当だ。主演は相変わらず自分なのに、語り手だけが交代する。人生の大改造ではない。日常の音声トラックを、ちょっと差し替えるようなものだ。

これが、案外そそる。「起きた。働いた。疲れた。以上」で閉店しそうな日にも、別の声がつけば違って聞こえるかもしれない。立派な一日でなくてもいい。こちらが気になるのは、「で、その地味な出来事をどう語るの？」なのだ。

日記帳を開くと「ちゃんと書かねば」がやってくる。でも、ペットへの報告なら「今日さあ」で始められそうだ。作文の試験会場から、帰宅後のおしゃべりへ。少なくとも、白紙と根比べするよりは気楽そうではある。

欲しいのは、うまい文章なのか。それとも、一日の話を聞いてもらう時間なのか。似ているようで、この二つは別腹だ。私が気になるのは作文の成績より、話し終えたあとに返ってくる声。その声で、今日がどう聞こえるかである。

もちろん、ここまではストアの説明を読んでの想像だ。実際に聞けば楽しいのか、むずがゆいのか。「明日も頼む」となるのか、「今日は自分で書きます」となるのか。説明文だけで星をつけず、そこは保留にしておきたい。

テッククランチは、将来のメタのペット型端末の先駆けになる可能性にも触れている。ただし、アプリと端末の具体的なつながりを確認したとは述べていない。「次は手のひらに相棒が！」と盛り上がるのは、まだ早い。

たまごっちに続くブームかどうかは、いったん置いておこう。まず面白がりたいのは、日記のナレーター交代だ。今日も一日お疲れさま。その一言がペットの声で返ってくるなら、明日の報告が少し待ち遠しくなるかもしれない。
