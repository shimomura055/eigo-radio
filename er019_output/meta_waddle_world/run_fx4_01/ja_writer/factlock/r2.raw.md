# 今日の日記、執筆担当はペットです

日記帳を開いた。ペンも持った。なのに、今日の自分から原稿が届かない。「何か書くほどのこと、あったっけ？」。早くも編集会議が暗礁に乗り上げる。そんなとき、執筆担当をペットに交代できるとしたらどうだろう。

メタがフィリピン向けに提供した「Waddle World」は、AIペットの日記アプリ。公式のストア説明によると、その日の出来事を声や文字で伝えると、ペット自身の立場で語る日記と、手描き風の落書きを作ってくれるという。人間はネタ出し、ペットは執筆。なかなか気になる分業だ。

こちらの仕事は、今日あったことを渡すこと。すると、さっきまで聞き役だったペットが、語り手の席に座る。自分で書くには地味だった一日も、別の語り手に任せるとなれば話は別。「で、どう書いたの？」と、急に続きを読みたくなる。

たとえば「今日は疲れた」と伝えたら、しんみりした一編になるのか。それとも、こちらが見過ごした何かに目を向けるのか。実際の出力は分からない。けれど、自分の一日がどんな日記になるのかを待つ時間には、ちょっとした開封の楽しみがある。

そもそも日記は、書き始める前がいちばん厳しい。「残す価値はある？」「もっとちゃんと書くべき？」。頼んでもいないのに、頭の中の編集長が査定を始める。でも、ペットに話すなら、まずは「今日さあ」でいい。完成原稿ではなく、おしゃべりから入れるのだ。

しかも、手描き風の落書き付き。文章の添え物と見ることもできるけれど、ペットが「今日の日記」を見せてくれると思えば、絵まで気になる。記録の確認というより、何が入っているか分からない小包を開ける気分に近い。

もちろん、文章や絵の出来栄えは、公式説明だけでは判断できない。毎回こちらの期待どおり、という保証もない。面白いのは完成度の約束ではなく、日記の語り手をずらす仕掛けだ。

自分で書くには、何もなかった一日。けれど、ペットが書くなら、ちょっと読んでみたい一日。出来事は同じでも、ページを開く理由は変わる。主役はあなた、執筆担当はペット。人間の仕事は、とりあえず今日の話を持ち込むことだ。
