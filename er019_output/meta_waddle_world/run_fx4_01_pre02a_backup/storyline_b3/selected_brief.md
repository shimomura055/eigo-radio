# Selected Fact Brief

## Storyline
Metaがフィリピン向けに提供したAIペットアプリ「Waddle World」は、一日の出来事をペットに伝えると、ペット視点の絵付き日記を作ると公式に説明されている。

## Selected Facts
・WW-01：Meta Platforms, Inc.名義の「Waddle World: AI Pet Journal」をフィリピン向けApp Store・Google Play掲載ページで確認。TechCrunchも同国向けのiOS・Android提供を報じた。Appleの掲載情報はiPhone専用であり、iOS全端末対応とは書かない。
・WW-03：両ストアの公式説明によると、利用者が音声またはテキストで一日の出来事を伝え、ペットが自身の声による日記エントリーと手描き風の落書きを作る。入力した出来事がペットによる絵付き日記になる、という機能上のつながりを説明の核にする。

執筆上の制約：生成機能は公式の製品説明として帰属を明示し、実際の生成品質を検証したとは書かない。提供範囲を他地域へ一般化せず、公開地域の選定理由や事業上の狙いを推定しない。
