# Selected Fact Brief

## Storyline
Metaがフィリピン向けに提供したAIペットアプリ「Waddle World」は、一日の出来事をペットに伝えると、ペット視点の絵付き日記を作ると公式に説明されている。

## Selected Facts
- 【事実1】Meta Platforms, Inc.名義のアプリ「Waddle World: AI Pet Journal」が、フィリピン向けのApp StoreおよびGoogle Play掲載ページで確認できる。TechCrunchは、iOS・Androidでフィリピン向けに提供されたと報じた。（範囲：フィリピン向けのストア掲載。Appleの掲載情報はiPhone専用と表示。日本・米国を含む他地域での提供はこの事実の範囲に含めない。条件：ストア掲載およびTechCrunchの報道に基づく。掲載・提供状況は確認時点のもの）
- 【事実2】App StoreとGoogle Playの説明は、利用者が音声またはテキストで一日の出来事を伝え、ペットが自身の声による日記エントリーと手描き風の落書きを作る機能を説明している。（範囲：公式ストア説明に記載された機能。条件：音声入力またはテキスト入力が可能と記載）
