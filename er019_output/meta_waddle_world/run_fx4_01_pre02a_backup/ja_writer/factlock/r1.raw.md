# 今日の日記、執筆担当はペットです

「今日は何を書こう」。日記を開いたとたん、そこで止まる。ところが、もし執筆担当がペットだったら？　こちらは今日の出来事を伝えるだけ。自分の一日が、ペット目線の日記になって戻ってくる。日記を書くのは面倒でも、それはちょっと読んでみたい。

メタがフィリピン向けに提供した「Waddle World」は、AIペットの日記アプリだ。公式のストア説明によると、その日の出来事を声か文字で伝えると、ペット自身の立場で語る日記と、手描き風の落書きを作ってくれるという。

つまり、あなたは今日の出来事を持ち込む人。ペットはそれを聞き、日記にする人……いや、ペット。さっきまで聞き役だった相手が、今度は語り手の席に座る。この小さな「席替え」が、なんだか楽しい。

たとえば「今日は疲れた」と伝えたら、どんな日記になるのだろう。しんみりした話になるのか、それとも思いがけないところに目を向けるのか。実際の出力は分からないけれど、自分が渡した一日を、別の語り手がどう料理するのか。その時点で、ページを開く理由ができる。

自分で日記を書くとなると、つい構えてしまう。「残すほどの出来事はあった？」「もう少しちゃんと書くべき？」。気づけば、自分の一日を自分で審査している。でも、ペットに話すのならどうだろう。立派な記録を完成させるより、まず今日のことを聞いてもらう。入口が変わるだけで、日記との距離も変わりそうだ。

そこに手描き風の落書きまで付く。文章のおまけ、と考えることもできるけれど、「ペットが作った日記を見せてくれる」と捉えると、ぐっと愉快になる。今日は何を書いたのか。どんな絵を添えたのか。記録を確認するというより、届いた一冊をのぞく気分に近い。

もちろん、どんな文章や絵ができるのか、公式説明だけでは分からない。期待どおりの仕上がりかどうかは、また別の話だ。ここで惹かれるのは完成度への保証ではなく、「自分のことを、自分以外に語ってもらう」という仕掛けである。

日記は、自分が自分について書くもの。そんな当たり前から、語り手だけをちょっとずらす。すると、残すほどでもないと思っていた今日が、「どんなふうに語られるだろう」と気になる今日になるかもしれない。主役はあなた。でも、執筆担当はペット。その役割分担なら、日記の続きを待つのも悪くない。
