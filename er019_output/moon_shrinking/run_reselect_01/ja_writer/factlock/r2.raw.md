# 月のしわ、8,900本超！その奥に潜む「岩の上着」の秘密

月にも、しわがある。しかも、研究チームが数えたのは8,900本超。夜空ではつるんと見える月も、近くで見ればなかなかの「しわ持ち」らしい。だが、美容液の出番ではない。このしわ、月の縮み方や、意外な「着こなし」を知る手がかりなのだ。

研究チームが使ったのは、月探査機LROのカメラ画像。月面の崖を探し、地図にまとめた。しわの正体は、片側が急で、反対側がゆるやかな崖。岩盤がぎゅっと押され、片方がもう片方に乗り上げた跡と考えられている。月面に刻まれた、壮大な「押し合いへし合い」の記録だ。

この地図から月の縮み方を計算すると、半径が約42から46メートル小さくなったことに相当するという推定が出た。表面のしわを読み解いて、巨大な天体のサイズダウンを探る。月の身体測定、なかなか手が込んでいる。

ただし、ここで「月は誕生以来、それだけしか縮んでいないのか」と思ったら、ちょっと待った。今回見ているのは、比較的新しい断層が残した、月の歴史の後のほうの収縮だ。誕生から現在までの総決算ではない。

一方、月が冷えてきた歴史全体を計算するモデルでは、もっと大きな収縮が予測されている。では、計算が大外れ？　そう結論づけるのは早い。比べている期間も、調べ方も違う。同じ条件で測った数字同士の勝負ではないのだ。

それでも気になる、この差。説明の候補として登場するのが、砕けた岩の層である。いわば、月がまとった「岩の上着」。聞くだけで肩が凝りそうだが、注目すべきは重さではなく、保温効果だ。

研究チームは、すき間の多い厚い岩の層が、断熱材のように働いた可能性を挙げている。家の断熱材が熱を逃がしにくくするように、月の内部の熱も逃げにくくなったのかもしれない。その結果、冷えるのも、縮むのも、ゆっくりになった可能性がある。

つまり月は、岩の上着でぬくもりをキープしていたのかもしれない。ただし、「犯人は上着だ！」と謎解きを締めくくるのはまだ早い。今のところは、差を説明できるかもしれない候補の一つだ。

月面の崖を数えていたら、話は内部の熱、そして上着の着心地ならぬ保温性へ。しわは、月の冷え方を探る大切な手がかりだった。次に月を見上げたら、その丸い姿の下にある「岩の上着」も想像してみよう。月の着こなし、見た目以上に奥が深い。
