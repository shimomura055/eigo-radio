# Selected Fact Brief

## Storyline
LROの月面画像で「しわ」を地図化し、後期の半径収縮を約42〜46 mと推定したが、熱史全体を扱う冷却モデルの予測より小さい理由は未解決で、砕けた岩の層の断熱効果が候補に挙がっている。

## Selected Facts
・しわの意味：ローベート・スカープは、片側が急で反対側がなだらかな崖状の地形。押し合う力で岩盤の一方が他方に乗り上げる、浅い断層の地表への現れと研究では解釈されている。単なる見た目のしわではなく、収縮を読み解く手がかりとして説明する。
・観測の土台：研究チームは月を回る探査機LROのカメラ画像から、こうした崖を8,900本超地図化した。月面に実在する全ての崖を数え切ったという意味ではない。
・中心的な推定：断層地形に基づく計算では、後期の収縮は月の半径で約42〜46 mに相当する。断層面の傾きなどの前提に依存する推定で、半径の変化を直接測定した値ではない。
・時間の範囲：これは月の誕生以来の全収縮量ではなく、若い断層群が記録した、何億年ものあいだのごくわずかな縮み。断層ができ始めた年代は確定しておらず、期間にも不確実性が残る。
・意外性と比較の制約：月の冷え方を計算するモデルには、累積の半径収縮を少なくとも約750 m、別のモデルでは少なくとも約1.1 kmと予測するものがある。ただし、モデルは熱史全体の累積、今回の推定は後期の断層に残る収縮であり、同じ期間を同じ方法で測った値の直接比較ではない。今回の値を月の全収縮量としたり、モデルが誤りと断定したりしない。
・理由の候補：厚く、すき間の多い砕けた岩の層が断熱材のように働き、内部の冷却・収縮を遅らせた可能性が挙げられている。候補説明の一つにとどめ、原因が決着したようには書かない。

表現上の制約：推定値と年代の不確実性を保持する。現在の縮小速度へ換算したり、急速な縮小、近いうちの見た目の変化、崩壊へ結びつけたりしない。
