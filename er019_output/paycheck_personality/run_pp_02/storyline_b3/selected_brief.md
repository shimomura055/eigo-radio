# Selected Fact Brief

## Storyline
11件の縦断研究の統合分析で、収入と勤勉性には個人内の小さな双方向の関連が見つかったが、観察データに基づくため因果関係とは断定できない。

## Selected Facts
・一次研究：Wen-Dong Liらによる、Psychological Bulletin掲載の収入と性格特性の双方向関係を扱った連続時間メタ分析。（F02）
・対象：事前登録された研究で、11件の大規模な縦断パネル研究の個人レベルデータを統合。就労中で、性格と仕事からの収入を報告した参加者を解析した。参加者数は解析ごとに異なり、最大134,515人。全モデル共通の人数ではない。（F04）
・方法：ランダム切片交差遅延パネルモデルを用い、安定した個人間差と個人内の変化を分けて推定した。単なる高収入者と低収入者の性格比較として説明しない。（F07）
・中心結果：最大の標準化離散時間交差遅延効果は、収入→後の勤勉性が+0.0630、勤勉性→後の収入が+0.0589。いずれも約1.30年の間隔で最大だった。複数の時間間隔にわたる最大推定値であり、収入や性格の変化率を示す数字ではない。（F08）
・解釈の限界：著者らは因果関係を確定できないと明記した。年齢調整でも主要な結論は大きく変わらなかったが、他の第三変数の可能性は残る。「収入が勤勉性を高めた」「勤勉性が収入を増やした」とは書かない。関連が生じる心理的な機序は、選定したFactからは説明しない。（F15）
