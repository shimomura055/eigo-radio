# Selected Fact Brief

## Storyline
11件【中核数値】の縦断研究の統合分析で、収入と勤勉性には個人内の小さな双方向の関連が見つかったが、観察データに基づくため因果関係とは断定できない。

## Selected Facts
- 【事実1】一次研究はWen-Dong Li、Kaili Yu、Weiwen Yang、Zhen Zhang、Xin Zhang、Christian Dormann、Huanxi Zhang、Yanglei Zhengによる、収入と性格特性の双方向関係を扱った連続時間メタ分析である。（範囲：Psychological Bulletin掲載論文）
- 【事実2】研究は事前登録された連続時間メタ分析で、11件【中核数値】の大規模な縦断パネル研究の個人レベルデータを統合した。解析に含まれた参加者数は最大134,515人【中核数値】で、解析ごとに参加者数は異なる。（範囲：11件【中核数値】の全国または地域代表性を持つ縦断研究。最大解析標本数は134,515人【中核数値】。条件：参加者数はBig Five各特性と収入の解析ごとに異なる。研究者は就労中で、性格と仕事からの収入の情報を報告した参加者を解析対象とした）
- 【事実3】対象研究は、収入とBig Fiveの少なくとも1【周辺数値】特性を縦断的に3回以上【中核数値】測定することなどを適格条件とし、解析には個人レベルの変化を扱うランダム切片交差遅延パネルモデルを用いた連続時間メタ分析を行った。（範囲：メタ分析に含めた縦断研究と、統合個人レベルデータの解析。条件：個人レベルデータまたは必要な同時・自己回帰・交差遅延相関情報が得られ、標本数や測定間隔などの記述情報が利用可能であることも条件とした）
- 【事実4】最大標準化交差遅延効果では、収入から勤勉性への関連は+0.0630【中核数値】、勤勉性から後の収入への関連は+0.0589【周辺数値】で、いずれも約1.30年【周辺数値】の間隔で最大だった。（範囲：11【周辺数値】研究の統合個人内モデル。特性別解析のNは異なる。条件：報告値は複数の測定間隔にわたる最大の標準化離散時間交差遅延効果）
- 【事実5】著者らは、観察された関係から因果関係を確定できないと明記した。年齢を調整した追加解析では主要な結果・結論は大きく変わらなかったが、年齢以外の第三変数の可能性がなくなるわけではない。（範囲：一次研究の全縦断分析。条件：追加解析では年齢を統制した。著者らは、因果関係のより強い根拠を得るため、可能であればフィールド実験を提案した）
