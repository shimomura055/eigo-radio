収入が増えると、性格も変わる？ 比べる相手は「自分」です

「よく稼ぐ人は、やっぱりまじめ？」「それとも、お金に余裕ができると人は変わる？」。性格と収入の話は、つい「成功する人の特徴探し」になりがちです。でも今回、スポットライトが当たるのは、隣の高収入さんではありません。ほかでもない、自分自身です。

研究チームがまとめて分析したのは、同じ人たちを追いかけた11件の研究データ。対象は、働いていて、性格と仕事からの収入を報告した人たちです。性格と収入は、それぞれ3回以上調べられています。一度きりの「性格・収入チェック」ではないのがポイントです。

さらに、この分析では、もともとの人による違いと、その人の中で起きた変化を分けています。「あの人は私よりまじめで、収入も高い」ではなく、「自分の収入が変わった後、自分のまじめさはどう動いた？」を見るわけです。他人とのランキング対決から、自分の変化を追う定点観測へ。カメラの向きが違います。

そこで登場するのが「勤勉性」。まじめに、こつこつ取り組む傾向のことです。分析では、同じ人の中で収入が高くなることは、その後に勤勉性が高くなることと結びついていました。

しかも、矢印は反対向きにも。勤勉性が高くなることと、その後の収入が高くなることにも、小さな結びつきがありました。つまり「性格から、その後の収入へ」だけでなく、「収入から、その後の性格へ」という向きにも、弱いつながりが見られたのです。

性格はいつも「収入を説明する係」だと思っていたら、収入の側にも出番があった。ここが、この研究の面白いところです。ただし、ここで「なるほど、給料アップで性格もアップデート！」と早合点するのは禁物です。

これは変化を観察したデータの分析であって、収入が性格を変えたとも、性格が収入を増やしたとも断定できません。別の何かが、両方に関わっている可能性もあります。「先に起きた」と「原因だった」は別の話。時間の順番が見えても、犯人確定、とはいかないのです。

だからこそ、自分の給料や働き方を振り返るときも、「自分はこういう性格だから」で話を閉じないでみる。「最近、自分の中で何が変わっただろう？」と眺めてみる。これは誰かを採点するための研究ではなく、自分の変化を見つめる手がかり。比較の相手を変えるだけで、収入と性格の話は、少し違う顔を見せてくれます。
