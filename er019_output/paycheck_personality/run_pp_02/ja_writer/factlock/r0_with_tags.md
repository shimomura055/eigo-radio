収入と性格、比べる相手は誰？

「収入と性格に関係がある」と聞くと、「よく稼ぐ人は、どんな性格なの？」と考えたくなりませんか。でも、今回ちょっと面白いのは、他人との比較より、自分の変化に目を向けることです。【事実3】

研究チームは、同じ人たちを追いかけた11件の研究のデータをまとめて分析しました。【事実2】対象になったのは、働いていて、性格と仕事からの収入を報告した人たちです。【事実2】性格と収入は、3回以上調べられています。【事実3】

ここで大事なのは、もともとの人による違いと、その人の中で起きた変化を分けて見ていることです。【事実3】「あの人は私よりまじめで、収入も高い」という比べ方ではなく、「自分の収入が変わった後、自分のまじめさはどう動いたか」に目を向けています。【事実3,事実4】比べる相手が、自分になるわけです。【事実3】

そこで注目したいのが「勤勉性」。まじめにこつこつ取り組む傾向のことです。【事実4】分析では、同じ人の中で、収入が高くなることは、その後に勤勉性が高くなることと結びついていました。【事実4】反対向きにも、勤勉性が高くなることと、その後の収入が高くなることに、小さな結びつきがありました。【事実4】

つまり、性格から後の収入を見るだけでなく、収入から後の性格を見る向きにも、弱いつながりがあったのです。【事実4】性格を「収入を説明する側」にだけ置かない。ここが面白いところではないでしょうか。

ただし、「給料が上がれば、まじめになる」と受け取るのは早すぎます。【事実5】これは、変化を観察したデータの分析で、収入が性格を変えたとも、性格が収入を増やしたとも断定できません。【事実5】別の何かが両方に関わっている可能性も残っています。【事実5】順番が見えても、それだけで原因が決まるわけではありません。【事実5】

自分の給料や働き方を振り返るときも、「自分はこういう性格だから」と話を終わらせず、「自分の中で何が変わっているのかな」と考える手がかりになるかもしれません。誰かを採点する話ではなく、自分の変化を眺める話として読む。そうすると、収入と性格の研究が、少し違って見えてきませんか。
