# 給料が上がると、まじめさもアップ？ 比べる相手は「いつもの自分」

「まじめに働けば、給料が上がる」。おなじみの話だ。では、「給料が上がると、まじめになる」はどうだろう。給料明細に、性格のアップデート機能でもついているのか？　今回の研究は、この意外な“逆向き”にも目を向けた。

研究者たちがまとめたのは、同じ人を長く追った11件の研究データ。対象は、働いていて、性格と仕事からの収入を報告した人たちだ。どの研究でも、性格と収入をそれぞれ３回以上調べている。一枚の記念写真ではなく、変化を追う連続ドラマである。

ただし、このドラマには「隣の優秀な同僚」との対決はない。比較相手は、いつもの自分。もともとの人と人の違いと、その人自身の変化を分け、「ほかの人よりどうか」ではなく、「自分の普段の状態からどう変わったか」を調べた。

すると、収入がその人の普段より高いと、その後の「勤勉性」も少し高い、という関係が見つかった。勤勉性は、ここでは「まじめさ」と考えてほしい。さらに、まじめさが普段より高いと、その後の収入も少し高いという関係があった。

収入から、まじめさへ。まじめさから、収入へ。一方通行だと思っていた道に、逆向きの車線もあったわけだ。ただし、どちらのつながりも小さい。「昇給したら超まじめ人間に変身！」という派手な展開ではない。

ここで、脳内に年収ランキングが浮かんだ人は、いったん閉じよう。これは「まじめな人ほど、ほかの人より稼ぐ」という話ではない。見ているのは、同じ人の中で起きる変化。対戦相手のいない、自分の定点観測なのだ。

そして、「給料が上がったから、まじめになった」と断定するのも早い。研究者たちも、この結果だけでは原因と結果を決められないとしている。別の何かが、収入とまじめさの両方に関わっていた可能性もある。関係が見つかっても、その仕組みまで判明したわけではない。

だから、給料明細を「人間としてのまじめさ採点表」にする必要はない。低収入なら不まじめ、高収入なら優等生。そんな乱暴な通知表は、この研究からは作れない。

面白いのは、収入を性格の「結果」として見るだけでなく、その後の性格を考える「出発点」にもしてみることだ。「誰がいちばん稼ぐ？」から、「自分はどう変わっていく？」へ。次回が気になる連続ドラマ、その主役はあなた自身かもしれない。
