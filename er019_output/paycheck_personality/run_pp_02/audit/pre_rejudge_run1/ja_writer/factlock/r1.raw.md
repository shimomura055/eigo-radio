# 給料が上がると、まじめになる？ 比較相手は「いつもの自分」

「まじめに働けば、収入は上がる」。そう聞くと、つい背筋が伸びる。でも、「収入が上がると、まじめさも上がる」と言われたら？　今度は給料明細をのぞきたくなるかもしれない。今回の研究は、この両方向に目を向けた。

研究者たちがまとめたのは、同じ人を長く追いかけた11件の研究データ。対象は、働いていて、性格と仕事からの収入を報告した人たちだ。性格と収入を、それぞれ3回以上調べた研究が使われている。一度きりの記念写真ではなく、変化を追うアルバムのようなものだ。

ポイントは、比べる相手。「隣の席のあの人」ではない。「いつもの自分」である。もともとの人と人の違いと、その人自身の変化を分け、「ほかの人よりまじめか」ではなく、「自分の普段の状態から、どう変わったか」を調べたのだ。

すると、収入がその人の普段より高いと、その後の「勤勉性」も少し高い、という関係が見つかった。勤勉性は、ここでは「まじめさ」と考えてほしい。さらに逆向きにも、まじめさが普段より高いと、その後の収入も少し高いという関係があった。

収入から、まじめさへ。まじめさから、収入へ。一方通行だと思っていた道に、反対向きの矢印も見つかった格好だ。ただし、どちらのつながりも小さい。「まじめさ倍増、収入も爆増！」という景気のいい話ではない。

そして、ここを取り違えてはいけない。これは「まじめな人ほど、そうでない人より稼ぐ」というランキングの話ではない。同じ人の中で起きる変化の話だ。他人との勝負を見ていたら、実は自分の時間の流れを見ていた。研究の面白さは、この視点の切り替えにある。

もちろん、「給料が上がったから、まじめになった」と言い切るのは早い。研究者たちも、この結果だけでは原因と結果を決められないとしている。別の何かが、収入とまじめさの両方に関わっていた可能性も残る。矢印が見えても、その仕組みまで解明されたわけではない。

だから、給料明細を「自分のまじめさについた点数」に変換する必要はない。収入が低ければ不まじめ、高ければ優等生。そんな採点表は、この研究からは作れない。

むしろ面白いのは、収入を性格の「結果」として眺めるだけでなく、その後の性格を考える「出発点」にもしてみることだ。「稼ぐのはどんな人？」から、「自分は時間の中でどう変わる？」へ。隣の誰かとの順位争いより、いつもの自分の続きが、ちょっと気になってこない？
