# その動画、車両全員への上映会になっていませんか

電車に乗った。座れた。ひと息つこう――と思ったら、どこかのスマホから動画の音。知らない人のおすすめ動画が、こちらの耳にも続々と到着する。乗車券は買った。でも、その上映会のチケットまで買った覚えはない。

そんな「音の相乗り」を考えたくなるニュースだ。英国では2026年10月19日、鉄道の利用者にヘッドホンの使用を促す全国キャンペーンの開始が発表された。

ただし、ここで早合点は禁物。「本日から、ヘッドホンなしの音は何でも禁止！」という新ルールができたわけではない。話の中心にあるのは、すでに存在する鉄道規則と、周囲への配慮を呼びかけるキャンペーンだ。

既存の規則では、他人を不快にさせる形で機器から音を出すことが禁じられている。スマホのスピーカーも、条件に当てはまれば対象になる。ただし、運営会社が書面で許可した場合は例外だ。

規則に従わなければ、最大£1,000の罰金を受ける可能性もある。なかなか耳に残る金額だが、大事なのは「最大」と「可能性」。スピーカーで再生した人全員に、自動で同じ罰金がかかるわけではない。「音を出したら即、千ポンド」という単純な話ではないのだ。

そこで登場するのが、ヘッドホンへの呼びかけ。駅や車内などで、ポスターや案内放送を使って伝えていく予定だ。罰金の数字だけを大きく眺めるより、こちらにも耳を向けたい。

キャンペーン名は、日本語にすれば「旅は分かち合っても、騒音は分かち合わないで」という感じ。これが、なかなかうまい。同じ車両に乗り合わせたからといって、全員が同じ動画のファンになったわけではない。その当たり前を、短い言葉で切り分けている。

私には、「楽しむのをやめて」ではなく、「音の届け先を変えて」と聞こえる。動画の続きも、好きな音楽も、自分の楽しみとして残せる。切り離したいのは、周りの人まで勝手に観客にしてしまう部分だ。ヘッドホンは、そのための小さな仕切りになる。

次に電車で再生ボタンを押すときは、ひと呼吸。「音を出していいか」に加えて、「この音、誰に届けるつもりだろう」と考えてみる。同じ電車で、同じ方向へ。それでも、耳の中まで同じ旅にする必要はない。
