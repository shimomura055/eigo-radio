# Selected Fact Brief

## Storyline
英国の鉄道では、他人を不快にさせる音の再生に既存規則で罰金が科されうる一方、2026年10月にヘッドホン使用を促す全国キャンペーンが始まったが、これは新たな一律禁止ではなく周囲への配慮を促す啓発策だ。

## Selected Facts
【今回始まった対応：F011】DfTは2026年10月19日、全国的な鉄道業界キャンペーン「Share the journey, not the noise」の開始を発表した。ヘッドホン使用を促し、事業者のウェブサイト、SNS、車内、駅で音声案内などを含むメッセージ展開を予定する。開始は発表済みだが、全事業者・全列車で展開が完了したという意味ではない。

【既存規則が対象にする行為：F002】全国鉄道Byelawsが適用される鉄道資産では、Byelaw 7(1)が、運営者の書面による許可なく、他人を不快にさせる形で音を発生・再生する機器等を使うことを禁じる。スマートフォンのスピーカー再生も条件次第で対象となりうるが、イヤホンなしの再生すべてを無条件に禁じる条文ではない。

【罰則との関係：F004】同Byelawsの違反は犯罪となり、Byelaw 17を除く各違反には標準罰金尺度レベル3以下の罰金が科されうる。DfTの同日発表は最大£1,000と説明している。これは上限であり、再生した人全員に自動的に科される即時・定額罰金ではない。

構成の軸は「今回の新しい動きは啓発」「迷惑な音への規制と罰則は既存制度」の対比とする。全国鉄道Byelawsの説明はその適用対象に限定し、キャンペーン自体が新たな禁止や罰金を設けたとは書かない。
