# Selected Fact Brief

## Storyline
2026年イグ・ノーベル賞の「ゴキブリのミルク」研究は、胚の栄養結晶の構造を調べ、結晶で栄養を蓄える生物学的意義を論じた2016年の研究だった。

## Selected Facts
・【IG2026-01】2026年9月3日に授賞されたイグ・ノーベル賞の公式受賞者ページに、ゴキブリの栄養結晶研究が掲載された。2026年は受賞年であり、対象論文の発表は2016年。
・【IG2026-02】研究対象は、胎生ゴキブリDiploptera punctataの胚の中腸から得た栄養タンパク質結晶Lili-Mip。X線結晶構造解析で立体構造を調べ、タンパク質が脂質を結合し、糖鎖を持つことなどを示した。人が飲むゴキブリ由来の乳を試験した研究ではない。
・【IG2026-03】科学的意義として、著者らは結晶として栄養を蓄える仕組みが胚への栄養供給を支える点を論じた。構造上の観察と著者による機能の解釈を区別する。比較対象に曖昧さがあるエネルギー倍率は紹介せず、ヒトへの栄養効果や食品としての安全性・実用性が検証されたとも書かない。
