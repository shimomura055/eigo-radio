# Selected Fact Brief

## Storyline
『ゴキブリのミルク』で2026年イグ・ノーベル賞に選ばれたのは、胚への栄養供給の仕組みをタンパク質結晶の構造から探った2016年の研究で、人間向け食品の効果を確かめたものではない。

## Selected Facts
【受賞と研究時期】公式受賞者ページは、この栄養結晶研究を2026年の受賞対象として掲載している。研究論文の発表は2016年であり、今年新たに実施・発表された研究とは書かない。（IG2026-01）

【何を調べたか】胎生のゴキブリDiploptera punctataの胚の中腸から得た栄養タンパク質結晶Lili-Mipを、X線結晶構造解析で調べた。結晶中のタンパク質が脂質を結合し、糖鎖を持つことなどが示された。対象は人が飲む乳ではなく、胚に蓄えられる結晶である。（IG2026-02）

【なぜ科学的に意味があるか】著者らは、結晶として栄養を蓄える仕組みが胚への栄養供給を支える点に、生物学的意義を見いだした。この部分は著者らの機能解釈として紹介する。人への栄養効果、安全性、食品としての実用性を検証した研究ではない。比較対象の表現に曖昧さがあるエネルギーの倍率は使用しない。（IG2026-03）
