# Hanshin Turns an Early Lead into a Complete Win in Hiroshima

That one run came in the fifth inning. Elehuris Montero hit a solo home run for Hiroshima. It was the Carp’s only score of the game.

Hanshin did not let that moment change the result. The Tigers added more runs in the seventh and eighth innings, and the gap continued to grow.
