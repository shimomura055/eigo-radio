## 3. notes生成規則(草案、一般規則)
1. 検出条件: claimの表現が状態変化・方向・撤回/復元・因果・主体・対象・時系列のいずれかで複数の解釈を持ち、解釈の選択がFactの方向・状態・因果・主体・対象・時系列を変える場合のみ。難語・低頻度語・数値の分母は対象外。
2. 形式: 「注意(多義): 『<表現>』は<解釈A>と<解釈B>のどちらにも読める。原資料では<根拠のある解釈>/<どちらとも確定できない>。<取り違えると変質する点>と読まないこと。」
3. 根拠なしは確定しない: 「原資料も曖昧。断定せず原語に近い表現で書く」と促す。原資料にない意味をnotesで確定しない。
4. 既存notes(制約・帰属)は維持し、注意を末尾に追記する。対象外Factには付けない。Fact本文・scope・conditions等他フィールドは変更しない。
5. 個別語を規則へ書かない(例示は解釈の型のみ)。1 factあたり最大1〜2表現。

## 4. 具体例(現行→新案、新案は注意部分のみ追記)
(a) HC-012 現行: 「サービス全体を停止した」とは書かない。ロールバック対象は人間コンシェルジュ機能として扱う。
新案: 現行+「注意(多義): 『ロールバックした』は機能の撤回・取り下げと、以前の状態への復元のどちらにも読める。本Factは『ミス』と認めた文脈で機能を当面引っ込めた意味であり、元の状態へ戻した・復元した・再び提供したとは読まないこと。原語・再開の有無は確定できないため、断定せず原語に近い表現で書く。」
(b1) HF-009 現行: 撤回後に原油価格が全面的に下落したとは書かない。観測されたのは一時的な上げ幅縮小と、その後の回復。
新案: 現行+「注意(多義): 『上げ幅を縮小した』は上昇幅が小さくなった意味で、価格が下落したとは読まない。『発表前に近い高い水準へ戻った』は縮小前に近い水準への回復で、元の水準と同一・超過とは確定できない(原資料は『近い』のみ)。途中の縮小だけ、または最終の高水準だけを単独で『下落』『変化なし』と書かないこと。」
(b2) HC-014 現行: 公開済みの一般機能と、ロールバックされた人間コンシェルジュ実験を区別する。
新案: 現行+「注意(多義): 『商業者』は取引先の企業・店舗とも提携事業者とも読め、原資料でどちらか確定できない。『公開展開する』は一般向け公開を指し、既に公開済み、または人間コンシェルジュの再開とは読まないこと。『商業者』は特定の主体へ断定せず原語に近い表現で書く。」
(c) HC-009(注意不要) 現行: 「AI電話は一般に切られる」と拡張しない。個別の従業員報告として扱う。
新案: 変更なし(多義表現なし、帰属・範囲制限のみ)。
