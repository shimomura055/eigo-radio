# USER_REPORT_CHECKLIST — ★★★★報告★★★★を出す前の固定チェック

本チェックリストはSSOTではない。`docs/pm/PM_GOVERNANCE.md` 12節(報告単位
管理ルール、特に12-3/12-4/12-4-1/12-11)・`docs/pm/REPORT_LEDGER.md`の
運用補助であり、Fableが★★★★報告★★★★ブロックを作成する直前に必ず
確認する5項目の固定チェックである(管理ID:
`PM-REPORTING-LEDGER-INITIAL-VS-RESTATE-01`、2026-09-26新設)。

## チェック5項目

1. `docs/pm/REPORT_LEDGER.md`を確認し、「初回正式報告」列が**未**の管理ID
   がないかを確認したか。REPORTファイルの存在・commit済み・Fable内部で
   完了していることは「ユーザーへ報告済み」を意味しない。
2. 初回報告となる管理IDは、結果本体(選択肢全文・推奨理由・必要数値・
   コスト・Artifact/player・Status・重要背景)を省略せず提示したか
   (「要約のみ」「詳細はREPORT参照」は不可)。
3. 再掲となる管理IDは、Fableが新たに要約し直さず、前回★★★★報告★★★★
   ブロック内の内容を基本そのままコピーしたか(12-4/12-4-1)。
4. ユーザーから明示的なFeedback・判断を受けた項目のみを再掲対象から
   除外したか(それ以外は`REPORT_LEDGER.md`上で「累積再掲対象=Y」の
   ままにし、省略しないこと)。
5. 未回答の`USER_DECISION_REQUIRED`を、報告ブロックの末尾に列挙したか
   (12-6・12-7・Gate 5/6と整合)。

## 使い方

★★★★報告★★★★ブロックを送信する直前に上記5項目を1つずつ確認する。
いずれかが未達の場合、送信前に是正する(送信後に「次回是正する」は
不可、12-9「他作業の完了待ち等を理由にした報告保留の禁止」と同旨)。
