現在の`family_z_melos_02/index.html`は、Standard／AdvancedへのリンクとASR警告一覧が中心で、ユーザー試聴用として不適切。

以下を満たすこと。

- Standard／Advancedそれぞれに、**全編通し再生ボタン**を分かりやすく配置する。
- Preview／Comment／Full Story等を含む全スクリプトを、再生順に表示する。
- Key Phrases（英語＋日本語意味）を表示する。
- 効果音・技術的な内部情報はスクリプトから除く。
- ASR警告一覧はユーザーの試聴を邪魔しない補助表示へ移動する。
- 既存の承認済みユーザー試聴ページを参照し、共通フォーマット・導線を踏襲する。
- Standard／Advanced両方で通し再生・シーク・スクリプト表示をブラウザで実確認する。
- GitHub Pages公開URLで実際にアクセス・再生できることを確認する。

既存MP3・原稿を再利用し、**記事再生成・TTS再生成は行わない**。費用JPY0を目標とする。
