# FAMILY-Y-SOURCE-DEEP-RESEARCH-01 ユーザー原文(逐語、2026-10-28)

# Claude Codeへの指示｜Family Y 議論テーマ・実在意見の情報源 Deep Research

## 1. 目的

Family Yの3 Voiceを、AIが想像で作った表面的・類型的な意見ではなく、**実際の人々の経験・価値観・感情・利害に根ざした、リアリティのある一人称の発言**にするため、議論テーマと情報源をDeep Researchで調査してください。

今回は単発のテーマ候補探しだけでなく、**今後のFamily Y量産で継続的に活用できるサイト・掲示板・情報収集方法の発掘**も目的とします。

## 2. 調査の優先順位

### 最優先：日本国内の情報源

日本の掲示板、Q&Aサイト、ニュースコメント欄、コミュニティ、個人の体験投稿などを重点的に調査してください。

候補例：
- Yahoo!知恵袋
- 発言小町
- Redditの日本関連コミュニティ
- 国内ニュースのコメント欄
- 日本語の専門掲示板・コミュニティ
- その他、実際の個人の意見・経験が豊富なサイト

上記は調査候補であり、掲載サイトを限定するものではありません。

### 次点：海外の情報源

海外の情報源も積極的に調査してください。

候補例：
- Reddit
- Quora
- 海外ニュースのコメント欄
- 専門コミュニティ・フォーラム
- その他、活発な議論が確認できるサイト

ただし、**日本人の生活・価値観・社会問題と関係が薄いテーマを主に扱うサイトは優先順位を下げてください。**

海外で盛り上がっている議論でも、日本のリスナーが自分事として考えられるテーマなら高く評価して構いません。

**サイトの所在地よりも、日本人との関連性と実際の意見の質を重視してください。ただし、同程度なら日本国内の情報源を優先します。**

## 3. 良いテーマの条件

以下を重視してください。

1. **少なくとも3つの異なる立場が自然に成立すること。** 賛成・反対・中立という機械的な3分類は避ける。
2. 立場の違いが、生活環境・経験・価値観・利害・責任などから生じていること。
3. 各人物が自分自身の言葉で主観的に語れること。
4. リスナーにとって身近、または興味を持って考えられること。
5. 具体的な体験やエピソードがあり、意見にリアリティがあること。
6. 単純な正解がなく、3人の意見を聞いた後にも考える余地が残ること。
7. 英語学習ラジオとして、興味深く聞き続けられること。

日本国内の題材に限定する必要はありませんが、日本人にとって関係性の薄い話題は優先しないでください。

## 4. 情報源の評価方法

各サイトについて、実際のスレッドや投稿を確認し、以下を評価してください。

- 個人の生の意見が豊富か
- 実体験・具体的な事情・感情が読み取れるか
- 異なる立場の人が議論しているか
- 同一テーマで3つ以上の異なる視点を集められるか
- 継続的に新しい議題を見つけられるか
- 原文・投稿日時・URLを確認できるか
- AI生成投稿、宣伝、作り話、極端な意見への偏りがないか
- 利用規約、引用、著作権、プライバシー上の制約がないか

**単に有名なサイトを列挙するのではなく、実際の投稿を読んで有用性を検証してください。**

検索結果や見出ししか確認できなかった場合、本文を確認したかのように報告しないこと。

## 5. 実在意見からPersonaを作る際の考え方

Family Yの設計思想は以下です。

- 3 Voice固定。
- 3人それぞれに異なる、明確な人物像を持たせる。
- 人物像を先に組み立て、そこから自然に主観的な発言が出てくる構成とする。
- Voiceは一人称で自由に語る。
- 客観的な記事の説明を3人に割り振るだけの構成は禁止。
- 実際の投稿から、意見の背景・経験・生活上の事情を読み取る。
- 投稿者の属性・動機を根拠なく断定しない。
- 個人の発言をそのままコピーするのではなく、複数の意見を材料に独自のPersonaと原稿を構成する。

今回は情報収集の調査であり、3 Voiceの完成原稿制作は対象外です。

## 6. 調査成果物

### A. 国内サイト・掲示板

日本国内の有望な情報源を優先順位順に整理してください。

サイトごとに、特徴、具体的な議論例、投稿の質、3 Voiceへの活用可能性、継続利用のしやすさを報告してください。

### B. 海外サイト・掲示板

国内とは分けて整理してください。

特に、日本人にも関係するテーマを発掘できるかを評価してください。

海外独自の制度・文化などが前提となり、日本のリスナーには関係しにくい議題が中心の場合は、その旨を明記して評価を下げてください。

### C. 具体的なテーマ候補

国内・海外それぞれで、実際の投稿から確認した有望テーマを提示してください。

各候補について以下を報告してください。

| 項目 | 内容 |
|---|---|
| テーマ | 議論したくなる具体的な問い |
| 国内／海外 | 情報源の区分 |
| 投稿URL | 実際の議論への直接リンク |
| 意見の実例 | 実際に見つかった主張・経験・感情の要約 |
| 3つの視点 | 自然に成立する異なる立場 |
| Persona候補 | それぞれの人物像と意見の背景 |
| 日本との関連性 | 日本人にも身近な問題か |
| 総合評価 | リアリティ・面白さ・多面性・情報の豊富さ |

想像上の意見と、実際に確認できた意見を明確に区別してください。

### D. 最終推奨

最後に、国内・海外を横断して以下を提示してください。

1. **Family Yで継続利用する価値が高い情報源の優先順位**
2. **次回制作に適したテーマ候補の上位5〜10件**
3. 各テーマで3 Voiceを成立させられる根拠
4. 今後の量産時に、低コスト・短時間で実在意見を収集する方法
5. 情報源の信頼性・偏り・利用上の注意点

国内情報源を優先しつつ、優れた海外テーマを不当に除外しないでください。

## 7. 進め方・QCD

- Deep Researchを実施し、表面的な検索結果の羅列で終わらせない。
- 国内・海外の調査は独立して並列に進めてよい。
- 候補サイトを幅広く調べたうえで、有望な情報源を深掘りする。
- 実際の投稿とURLを確認し、情報が確認できなかったものは明示する。
- 特定サイトへの過度な依存を避ける。
- 今後の量産単価70円／記事セットを踏まえ、継続利用時の検索・収集コストも考慮する。
- 調査中の技術的な問題は承認済み範囲内で自律的に解決する。
- 不要な中間報告や細かなユーザー判断は求めない。

## 8. Scope・Status・STOP条件

**今回の承認範囲は、Deep Researchによる情報源とテーマ候補の調査・評価までです。**

- Family Y本文の新規制作は行わない。
- 英訳・TTS・公開は行わない。
- Productionコード・Prompt・仕様は変更しない。
- 今後の情報収集方法について改善案を提示してよいが、自動的に正式仕様として採用しない。
- 既存の承認予算と安全条件を遵守し、超過が必要な場合はSTOPする。
- 調査結果は候補・推奨として報告し、Production採用と混同しない。
- 未解決事項とユーザー判断事項は適切に記録する。

## 9. 最終報告の形式

**結論 → 国内情報源 → 海外情報源 → テーマ候補 → 推奨情報源・テーマ → QCD・残課題**

の順に報告してください。

ユーザーは技術実装担当ではないため、具体的なサイト・議題・意見例・活用可能性を中心に、意思決定しやすい報告としてください。

**最重要：Family Yの品質を高めるため、現実の人々が本当に何を考え、なぜそう考えるのかを拾える情報源を発見すること。単に賛否の数を集めたり、AIがもっともらしい意見を補ったりする調査にはしないでください。**
