# Claude Code指示｜「月は少しずつ縮んでいる？」学習項目再選定・音声再制作

## 1. 目的・対象

記事「月は少しずつ縮んでいる？」について、「告げ口心臓」と同じ方式で、学習項目の再選定から音声制作までやり直してください。

**既存のStandard／Advanced本文は変更しないこと。**

最初にRepo・SSOTを確認し、対象記事の正式ID、Family、Standard／Advancedの本文正本、既存完成物を特定してください。

## 2. 学習項目の再選定

Standard／Advancedそれぞれについて、現在の承認済みProduction仕様に基づき、以下を再選定してください。

- ① Key Phrase
- ② Key Phrase
- ③ Key Word
- 文法・構文解説の対象

「告げ口心臓」で採用した選定・確定フォームと同じ運用を適用してください。

文法の選定件数は、本文の学習価値と現行仕様に従って判断し、無理に項目を作らないこと。

選定後、**ユーザー確認フォームを提出し、選定内容の承認を受けてください。**

ユーザー承認前に学習項目を確定扱いしたり、それに依存する有料音声制作へ進んだりしないこと。

## 3. ユーザー承認後の音声再制作

選定内容の承認後、既存の正式Production経路を使い、Standard／Advancedの音声を制作し直してください。

- 本文は既存の承認済み正本を使用する。
- Key Phrase／Key Word／文法・解説は、新たに確定した内容を使用する。
- TTS、ASR品質検査、音声組立、最終確認フォームの制作を行う。
- Voice・Style・速度・Chunk分割・retry／fallback等は、そのFamilyの現行承認仕様を適用する。
- 既存成果物を安全に再利用できる箇所は再利用し、不要なAPI費用を発生させない。

本文変更や未承認の仕様変更は行わないこと。

## 4. 最終確認フォーム

全Family・全レベル共通の、承認済み報告資料仕様を適用してください。

- 実際のChunk境界：`⏸`
- Local Rewrite：変更箇所を赤色表示し、変更前後の英文を示す
- Fallback：適用範囲全体を濃い青色表示し、最終採用Styleを示す

実際に発動していないものを表示しないこと。

これらは音声制作後のユーザー確認フォーム上の表示であり、TTS原稿へ混入させないこと。

## 5. 品質・Production Wiring

- 確定済み学習項目の後工程での無断変更を防止する。
- 本文・音声・ASR正解原稿の一致を確認する。
- LR／Fallback／regeneration／resumeと整合させる。
- 必須Regression・Validator・Integration TestをPASSさせる。
- 正式Production経路のruntime evidenceを記録する。
- Fable独立受入を実施する。
- CURRENT_SPEC／DECISION_LOG／OPEN_ITEMS／Gitを必要に応じて更新する。

既存の共通機能についてPRODUCTION_WIRED済みのものは再実装せず、当該記事への適用・動作を確認してください。

## 6. 進行・報告

品質 ＞ Delivery ＞ 量産単価 ≫ 開発費用。

既存の予算枠・STOP条件を遵守し、独立作業は並列化してください。

**報告は本タスク単位とし、無関係な案件を混ぜないこと。**

通常の中間報告・内部委任ログ・ツール実行詳細のユーザー向け出力は不要です。

ただし、今回の作業にはユーザーの選定承認が必要なため、以下の2回は正式な報告・判断区切りとします。

**第1回：学習項目の選定完了**
- Standard／Advancedの選定フォームURL
- 必要なユーザー判断

**第2回：音声・完成版の制作完了**
- Standard／Advancedの完成版試聴URL
- 音声・学習項目の品質検査結果
- Fable受入・Production Wiring状況
- 費用実績
- ユーザー最終試聴・承認待ちの明示

重大なSTOP・承認範囲外の問題は、例外として速やかに報告してください。
