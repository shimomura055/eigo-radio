# 指示｜Key Phrase意味・説明品質Trialの検証実態とNG原因の精査

## 1. 目的

これまでの報告は「59/60合格」「120件で伝染0」「誤り3件」などの集計値が中心で、**何を検証し、何が原因でNGになったのかが不明確**。

ユーザーが品質と改善方針を正しく判断できるよう、既存Trialの生データ・Prompt・入力・判定結果を再確認し、NGの原因と内訳を明確にすること。

**今回は調査・集計・報告のみ。新たな生成Trial、仕様変更、Production Wiringは行わない。**

## 2. 調査① Advanced英語説明

以下の2つの検証を明確に区別する。

- 難例20 KP × 3回＝60出力、59 PASS／1 NG
- 通常40 KP × 3方式＝120出力、日本語意味の誤りがAdvancedへ伝染した件数0

それぞれについて、以下を整理すること。

1. 何種類のKPを、どのPrompt・モデル・入力条件で、何回生成したのか。
2. Advancedが参照したStandard日本語意味は何か。
3. 日本語意味が正しかったケース、誤っていたケースの件数。
4. AdvancedのPASS／NG件数。
5. **AdvancedのNGを原因別に分類すること。**
   - Standard日本語意味の誤りに起因するNG
   - Advanced英語説明の生成自体に起因するNG
   - 両方に原因があるNG
   - 原因を特定できないNG
6. 59/60の唯一のNGについて、対象KP、Std日本語意味、Adv英語説明、NG理由と根拠を具体的に提示する。
7. 「伝染0件」の判定について、どのような検査で何を確認し、何を確認していないのか明示する。

**特に、日本語意味が誤っていた件数を分母として、そのうち何件がAdvancedの誤りに波及したのかを示すこと。**

単純な「0/120」だけでは不十分。

## 3. 調査② Standard日本語意味

G0（現行）／G2／G3について、各120出力のNGを原因別に整理する。

最低限、以下の分類を設ける。

| NG分類 | 内容 |
|---|---|
| 字義訳NG | 慣用句・比喩表現を文字どおりに訳して意味を誤る |
| 語義誤認NG | 複数の意味から本文に合わない意味を選ぶ |
| 文法・意味関係NG | 所有者、動作の対象、主語と目的語などを誤る |
| その他NG | 上記以外の明確な品質不合格 |
| 原因不明 | 根拠不足で分類できないもの |

分類の重複を整理し、**各方式のNG総数と分類別件数が一致する表**を作成すること。

また、品質が弱いがNGには至らない「薄い表現（△）」は、NGと混同せず別集計する。

各NGについて、次の実例を提示すること。

- Key Phrase
- 本文中の用法・意味
- 実際の日本語出力
- 正しい意味
- NGの具体的理由
- G0/G2/G3での発生状況

特に`draw a line`の「線を引く」が、それぞれ何回発生したかを明示する。

## 4. 集計の整合性・信頼性確認

- Trial_02／Trial_03およびOpus・Fableの最終判定を照合する。
- 古い暫定Judge判定と確定判定を混在させない。
- Fable最終判定とSonnet参考判定に差がある場合、その差を示す。
- 同一KPの再生成回数と独立KP数を区別する。
- 重複データ、再実行、欠損補修が集計に与える影響を明記する。
- 原因が推定にとどまる場合は、その旨を明示する。

既存データから判断できないものは、推測で埋めず「不明」と記載すること。

## 5. Fable独立確認

Claudeの集計結果をFableが独立して確認する。

特に、以下を重点的に検証すること。

- 59/60のNG原因の正確性
- 日本語意味の誤りとAdvanced NGの因果関係
- Standardの分類別NG件数
- 分母・分子・合計の整合
- 過去報告との矛盾

## 6. 報告形式

**結論を先に示し、次の順で簡潔に報告すること。**

1. 検証全体の一覧（対象KP数、生成回数、条件、PASS/NG）。
2. AdvancedのNG原因別内訳表。
3. StandardのG0/G2/G3別・NG原因別内訳表。
4. 代表的なNGの実例（原文・出力・正しい意味）。
5. 日本語意味の誤りがAdvancedへ波及した件数と、その根拠。
6. 未判明事項・集計上の限界。

**目的は新しい改善案を提案することではなく、既存Trialで実際に何が起きたのかを正確に把握すること。**

今回の報告では採用判断を求めない。原因と内訳を明確にした後、必要な改善方針を別途判断する。
