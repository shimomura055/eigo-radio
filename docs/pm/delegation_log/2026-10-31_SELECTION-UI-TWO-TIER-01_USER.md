# Claude Codeへの指示｜学習項目選定UIの2階層化・操作性改善

## 1. 背景・目的

OPEN-620 (II)で完成した「学習項目選定UI v3」について、ユーザーが実際の画面を確認し、**既存機能・内容はすべて問題なし**と評価しました。

今回の追加依頼は、操作性をさらに改善するための画面構成変更です。

現在は、記事一覧と各記事・レベルの選定フォームが同じページに存在し、画面内で切り替える方式ですが、これを次の**2階層構成**に変更してください。

- **トップページ：対象記事一覧・進捗管理・各選定ページへの入口**
- **個別ページ：1記事×1レベルの学習項目選定フォーム**

既存の選定仕様や機能は変更せず、画面遷移と操作性を改善することが目的です。

## 2. 変更後の画面構成

### ① トップページ

ユーザーが提示したスクリーンショットの一覧画面を基本とします。

表示内容：

- eigo-radio｜学習項目選定
- 対象記事数・対象セット数
- 全体のDone進捗（例：Done 1/18）
- 進捗バー
- 対象記事一覧
- 各記事の「Standard」「Advanced」の選定ページへのリンク
- 各レベルのDone／未完了状態
- 報告単位の一括コピー機能

**重要：トップページには個別の選定フォームを表示しないこと。**

一覧からStandardまたはAdvancedをクリックすると、それぞれの個別ページへ遷移します。

従来どおり、表示対象はその報告でユーザー判断が必要な記事・レベルだけです。過去記事や対象外のセットを混在させないこと。

### ② 個別の学習項目選定ページ

1ページにつき、1記事×1レベルの選定フォームを表示します。

表示内容と順序は、現在の承認済み仕様を維持してください。

1. 記事タイトル・レベル
2. 候補フレーズ
3. フレーズ選定へのコメント欄
4. 候補単語
5. 単語選定へのコメント欄
6. 追加指示（全体コメント）
7. Done操作

**個別ページの最上部と最下部に「Topへ戻る」ボタンを設置してください。**

長いフォームを操作していても、上部・下部のどちらからでも簡単にトップページへ戻れるようにします。

スマホでも押しやすい配置・サイズにしてください。

## 3. 既存機能の維持（必須）

今回の変更に伴い、以下を壊さないでください。

- 既存の候補表示・選定条件
- 「残りをすべて選択」
- フレーズ・単語それぞれの独立コメント欄
- 全体コメント欄
- Done条件の検証
- 選定内容変更時のDone自動解除
- 入力内容の保存・復元
- 報告単位(batch)ごとの入力状態の分離
- トップページのDone進捗表示
- 全セットDone後の一括コピー
- 未完了時の一括コピー拒否と未完了一覧
- Claude受領側のbatch照合

**ページを移動しても、入力内容とDone状態が消えないことが必須です。**

個別ページでDoneにしてトップへ戻れば、トップページの進捗と当該セットの状態が正しく更新されるようにしてください。

また、全セットDone後の一括コピーは、従来どおりトップページから**1回の操作で全記事・全レベルの選定結果とコメントをまとめてコピー**できること。

ページごとにコピーさせる方式には変更しないでください。

## 4. 設計・実装方針

実装方法はClaude側で最適化してください。

ただし、以下を満たすこと。

- 既存の選定UI v3を最大限再利用する。
- 記事・レベルごとに個別のHTMLを大量生成する必要はない。共通テンプレートとURLパラメータによる切替など、保守しやすい方式でよい。
- URLを直接開いても、指定された記事・レベルのフォームが正しく表示される。
- 個別ページからトップへ戻る際、同じbatchのトップページへ戻る。
- 別batchのデータや入力状態と混在しない。
- 無効なURLや存在しないセットについては、安全な案内表示とする。
- PC・スマホの両方で操作しやすくする。
- 不要なAPI呼び出しや量産工程の変更を行わない。

**今回の変更範囲は選定UIの画面構成・遷移・関連する状態管理に限定します。**

記事本文・音声・TTS・学習項目の選定ロジック・Production記事制作経路は変更しないでください。

## 5. 検証・受入条件

前回OPEN-620では、機能が実装済みでも公開ページで利用できない問題が発生しました。

今回は同じ問題を繰り返さないよう、**実際の公開URLでの操作確認を必須**とします。

少なくとも次を検証してください。

1. トップページには対象記事一覧のみが表示され、個別フォームは表示されない。
2. Standard／Advancedをクリックすると、対応する個別ページが開く。
3. 個別ページ上部の「Topへ戻る」が正しく動作する。
4. 個別ページ下部の「Topへ戻る」が正しく動作する。
5. フレーズ・単語の選択内容とコメントがページ移動後も保持される。
6. 個別ページでDoneにすると、トップページの状態・進捗が更新される。
7. Done後に選定内容を変更すると、従来どおりDoneが解除される。
8. 18セットすべてDoneにした後、トップページで1回の一括コピーができる。
9. コピー結果をClaude受領側で18/18件正しく処理できる。
10. 別batchとのデータ混在がない。
11. PC・スマホ双方で一覧・フォーム・上下の戻るボタンが正常に操作できる。
12. 既存の選定条件・コメント欄・入力保持・一括コピーについてRegressionがPASSする。

可能であれば、ブラウザの戻る操作や個別ページの再読み込みでも状態が失われないことを確認してください。

承認済み範囲内で発生した不具合は、原因究明→修正→再検証を自律的に行ってください。

既存仕様の変更、重大な品質問題、承認範囲・予算の超過が必要な場合のみSTOPして報告してください。
