**暫定(ユーザー未承認)。** 本書は夜間自律ループで使う代理指標の定義であり、「面白さ」そのものの測定ではない。面白さの主指標はユーザー盲検読み比べ(約10組、「続きを聞きたい方」の非劣性)で、夜間は取れない。代理指標だけで非劣性は確認できない。LLM・API不使用(¥0)。カウント実装は`docs/pm/stage0_01/narrative_count.py`(正規表現+辞書)。

## 1. 対象と単位
- 対象テキスト: JA台本(R2=`ja_writer/revision2.md`、段階2以降はChecker前後の同一言語の本文)。タイトル=先頭行、本文=空行区切り段落、「## In one line」等の見出し段落は本文に含めない。
- 文=`。！？`で分割。段落=空行区切り。
- 要素の数え方: 記事単位要素(Hook・語り枠・コメント呼応)は有無(0/1)、文単位要素(場面描写・ひねり・コメント・比喩・問いかけ)は該当文数。

## 2. 要素定義と検出手順(機械的)
| 要素 | 定義 | 検出手順(すべて正規表現/辞書、付録参照) |
|---|---|---|
| Hook | 冒頭段落で読者を引き込む問い・想像誘導・意外性提示 | 本文第1段落が`hook_q`(?・ますよね・思い浮かべ・想像・もし等)または、タイトル+第1段落が`hook_surprise`(意外・なぜ・実は・謎等)に一致すれば1 |
| 場面描写 | 場所・情景語と動作・状態の過去/進行表現を持つ具体的な描写文 | 文が`scene`辞書語と`scene_verb`に一致し、かつ数字を含まない文(数値の事実文を除く) |
| ひねり | 転換・逆接で話の見え方を変える文 | 文頭が`twist`(ところが・しかし・ただ、・ただし・でも・それでも・とはいえ・一方等) |
| 語り枠 | 記事を貫く舞台・物語の枠(舞台/幕/主役/謎/ミステリー/看板等)が前半と末尾で呼応 | `frame_words`辞書語が「タイトル+先頭40%の文」と「末尾3文」の両方に出現すれば1 |
| コメント | 筆者の評価・感想・読みどころを述べる文 | 文が`comment`(考えさせる・思います・でしょう・大事なのは・ポイントは・注目等)に一致 |
| コメント呼応 | 末尾のコメントが冒頭の語り枠と同じ語で呼応 | コメントが1文以上あり、かつ語り枠が成立し、末尾3文にコメント語が出現すれば1 |
| 比喩 | たとえ表現または枠語を使った言い換え | 文が`metaphor`(ようだ・ような・ように・みたい・いわば・まるで等)または`frame_words`に一致 |
| 問いかけ | 読者への疑問・呼びかけ | 文が`question`(?・ますよね・ですよね・でしょうか等)に一致 |

## 3. Checker前後の保持率の計算式
before=Checker/Rewrite前のJA本文、after=後の本文(どちらも同じ手順で要素を数える)。文の対応付け: 完全一致=unchanged、`difflib.SequenceMatcher`類似度0.6以上=modified、それ以外=deleted。
- 要素eの保持率 R_e = (beforeのe該当文のうち、unchangedまたは「modifiedでafter側の対応文もe該当」の数) / (beforeのe該当文数)。before該当0なら N/A。
- 厳格保持率 R_e(strict) = unchangedのみ / before該当文数。
- 記事単位要素(Hook・語り枠・コメント呼応)=before成立なら、after成立で1、不成立で0。
- 総合保持率 R_all = Σ_e kept_e / Σ_e before_e(N/A要素を除く)。
- 併せて報告: 変更文比率=modified/before文数、削除文比率=deleted/before文数、after文数−before文数。
- 判定の使い方(案、未承認): 要素別R_eの低下が大きい記事を人間確認パックに回す。閾値は未設定(段階0で分布を見てから事前登録)。

## 5. 限界(必ず併記)
- 正規表現と辞書による機械カウントであり、要素の質(うまいHook・効いたひねり)は測れない。誤検出・見逃しがある(例: dk7n R0のHookは0と数えたが、人が読めば冒頭が問いかけ的である可能性。未確認)。
- 「比喩」は`frame_words`を含む文を比喩に数える(語り枠と二重カウント)。「コメント」は筆者の評価語に依存し、事実文中の「意外」等も拾う。
- 数値を含む文を場面描写から除外するため、数値入りの情景文は数えない。
- JA/EN不一致(OPEN-239)があるため、EN側の保持は別途見る必要がある(本版はJAのみ)。
- 「保持率が高い=面白さが保たれた」とは言えない。面白さの主指標(ユーザー盲検読み比べ)の代替ではなく、夜間に取れる代理指標にとどまる。
- 3記事の試算は式の動作例で、統計的な意味はない。
