# USER_GUIDE_02 文法だけを選ぶ方法(Standard / Advanced)
1. https://shimomura055.github.io/eigo-radio/user_test/selection_form_v3/ を開く(古い画面が出る場合は再読込)。記事選択の1番目=AIの仮想の島｜Standard、2番目=AIの仮想の島｜Advanced。
2. 画面上部の青い枠に「Key Phrase／Key Word 10件はユーザー確定済み」と出ます。**KP/KWの再選定は不要**(変更できません)。
3. 下の「文法解説」に Top 1・Top 2 の2件(文法名+解説全文)が出ます。**1件を選ぶ**か、どちらも不適切なら「適切な候補なし(0件)」を選びます(2件同時は選べません。未決定のままは送信できません)。
4. Standard・Advanced それぞれで繰り返し、各画面で「選定結果をコピー」(または「ChatGPTへ送信」)。送信文が長いため通常は自動でコピーに切り替わります。コピー内容をChatGPT/チャットへ貼って提出してください(両レベル分)。
