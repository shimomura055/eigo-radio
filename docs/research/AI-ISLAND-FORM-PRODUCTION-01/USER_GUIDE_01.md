# USER_GUIDE_01 AI島の選定手順(必要最小限)

1. 開く: https://shimomura055.github.io/eigo-radio/user_test/selection_form_v3/
2. 上の選択欄で『1. AIの仮想の島｜Standard』を選ぶ(次にAdvancedも同様に。Standardの選定内容はAdvancedとは別に保存されます)。
3. 候補ごとに ①②③ のどれか1つを選ぶ(①最大3 / ①+②最大5 / ①+②+③最大12)。英語・日本語訳・「AI理由・確認用」を見て判断。
4. 下の「文法解説」で、解説全文を読み、使うものを最大2件チェック(0件でも可)。
5. 必要なら自由コメント欄に追加指示。
6. 「ChatGPTへ送信」を押す。文法を選ぶと文章が長くなるため、通常は**自動で全文がコピーされる**(「選定結果をコピーしました」と表示)ので、ChatGPTの入力欄に貼り付けて送信。うまくいかない場合は「選定結果をコピー」ボタンを使う。
7. ChatGPTが返した出力(構造化JSON+本文)を、そのまま Claude Code に貼り付ける。StandardとAdvancedそれぞれ1回ずつ。

※ 選定が終わるまで、完成記事(音声・ページ)の制作は始まりません。
