# THEME_DEFINITION_02 (委任_24: 新テーマ再現Trial「宅配の再配達は有料にすべきか?」のテーマ定義)

作成: 2026-10-24。API 0。工程は ①テーマ定義(本書) → ②実在意見収集(SOURCE_LOG_02) → ③対立軸(AXIS_ANALYSIS_03) → ④Persona(PERSONAS_05) → ⑤3 Voice構成(次委任のR0)。
前回(THEME_DEFINITION_01)と同じ形式。**テーマ固有の情報はすべてデータ側**(本書と`THEME_DATA_02.json`)に置き、runnerのPrompt・コードには入れない(PROMPT_DIFF_05参照)。

## 中心テーマ(ユーザー指定)
**「宅配の再配達は有料にすべきか?」**(ユーザー原文 USER_08 §1①、§3)

## 1. 対象と範囲
| 項目 | 定義 |
|---|---|
| 何の再配達か | 受取人の不在などで荷物を渡せず、配達員があらためて届けに行く、宅配便の再配達。 |
| 誰の話か | 受け取る側(共働き・一人暮らし・在宅勤務・高齢者などを含む)と、配達する側(宅配ドライバー)。個々の家庭の運用の良し悪しではなく、**料金を取る仕組みを設けるべきか**という問い。 |
| 問いの形 | 再配達に、通常の配送料とは別に料金を課す(有料化)べきか。幅は (a)すべての再配達から課す (b)くり返し不在の場合だけ課す (c)日時指定など別の対象に課す (d)課さずに別の手段で減らす(運賃全体・割引・受取手段の整備)。 |
| 国 | 日本。外国の制度・統計・数字は語りに出さない(既存規則を維持)。 |
| 時期 | 現在。出典には2016年〜2026年の声が混じる(SOURCE_LOG_02に日付を記録)。古い声は、当時の状況(ヤマトの有料化報道など)に依存する部分を使わない。 |

## 2. 含める論点(実在意見に根拠があり、**有料化への賛否の理由**として語られるもの)
(論点の根拠となる声IDは`AXIS_ANALYSIS_03.md`)
- 不在は誰の責任か(受取人の都合か、時間指定の不遵守・在宅なのに不在票といった配達・発送側の運用か)
- 料金を取って行動が変わるか、徴収は実際にできるか(未納・返品・受取拒否・水掛け論)
- 誰が負担する設計か(再配達した受取人に直接か、運賃全体・送料無料の見直し・割引で誘導か)
- 置き配・宅配ボックス・営業所/ロッカー/コンビニ受取が現実に使えるか(**再配達有料化との関係がある範囲に限る**。盗難・誤配・満杯・築古の住まい・営業所が遠い)
- 有料化の対象と例外(「くり返し不在だけ」「日時指定を守った上で不在」「贈答は差出人」「弱い立場の受取人」。**実在意見に根拠がある範囲のみ**)
- 配達員の負担の受け止め方(「ドライバーのために」という理由づけを受け入れるか、経営の問題のすり替えと見るか)

## 3. 除外する論点と、例外(理由としてのみ許容)
| 除外する論点 | 除外の理由 | 例外(許容する形) |
|---|---|---|
| 物流業界全体の待遇問題(請負・委託の報酬体系、誤配ペナルティ等の労務問題) | 再配達有料化の是非からの拡散。ユーザー原文§3で明示的に拡散禁止 | 当事者が**有料化への賛否の理由**として、自分の言葉で一言ふれる場合は可(例: 再配達は報酬にならない、運賃の問題と考える)。主題にしない |
| 環境問題(CO2排出) | 同上 | 「燃料の無駄」程度を理由として一言なら可。数字・制度としては語らない |
| 通常配送料の値上げ全般・EC事業者の送料無料の是非 | 周辺論点 | 有料化の代わり/補いとして語られる場合だけ一言可 |
| 置き配の標準化・手渡しの有料化(国の検討)の制度論 | 制度解説になる | 受取人本人の経験・感情の形(盗難が心配、誤配でやめた)なら可。制度の説明は書かない |
| 料金の具体的な金額・各社の施策・統計の数字(再配達率など) | 声ではない(既存規則) | なし(背景のみ。語りの中に数字を出さない) |
| 配達員の不正・詐欺メールの詳細 | 実装論・周辺 | 「不安」の形で一言なら可 |

## 4. 不必要に狭めない理由(ユーザー§3の但し書きへの対応)
- 実在の声の多くは「有料にすべきか」だけでなく「どう有料にするか(対象・段階)」「その前に何を整えるか」を語っている。**対象・例外・前提条件(時間指定の遵守、受取手段の整備)は中心テーマの内側**に置く。
- 判定の目安(目視、機械判定にしない): Voiceの全文を読んで、「この人は、再配達に料金を取ることについて何を望むのか(条件があればそれは何か)」が一言で言えれば範囲内。言えず、物流全体の待遇や環境が主題なら範囲外。

## 5. 用語定義(`relevant_terms`の候補。Voiceごとに渡す範囲は前回方式=関連分のみ。定義に賛否の立場を入れない)
| 用語 | 定義(WORLD_FRAMEの distinctions に入れる文。数字なし) |
|---|---|
| 再配達 | 配達先が不在などで荷物を渡せず、あらためて届けに行くこと。 |
| 有料化 | 再配達に、通常の配送料とは別に、受取人が料金を払う仕組みにすること。 |
| 置き配 | 受取人に会わずに、玄関先などあらかじめ決めた場所に荷物を置いてもらう受け取り方。 |
| 宅配ボックス | 留守でも荷物を預けておける、鍵のついた受け取り用の箱。 |
| 時間帯指定 | 受け取れる時間の幅を決めて、その間に届けてもらうよう頼むこと。 |

注意(前回run_03の教訓): 定義の内容を、その人の意見として語らせない。Voice Promptの「考え方D」(THINK_BLOCK)を維持し、定義はPersonaの`relevant_terms`にある用語だけを渡す。

## 6. 前回(SNSテーマ)との差で、設計時に注意した点
- 前回は構造化された大量の意見データ(CC BY 4.0)があった。**今回は構造化データがない**ため、検索・サイト内検索・人手による閲読で個人の声を拾い、出典ごとに権利区分を付ける必要がある(SOURCE_LOG_02)。
- 数字(回数)が論点そのもの(「二回目から」)になりやすく、Voice Promptの「数字・漢数字の数量表現を使わない」規則と衝突しうる。Sheetでは回数を数字にせず「くり返し」「最初の不在は大目に見る」と言い換え、規則自体は変えない(PROMPT_DIFF_05 §3、Fableへの確認事項)。
