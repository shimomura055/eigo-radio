## 設問(各記事・各Voiceに回答。引用必須。BLIND_SET_03と同一)
- A 当事者性: この人物が、この争点について語る自然な理由が本文から分かるか → あり / やや弱い / なし(根拠の引用)
- B 主張の必然性: この人の経験・感情・価値観から、この主張が生まれることに納得できるか → 明確 / やや弱い / 弱い(不自然な箇所の引用)
- 制度の取り違え: 争点の制度・規則を取り違えている箇所があれば引用(なければ『なし』)
- Q: 『実在の人が自分の生活から語っているか』 → はい / どちらとも / いいえ(根拠の引用)
- C(記事ごと): 3人を聞いて、単独では得られない対立・発見・面白さがあるか → あり / やや弱い / なし(具体)
- 同型化: 3人の語りの展開・冒頭・結びが似ていないか → 似ている / 一部 / 似ていない(引用)
- 記事間比較: どの記事が『実在の人が語っている』感が強いか、どの記事が『説明している』感が強いか。

## 記事A (言語: 日本語、題材: school)

争点: 日本の高校で、今は授業中だけ使えないスマホを、休み時間や昼休みを含む校内全体で使わないことにするか。
共通の前提: 日本の高校で、スマホの持ち込みは認めたまま、授業中だけでなく休み時間や昼休みも校内では使わないことにするかどうか。

### 記事A Voice a

授業中は、ちゃんとスマホを鞄にしまってる。昼休み、周りで机が寄せられる横で弁当箱を開けて、別の高校に通う中学の友達に模型の写真を送る。塗装に失敗したところを送ったら、向こうも塗料がはみ出した写真を返してきて、ちょっと笑って、止まってた箸を動かした。大した話じゃないけど、僕には必要な時間なんだ。クラスの通知は、返事を考えてるうちに休みが終わることもある。切ればいいのに、連絡を知らないのが怖くて見てしまう。でも、昼休みまで校内で使えなくなるのは困る。音は出さないし、周りも撮らない。教室で誰かと話すのと、外の友達とつながるのは、どっちかにしなくてもいいと思う。

### 記事A Voice b

仕事の連絡が嫌なわけじゃないんだ。惣菜売場のエプロンを畳んだ袋と教科書が、私のかばんには入ってる。売場も人手が足りないから、頼まれるとうれしくて。この前も教室前の廊下で、翌日の出勤を早められるか連絡が来た。バスを調べて返信してたら、借りた数学のノートを開けないまま休み時間が終わった。スマホは持って来られても、校内では休み時間も使わない決まりなら、少しほっとする。でも、返さないと仕事を減らされるかもって気になる。学校にいる間は返せないって、職場にも分かっていてほしい。私もその間は、明日の仕込みじゃなくて、式の続きを考えたい。

### 記事A Voice c

夕方に欠勤の連絡が来ると、スーパーの売場から事務所へ戻り、翌朝の勤務表を鉛筆で直す。定時制へ向かった品出しの生徒には、授業中は見なくていい、休み時間に確認してくれればと添えて送る。この前も、空欄を指でたどって返事を待った。出られると返事が来て、開店準備の担当を書き直した。スマホを持ってこられても、休み時間まで使えなくなるのは、正直困る。連絡を登校前に済ませる段取りは考える。でも、急な欠員を毎回、自分の早出で埋めるのはきつい。急がなくていいと送りながら、返事を当てにしてるんだ。授業には割り込まないから、休み時間の連絡は残してほしい。学校にも事情はあるだろうけど。

## 記事B (言語: 日本語、題材: school)

争点: 日本の高校で、今は授業中だけ使えないスマホを、休み時間や昼休みを含む校内全体で使わないことにするか。
共通の前提: 日本の高校で、スマホの持ち込みは認めたまま、授業中だけでなく休み時間や昼休みも校内では使わないことにするかどうか。

### 記事B Voice a

休み時間もスマホを使わないと聞いて、ちょっとほっとした。友達が嫌なわけじゃない。昼休み、机に弁当と美術部の下描きを広げても、クラスのグループが気になって箸も鉛筆も止まる。この前も隣の子に見たかだけ教えてと言われ、笑って箸を置いて反応を送った。通知を切っても、自分で確かめてしまうのが疲れる。持ってくるのはよくて、校内では皆が返さないなら、僕も言い訳せずに弁当を食べられると思う。別の高校の友達に絵を送って、教室での気まずさが薄れることもあるから、そこまで使えなくなるのは困る。でもまず、返事をしなくていい休み時間がほしい。

### 記事B Voice b

学校にも売場にも事情があるのは分かる。ただ、また私が説明して回るんだなって。昼に着た惣菜売場の制服の袋と教科書の鞄を足元に置いて、夜の学校の休み時間に翌朝の早出に返事をした。頼られるとうれしいし、給料も増える。でも学校にいる間くらい仕事から離れたい。持ち込みはよくても休み時間までスマホを使えなくなるなら、返事が遅れることを誰が売場に説明するの？担任には学校にいる時間を伝えるよう言われたけど、担当が替わればまた同じ話になる。学校には使う理由、売場には返せない理由。私が言い直し続けるだけじゃなく、学校からも伝えて、売場の担当同士でも引き継いでほしい。

### 記事B Voice c

昼休みに開け損ねた弁当の横で、次の授業の教材と生徒指導部の規則案を交互に見ている。授業中だけでなく休み時間もスマホを使わない、と直したところで手が止まった。階段の踊り場で声をかけた子は、母親の仕事が延びて、弟を迎えに行く相談をしていた。自分は連絡が済んだら教室へ戻るよう伝えた。持ち込みは認めても、あの連絡まで止めるのは違うと思う。必要な連絡や健康のための使用を、誰がどこで確かめて引き継ぐのか？そこを決めず、見かけた教員に任せるのは困る。いや、昼飯と授業準備の時間も残してほしい。校内で使わないと決めるなら、先にそこを詰めたい。
