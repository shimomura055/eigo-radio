## 2. V2・V3で「人物と主張の因果が弱い」具体箇所と、工程のどこで生じたか
最終稿(Trial_03 it3、`article_ja.md`)から引用。

### V2(54歳・養護教諭)
- 引用1: 「学校が休み時間まで使えなくして、それで対策した気になってしまわないかな。それが、どうにも怖い。」 → 主張は**学校組織への政策批評**(「対策した気になる」)で、本人の利害・欲求ではない。本人の生活(保健室)に規則が直接作用する場面がなく、「見る側」の観察者にとどまる。
- 引用2: 「先生に『スマホを禁止にしたら、保健室に来る子は減る？』と聞かれて、私は答えに詰まった。」 → **後から1文足した「発言理由」**(`TEXT_DIFF_01.md`の変更表row 6(:22)、`WORLD_SETTING_01.md` §4)。養護教諭がなぜこの争点で語るかが初稿で成立していなかった証拠。
- 引用3: 「来ないのと、つらくないのは同じなんだろうか。」「昼間にスマホを取り上げられた翌日から、顔を見せなくなったあの子」 → 抽象的な問いかけ(書き言葉の修辞)と、「使用禁止」と「取り上げ」が混ざった描写(争点は持込可・校内使用禁止、`WORLD_SETTING_01.md` §0)。
- 工程上の原因: (i)`PERSONA_CANDIDATES_01.md` #7は主張の芽を「取り上げても保健室の寝不足は治らない。問題は夜」とし、事実欄に台帳OECD-02(禁止校でも使う生徒がいる)を書いた。**台帳Factからの逆算が主張の骨格**になっている(OPUS_REVIEW_02 OF-12が価値観起点に直したが、「禁止で安心されたら…」という政策批評の骨格は残った)。(ii)選定理由は「教科担任とV1の悪者役軸が重なるから外した」=**軸の非重複**(`PERSONA_CANDIDATES_01.md:27`)。当事者性・必然性ではない。(iii)Sheetの`closing_type`=「問い返し」、`order`=「場面→感情→主張」(`er110_family_y_persona_text_trial_01.py:115-116`)が人物の語りを**指定**した。

### V3(19歳・昼は倉庫、夜は定時制)
- 引用1: 「僕は授業中、鞄の奥にしまって触らないと約束する。でも、休み時間まで使えなくすると決める前に、僕の働き方も聞いてほしい。」 → 主張が**「約束+要求」の交渉文**で、礼儀正しい整理済みの要望。怒り・不満・ずるさなど、本人の生の反発がない。
- 引用2: 「仕事か学校かなんて、選びたくない。」 → ここだけが人物固有の感情で、主張全体の入口ではなく途中に置かれている。
- 工程上の原因: (i)締めの型「約束と要求」はSheetの`closing_type`(同:151)で指定され、OF-Y3-09(締めの同型化防止)の要件から来た。**差異化の要件が、人物の主張の形を決めた**。(ii)Persona先行で固定した後、規則(終日一律回収)が実態と合わず、**争点側を人物に合わせて再設計**した(`WORLD_SETTING_01.md:15`)。定時制の実態は校内使用禁止2/25校(同§2-B-2)で、この争点で定時制の生徒を主役にする必然性は検証されていない。(iii)主張が交渉的・手続き的(「決める前に聞いてほしい」)なのは、ROOT_CAUSE_01 (a2)で既出の「手続き的で慎重な主張」への回帰。

### 共通(V2・V3・V1の3人)
1. **「優等生の大人」だけが残った**: 3人とも他者への配慮(子の行き場・職場の信用・娘との関係)が最終的な動機で、感情的反発、利己的な願望、思い込みが表に出るのはV1だけ。ユーザーが許容した多様な本音(USER_05 §2 ③)を探索する工程がなく、Prompt規則4「主張の核は1つだけ…他の論点は入れず、締めの一言で主張の核に戻る」(`er110_family_y_persona_text_trial_01.py:256`)と規則6「ためらいは多くても1か所」(:258)が、整った語りを強めた。
2. **主要当事者の除外**: 高校生本人・規則を実施する教員(生徒指導)・保護者(連絡手段が必要な家庭)が候補表で「声」「重なり」を理由に落ち、校内使用の規則に最も直接的に影響を受ける人が選ばれなかった(`PERSONA_CANDIDATES_01.md` #1、#8、#6)。これはユーザー指摘の「主要な当事者を不自然に除外しない」に反する。
3. **同一の骨格**: V1とV3の語りの順序が同一(「主張→具体的な場面→感情」、`er110_family_y_persona_text_trial_01.py:77,150`)。3人とも「自分の主張→日常の具体物→自分を少し笑う/迷う→締め」の同じ起伏で、締めの型だけを変えている(締めの種類の差は表面的な差異化)。

## 3. V1が成功した理由(再現可能な要因か偶然か)
V1(43歳の父): 主張=「学校が決めてくれれば俺だけが悪者にならずに済む」「ただ、俺が楽になりたいだけな気もする」(自己中心的な動機と自己矛盾)。
- 再現可能な要因(新設計に織り込む): F-a **規則が本人の日常に直接作用する**(夜の居間のカゴ・取り上げた翌朝の食卓)/F-b **主張が本人の欲求から出ている**(悪者役を降りたい。利己的でよい)/F-c **自己矛盾が本人の語りの中に出る**(「楽になりたいだけ」)/F-d **具体的な過去の出来事が2つ以内で語られる**/F-e 本人の言葉の癖(短い断言・自嘲)。
- 偶然の要因: 「親」はユーザー原文とPERSONA_CANDIDATESの最初に想起される類型で、設計者が生活の細部を最も書きやすかった。**想像しやすい人物ほど深く書ける**ため、V2・V3のような想起しにくい類型で同じ深さが出る保証がない(再現性がない)。ユーザーが高く評価した語りは維持する(`WORLD_SETTING_01.md` §3-b)。
- 結論: V1の成功は半分は構造(F-a〜F-e)、半分は類型の偶然。新設計は前者を工程のルール(S3の`origin`と`kind`、S5の矛盾・出来事、S4のA/B評価)に落とし、後者を「候補を幅広く出し、想起しやすさに依存しない」ことで補う(DESIGN_PROPOSAL_05)。
