# PROVENANCE_TEMPLATE_01 (出典対応表の書式。Phase 2のR0完成後に記入する)

目的: R0の各Voiceの主要な主張・経験・感情が、どの実在の声(ID・URL)から来たか、どう編集したか、何を補ったかを追跡可能にする。**リスナーには見せない内部記録**(公開時は別途CC BY 4.0の出典表示のみ)。

## 書式(1行=R0本文の1つの主張・経験・感情)
| 列 | 記入内容 |
|---|---|
| Voice | V1 / V2 / V3(One / Another / A Third) |
| R0内の位置 | 文番号(例: 第3文) |
| 主張・経験・感情(自分の言葉の要約) | R0本文の該当部分の要約(原文の長い転載はしない) |
| 種別 | 主張 / 経験 / 感情 / 理屈 / 矛盾 |
| 根拠の声ID・URL | `SOURCE_LOG_01.md`のID(例 MR-T010-02)+そのURL(みらい議会はトピックURL、TBSは記事URL+page番号) |
| 集約関係 | 単独 / 集約(複数IDを列挙。どの声のどの要素を使ったか) |
| 編集・一般化 | 元の声から変えた点(数字を落とした、肩書を落とした、言い回しを変えた等)。意味・立場を変えていないことの確認 |
| 補った表現(出典なし) | 出典にはなく編集時に補った内容(感覚的な細部、言い回し、年齢・性別等)。無ければ「なし」 |
| 判定 | OK / 補った表現のみ / **UNMAPPED**(出典も補った表現にも対応しない出来事=捏造扱い、再生成対象) |

## 運用ルール
1. R0の全文を文単位に分け、各文の内容が出典IDまたは「補った表現」に対応するかを確認する。対応しない文にUNMAPPEDを付ける。
2. UNMAPPEDが1件でもあればR0を再生成(上限は既存Gateの再生成回数に従う。上限超過ならHR Lock=人間判断)。
3. 「補った表現」は感情・感覚・口調の範囲に限る。人物・会話・出来事は補えない。
4. 実在の特定個人(番組出演者・投稿者)を識別できる情報を、本表にも書かない(属性ラベルのみ)。
