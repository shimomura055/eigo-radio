# THEME_DEFINITION_01 (委任_20 Phase 1 / ユーザーUSER_07 §2①: 対立軸抽出の前に決める中心テーマの定義)

作成: 2026-10-24。API 0。工程は ①テーマ定義(本書) → ②実在意見収集(SOURCE_LOG_01 §6) → ③対立軸 → ④Persona(PERSONAS_03) → ⑤3 Voice構成。runnerの`WORLD_FRAME_02`(`er110_family_y_opinion_based_02.py`)と一致させている。

## 中心テーマ(ユーザー指定)
**「子どものSNS利用に年齢制限・禁止を設けるべきか」**

## 1. 対象と範囲
| 項目 | 定義 |
|---|---|
| 誰の利用か | 日本の子ども(未成年)。小学生・中学生・高校生を含む。1人の特定の子ではなく、年代ごとの違いも論点になりうる |
| 何の利用か | SNS(動画やメッセージのやり取りができるアプリを含む)の利用。アカウントを持つこと、DMなどの機能を使うこと、見ること・投稿することを含む |
| 問いの形 | 年齢(または成長・判断力)を理由に、利用に制限や禁止を**設けるべきか**。制度・ルールとしての是非であって、個々の家庭の運用の良し悪しではない |
| 「制限」の幅 | (a)一定年齢までアカウントを持てない全面的な禁止 (b)年齢や成長に応じて機能・範囲を広げる段階的な制限 (c)機能ごとの制限(DM等) (d)制限をかけず家庭や本人の裁量に任せる(=設けない側の立場) |
| 国 | 日本。外国の制度・統計・数字は語りに出さない(既存規則を維持) |

## 2. 含める論点(実在意見にあり、**制限・禁止への賛否の理由**として語られるもの)
段階的制限・機能別制限 / 年齢と判断力・成長の関係 / 実効性(抜け道、制限が破られること) / 家庭の裁量と一律ルールの関係 / 友達との連絡・居場所としてのSNS / 教室内で使える子と使えない子が分かれること / 依存・睡眠・長時間利用 / いじめ・中傷・危険な人との接触 / 禁止が外れたあとの準備(いきなり解禁される問題) / 事業者の設計(無限スクロール等)の責任(制限の賛否の理由としてのみ)。

## 3. 除外する論点と、例外(理由としてのみ許容)
| 除外する論点 | 除外の理由 | 例外(許容する形) |
|---|---|---|
| **親が子の投稿・やり取りを見張ることそのものの是非** | 制度の是非ではなく家庭内の運用の話。前回R0のAnother Voiceはここが中心になり、テーマから逸れて見えた | 「見張られる前提の制限は嫌だから反対」「監視より○○がいい」のように、**制限・禁止への賛否の理由**として語られる場合は、**1か所・短く**許容する(Sheetの該当項目に「理由としてだけ語る」と明記) |
| 年齢確認の技術方式(本人確認書類・マイナンバー・国か事業者か) | 実装論。語ると制度解説になる | 「年齢確認があっても抜けられる」のように実効性の理由として一言ふれるのは可 |
| プライバシー・国家監視・表現の自由の制度論の詳細 | 一般論の意見発表になりやすい(Third Voiceが失敗した型) | 本人の言葉で「見られすぎるのは嫌」など感情の形なら可 |
| 性教育・リテラシー教育一般、課金・広告規制、生成AI | 周辺政策。中心の問いと別 | 「禁止だけでなく教育も」のように、制限の代わり/補いとして語られる場合は一言可 |
| 統計・調査の数字 | 声ではない(既存規則) | なし(背景のみ) |

## 4. 不必要に狭めない理由(ユーザー§2①の但し書きへの対応)
- 実在意見の多くは「禁止すべきか」だけでなく「どう制限するか」(段階・機能別・家庭の裁量)を語っている。**段階的制限・機能別制限は中心テーマの内側**に置く(狭く「全面禁止の賛否」だけにすると、保護者の実在意見の大半が対象外になる)。
- 賛成・反対の**理由**として親子関係・友人関係・依存が出るのは自然な議論なので排除しない。除外するのは、それ**自体が主題**になる場合(例: 親の監視の是非だけを論じる)に限る。
- 判定の目安(目視、機械判定にしない): Voiceの全文を読んで、「この人は、年齢による制限・禁止(またはその代替・段階)について何を望むのか」が一言で言えれば範囲内。言えず、周辺論点が主題なら範囲外。

## 5. 前回R0(run_01)への当てはめ(逸脱の確認)
- One Voice: 範囲内(制限への条件付き賛成)。Third Voice(中学生): 範囲内だが、制度の最低ラインを語る一般論の意見発表になっていた(PERSONAS_03 の記録参照)。
- **Another Voice: 主題が「親に投稿まで見られること」へ寄っており、中心テーマ(年齢による制限・禁止)への主張が弱かった**。→ 改善R0では「年齢による全面禁止への反対と自由」を主題に、親の見張りは理由として1か所だけにする。
