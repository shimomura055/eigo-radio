## 結論(先頭)
1. 字義訳NG(例: `an unseen clock`→「見えない時計」)は**特定の型のKPで系統的に出る**(原因は意味確定の段が無いこと)。X2pは追加callなしでこの型のFAIL系を 10/12→0/12 にしたが、**その証拠は設計に使ったKPの上でしか取れていない**。設計に使っていないKPでの再確認は未了(補強検証(b))。
2. 通常KP(54件)では35/54の文字列が変わり、**本文の文脈を持ち込む副作用が少なくとも6/54(11.1%)**あった。本番KPに占める『比喩・慣用を認識したKP』は**11〜13%**、そのうちNGが確認された型は**約2〜3.5%**。したがって**「直る希少KP」と「影響を受ける通常KP」の比は約1:3**(§3)。副作用を抑えない限り、本番全体で品質が上がるとは言い切れない。
3. そこで、X2pに『本文の語義を選ぶが、表すのはkey_phraseの範囲だけ(否定・主語・時制・対象・場面は持ち込まない)』と『定訳優先』を足した**X2p'**を、本番構成(1 level全KPを1 call・`rules_fulltext`・`prior`)で再検証する(`TRIAL_DESIGN_07.md`)。
4. 判断を依頼するのは**補強検証の後**(通常は)。ただし費用が累計300円を超えるため、**先に補強検証の費用承認**が要る(UDR #178)。

## 2. 設計原則の案(Opus推奨。二択ではなく『範囲』で切る)

### 3-3. 比較と含意
- **影響を受けるKPの数**: 直る可能性のあるhard-core型 ≒ 0.2〜1.3 / 記事セット、持ち込みが生じる通常KP ≒ 1.0 / 記事セット。**数だけを比べると同程度かやや不利**。
- **深刻度**: hard-core型のNGは『意味が日本語読者に伝わらない(FAIL_LIT)』で重大。持ち込みは多くが『意味は合うが範囲が広い/狭い(THIN)』〜Fable水準ではPASS。重み付けすれば改善側が上回る可能性がある(ただし**Fable単独判定が緩い方向に揺れた**ため、持ち込み側の重大度は過小評価の可能性)。
- 結論: 現状のX2pのまま採用すると『希少な重大NGを直す代わりに、通常KPの軽微な持ち込みを増やす』交換になる。**X2p'で持ち込みを抑えられるか**が採否の分かれ目で、補強検証(c)(d)がそれを測る。Zは比喩認識KPが少ない(2.2%)ため、**Zへの適用は便益が小さく副作用のみ残る可能性**(仮説、補強検証の対象外。Zを除外して配線する案はFable判断)。

## 4. 過去のユーザー判断(wallet)との整合(OF-KP2-08、Charter 8)
- 過去のユーザー判断: `reach for someone's wallet` について、ユーザーは『他人の財布に手を伸ばす、でいいんじゃない。比喩的な意味なのか直接的な意味なのかはわからないが、後者なら問題ない。**本文で云々は関係ないでしょ?**』と述べ(`docs/pm/delegation_log/2026-10-23_FX-KP-GENERALIZATION-MEANING-COMPREHENSIVE-01_USER_05.md:3-8`)、所有者誤りNGの分類は取り下げられた(`AUDIT_01/AUDIT_SUMMARY_01.md:108`)。B0の「人の財布に手を伸ばす」は**見出し語忠実でPASS**(`TRIAL_05/FABLE_BLIND_RESULT_05.md` 注記17)。
- 整合の評価:
  - **原則と矛盾しない部分**: ユーザーの『本文の事情(誰の財布か)はglossに関係ない』は、『表すのはkey_phraseの範囲だけ。本文側の主語・対象・場面は持ち込まない』と**同じ方向**。この原則は本判断を補強する。
  - **要注意の部分**: ① X2pの「財布を出してお金を払おうとする」(Fable: PASS)は、見出し語の `someone's` を訳出せず、『お金を払おうとする』という解釈を含む。**ユーザー判断では元の「人の財布に手を伸ばす」が既にPASS**なので、Stage 2の『FAIL→PASS 2件』のうち wallet は**改善ではなく『PASSからPASSへの言い換え』**で、改善件数は **2件→1件(`settle at`のみ)**とするのが正確。② 『直接的な意味ならB0のままで問題ない』という判断は、**字義が正しい用法まで解釈訳に書き換えるリスク**(過剰解釈)を示す。X2p'の定訳優先・範囲規則がこれを抑えるかは補強検証(b)の`sheltered from the rain`型(字義が正解のKP)で測る。
- 再照合: 二重判定(`fable_blind_06.md`の再照合対象)で、第二評価者が『範囲を超えた持ち込み』基準で wallet の各文字列を評価し、過去判断と矛盾するかを書く。**矛盾が出ればユーザー判断を覆さず、基準側を見直す**(ユーザー判断が優先)。
