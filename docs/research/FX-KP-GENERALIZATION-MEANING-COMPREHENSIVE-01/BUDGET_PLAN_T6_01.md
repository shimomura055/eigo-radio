## 3. 補強検証の費用見積(次委任・ユーザー承認後)
見積方法: `py er112_kp_gm_trial_06.py plan ...`(API 0)。Trial_05台帳の実測(call内KP数nに対する 1call費用 = a + b×n を最小二乗。X2pp←X2p実測に+10%余裕[X2p'追加分は未測定])を、本番構成のcall内KP数へ**外挿**。実測のnは最大4(B0は最大2)で、本番構成(5〜8)は外挿であり、**この外挿の実測が補強検証(c)(e)の目的の一つ**。
| 補強 | 集合・構成 | arm×rep | 見積(円) |
|---|---|---|---|
| (b) 新hard-core 9KP | siblingなし(8 call/rep) | B0p×2rep | 0.93 |
| | | X2pp×2rep | 2.13 |
| (b') R退行確認(追加) | R 7KP(4 call) | X2pp×1rep | 0.75 |
| (c)(e) 本番構成 Stage 2 54KP | full-level(33 call、call内KP 3〜8、生成対象161KP[sibling 107]) | B0p×1 / X2pp×1 | 2.02 / 15.17 |
| 〃 `--max-level 5`(33 call、call内KP 3〜5、生成対象151KP) | | B0p×1 / X2pp×1 | 2.01 / 14.30 |
| 〃 評価KPのみ(29 call、sibling無し=本番構成ではない) | | B0p×1 / X2pp×1 | 1.71 / 5.72 |
- 構成案: **(P)full-level**: 0.93+2.13+0.75+2.02+15.17 = **20.99円**(retry込み上限 ×1.3 = **27.3円**)。**(Q)max-level 5**: **20.11円**(×1.3=26.1円)。**(R)評価KPのみ**: **11.23円**(×1.3=14.6円。ただし『1 level全KPを1 call』という本番構成は検証されない=OPUS_REVIEW_08 論点1-4は未解消)。
- 推奨: **(Q)**(本番のlevelは5件前後が想定。`--max-level 5`はeval KPを優先して残しsiblingをrank順に詰める)。ただし実在のlevelは3〜8KP(平均4.9)なので、(P)が最も本番に忠実。差は約0.9円。
- 見積の不確実性: ①外挿(nが大きいほどX2ppの出力tokenはKP数にほぼ比例、reasoningは非線形の可能性) ②X2p'の追加文言による推論token増(+10%余裕のみ) ③retry発生(上限2)。上限は ×1.3 を目安にしつつ、`--cap` は**25〜28円**を推奨(cap超過見込みでHALT)。
- 内訳外の費用: 判定(Fable盲検・第二評価者)はAPI 0。Sonnet参考Judgeは使わない。
