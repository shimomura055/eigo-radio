# DOMESTIC_METHOD_01 (委任_01A: 国内の実在意見を低コスト・短時間で継続収集する方法の提案)

作成: 2026-10-28。**提案であり、正式仕様として採用するものではない**(CURRENT_SPEC・Prompt・Production code は無変更)。数値は今回の調査で実測したものと、実測していない想定を分けて書く。

## 1. 今回の調査で実測したこと(根拠)

- 取得はHTTP GETのみ(requests+BeautifulSoup)、LLM API呼出0、API費用0円。1.6秒以上の間隔で、本文取得36ページ+一覧・robots・規約の取得を合わせ約100リクエスト。実時間は約20分(調査者の閲読時間を含む)。
- ページ取得自体は軽い(静的HTML、UTF-8、1ページ0.3〜1秒)。**時間の大半は選別・閲読**(1テーマあたり3〜5スレッドを読む作業)。
- サイト別の発見のしやすさ(実測):
  - ガルちゃん: トップ/`/rank/`で当日の人気トピック(順位・コメント数・経過時間つき)が1リクエストで取れる。
  - 小町: ジャンル別の週間/月間ランキングが取れる(規約上、自動化は不可)。
  - ママスタ: カテゴリ一覧(`/bbs/topic/category/<id>`)にトピ名・日時・コメント数が出る。
  - 5ch: 板の`subback.html`にスレ一覧(レス数つき)が出る。
  - 増田: トップ・日別アーカイブが取れる。
  - 知恵袋: カテゴリ一覧(`/category/<id>/question/list`)は取れるが新着は回答0〜2件が大半で、成熟した議論は検索エンジン経由(DuckDuckGo HTMLの`site:`指定)で探す必要がある。DuckDuckGo HTMLは連続問合せでHTTP 202のbot確認が出た(間隔8秒でも約半数)。Yahoo!JAPAN検索は既存調査で429、BingはHTMLの`site:`指定が実質効かなかった。

## 2. 推奨する収集手順(案)

### 手順A 候補プールの作成(API 0・自動・1日1回)
1. 一覧ページ(上記)から、サイト・URL・題名・コメント数・日時だけを取得し、`candidates_<日付>.jsonl`に追記する。本文は取らない。
2. 機械的な除外(辞書とルールのみ、LLM不使用): 芸能人名/事件名のみの題名、ニュース記事の単純転載で議論になりにくいもの、レス数が小さいもの(例: 100未満)、実況・雑談スレ。
3. 所要: 一覧5サイト×1リクエスト+間隔≒1分。

### 手順B テーマごとの深掘り(1テーマ約10分)
1. 手順Aの候補から「生活環境・経験・価値観・利害・責任の差から立場が割れそうな題名」を人(またはAgent)が選ぶ。
2. 同一テーマを別サイトで探す(知恵袋・増田・ガルちゃん・ママスタ・5chを1〜2回ずつ検索)。**同一テーマが2サイト以上で見つかるものを優先**(今回のT1・T2がこれ。単一サイト依存と1サイトの空気に偏るリスクを避ける)。
3. スレッド本文を取得し、長いコメント(例: 150字以上)だけを抜き出して閲読する(`DOMESTIC_longc_01.py`が原型。ガルちゃん形式の連番に対応)。
4. 採録する意見は、URL・投稿日時・サイト・短い抜粋・属性(本人が書いた範囲)を記録する(既存`PROVENANCE_04.md`/`SOURCE_LOG_02.md`の方式を踏襲)。`DOMESTIC_verify_excerpts_01.py`のように逐語抜粋が取得本文に存在することを機械照合する。

### 手順C 立場の割り付けとPersona(Family Yの設計思想に沿う)
- 3視点は、賛否ではなく「生活環境・経験・責任・利害」の差で決める(今回: T1=負担する嫁/見捨てられない実子/高齢当事者・制度派、T2=地方出身で東京拒否/東京育ちで地方拒否/帯同を迷う配偶者)。
- Personaは複数投稿の背景(年齢層・家族・仕事・事情)から人物像を先に組み、投稿者本人の属性・動機は断定しない。個人の発言をそのままコピーしない。
- 実在の意見が取れていない立場は【想像】と明記し、その立場だけは追加収集する(今回T4・T8・T10の「子ども」「ベテランパート」「近隣住民」は直接の声が取れていない)。

## 4. 取得手段の改善案(既存`search_01.py`の拡張案)

1. UAを自己申告にする(ブラウザ偽装・AI crawler名の詐称をしない)。今回の取得はすべてこの方式で通った。
2. サイト別アダプタを追加: ガルちゃん`/rank/`、ママスタ`/bbs/topic/category/<id>`、5ch`subback.html`、増田日別、知恵袋カテゴリ一覧。
3. robots.txtを実行前に読み、Disallowなら取得しない仕組みを入れる(既存の知恵袋`/search`・はてブ`jsonlite`はDisallow対象)。
4. 検索エンジンの問合せ間隔を8秒以上にし、202(bot確認)が出たらそのセッションを止める(再試行ループを作らない)。
5. 取得済みページのキャッシュ(`_cache_uncommitted/`)は権利上commitしない。記録は要約+短い抜粋+URL+日時のみ。

## 5. 信頼性・偏り・規約上の注意

- **発言小町は規約が自動取得・生成AI・営利・解析を禁止**し、情報解析は別途ライセンス契約を要する。ライセンスを得るか人が読む範囲に限るまでは、収集手順に含めない(判断候補)。
- 知恵袋: AI回答欄を除外する。robotsは`/search`・回答`/a`をDisallow。ベストアンサーが多数意見とは限らない。
- ガルちゃん・ママスタ・小町は女性ユーザー中心、年齢層は30〜60代が多いと見られる(未計測)。5ch・増田・価格.comは男性比率が高い傾向が見られた(印象、未計測)。Voiceの属性設計で偏りを意識する。
- 匿名掲示板は、釣り・ネタ・荒らし(今回5chで確認)・ステマ・ニュース転載による誘導が混ざる。1サイトだけに依存せず、同一テーマを2サイト以上で裏取りする。
- 人物の特定・事件・実在の芸能人が出る題材は対象外にする。個人名・ID・URLの個人情報を成果物に残さない。
- 原文の再掲はしない(短い抜粋のみ、複数の意見を材料に独自のPersonaを組み立てる)。
- 制度・数字(例: 3号年金の見通し)は投稿者の理解であり、事実確認が別途必要。
- X・Threads・Reddit・Yahoo!ニュースコメントは今回取得できていない。必要なら公式APIやライセンス、または人が読む運用の別検討(判断候補)。
