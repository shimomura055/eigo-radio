## 4. ブラインド裁定(置換: ADJUDICATION_RUBRIC_01の左右比較を、より再現的な個別採点に変更。実行前に確定)
- **単位**: 文。各文について、全条件の「最終訳」+「verify前の1回目の訳」+公開版訳(A''、生成partのみ)の**重複を除いた全異なる訳**を匿名文字(乱数seed固定の順序)で提示。方式名・費用・verify結果・出自は伏せる。前後2文の英文を理解用に添える(訳の対象ではない)。**同一文字列の訳は1つ**として採点(同じ訳=自動で同等)。fail-closed(訳None)は採点しない。
- **採点**: 0=OK / 1=軽 / 2=中 / 3=重大 + 類型(POLY/DEIX/FIG/ADD/NAT/MIX/OTHER)。重大=意味の反転・欠落・誤伝達 / 中=語選択・指示対象の誤りで意味がずれるが大筋は保持 / 軽=自然さ・小さな追加・表記。**訳語不整合(TERM)は文単位では採点せず**、記事単位指標(§5 B1(b)、M-6)で測る。MIX=翻訳対象外(文脈文)の情報が訳に入った場合(類型MIX、重大度は内容による)。迷い・割れは`exclude`。
- **改善/悪化**: 同一文の二つの訳の採点差(M<A=改善、M>A=悪化、同=同等)。**A(現行)の絶対評価は「新規生成Aに付けた採点」**(ev03公開版ラベルは参照のみ)。理由コード別集計(CTX=文脈で語義・指示対象が正しく/誤りに、MIX、NOISE)は、採点に付けた類型と、A'との差で補助的に出す。
- **M-8 規則**: (1)`exclude`は「方式に不利な扱い」(改善はexclude=同等、悪化相当はexclude=悪化)の**感度集計を必須**で併記。(2)一次裁定(実行層Sonnet、AI同系列の偏りあり)とFable再裁定が食い違った項目は**保守側**(どちらかが悪化なら悪化、改善は両方が改善と見た場合のみ)。(3)**Fable再裁定対象**=全体の10%以上(乱数抽出)+重大(採点3)全件+**合否に効く項目全部**(最終候補のA対M悪化・改善件、G1/G2判定に寄与する件、B1(a)項目)。一覧を`FABLE_REJUDGE_LIST_02.md`で出す。(4)**fail-closed欠落文**: MだけがNone(英語のみ表示)でAが表示=悪化(重大度=中)、AだけがNoneでMが表示=改善、両方None=同等。
- **観点6(3区分表)**: 条件ごとに文単位の3区分表(表示正しい=採点0〜1 / 表示誤り[重大度別: 軽・中・重大] / 非表示=fail-closed)を出す。
- **R-2 決定論の混入検査(補助指標)**: M訳に含まれるカタカナ語・数字のうち、(i)AおよびA'の同文訳に無く、(ii)対象英文に対応しない(数字は英文に無い)、(iii)同記事の他文の訳に現れる、ものを「混入候補」として検出し件数を出す。確定は裁定のMIX。
- **R-5 ノイズ補強**: A'対Aに加え、公開版(A'')対A、M対A'を集計する。**R-6**: T1はcall単位の中央値。
