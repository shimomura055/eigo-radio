# ADJUDICATION_RUBRIC_01(裁定基準。JA-GLOSS-QUALITY-ALARM-TRIAL-01にはrubricファイルが無く[Fable裁定シート方式]、本Trial用に同形式で新設。2026-10-31)

## 単文の適否(誤訳実態調査)
裁定者には**英文と訳だけ**を見せる(旗・出自・方式名・他の訳は伏せる。順序は乱数seedで混ぜる)。判定=OK / NG。NGは重大度と類型を付ける。
- 重大度: **重大**=意味の反転・欠落・誤伝達で学習者が誤解する(例: 『省かれたもの』=出しっぱなしの物の取り違え) / **中**=語選択・指示対象の誤りで意味がずれるが大筋は保持 / **軽**=訳語不整合・自然さ・表記・小さな追加。
- 類型: POLY=多義語・助動詞 / DEIX=指示語・省略主語 / FIG=比喩・句動詞 / TERM=訳語不整合(同一記事内で同じ英語表現が別の訳語) / NAT=自然さ / ADD=情報の追加・欠落。
- 判定基準は既存の対訳照合(VERIFY_HEAD)の誤り定義に**語義・訳語整合・自然さ**を加えた「人が読んで違和感なく正しいか」。基準を後から緩めない。

## 方式比較(Trial)の裁定(TRIAL_PLAN_01 §5)
各項目で、A(現行)とM(文脈方式)の訳を匿名(X/Y)・左右乱数で提示し、判定=**改善 / 同等 / 悪化** + 重大度(重大/中/軽)+ 理由コード(下記)。
- 理由コード(文脈起因か): CTX=文脈で語義・指示対象・訳語が正しく/整合した(または、文脈の影響で誤った) / MIX=翻訳対象外の情報が訳に混入 / NOISE=文脈と無関係の言い換え・揺らぎ / OTHER。
- 集計は **理由不問**(改善・悪化を全部数える)と **理由一致**(改善はCTX、悪化はMIX/CTX悪化のみ)の両方を出す。NOISEは同条件の再生成(A対A')の差として基準ノイズを測り、方式の効果から差し引く。
- 裁定者: 実行層Sonnetがブラインドで一次裁定。割れる/確信なしは`exclude`にして件数を報告(重要判断にしない)。Fableが10%以上を独立再裁定して受入評価(Trial終了時)。
