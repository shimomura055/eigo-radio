# 照合rubric (COMPARISON_RUBRIC_01) -- 判定開始前に固定

管理ID=JA-TRANSLATION-LITERALNESS-AUDIT-01 / 委任_01B / 調査④ / 2026-10-31。API 0。裁定者はLLM agent(Sonnet)自身が読んで判定(外部LLM呼出なし)。**判定開始後に本基準を変更しない**。参考=JA-GLOSS-QUALITY-ALARM-TRIAL-01/ADJUDICATION_RUBRIC_01.md(本件は「語の訳」でなく「対訳としての照合」なので類型を別定義)。

## 1. 単位と見る情報
- 単位=End Userページで英文(群)の隣に表示される日本語訳の1ブロック: story/comment/preview/oneline は ja_align の「群」(1群=英文1〜数文 ↔ 日本語の1区間)、kp_ja/gloss/vocab_meaning は語句の訳語、vocab_sentence/grammar_sentence は英文1文↔日本語訳、title は topic_en↔title_ja。
- 第1判定(blind)で見るのは `ID・訳種別・英語・日本語` のみ。見ない: ja_source・Family・Level・記事名の扱い・alignの how/conf・過去所見。順序はseed固定でシャッフル。
- 目的の物差し(ユーザー原文): 「単純な直訳」を求めない。**日本語として自然でありながら、英文の意味・情報・文構造を可能な限り保持し、学習者が英文と照合できること**。

## 2. 分類(原文§6の1〜6)
| 分類 | 定義 | 判定の目安 |
|---|---|---|
| 1 情報欠落 | 英文にある命題・修飾・数値・節・主語/目的語が日本語に無い | 1文中の節/修飾の脱落、複数文のうち1文以上が訳に現れない(統合でなく単純欠落) |
| 2 情報追加 | 日本語に、英文にない事実・主張・限定・因果・評価が入る | 前後の英文から持ち込んだ内容、独自の説明・誇張・断定の追加。文末の「〜のだ」等の語気のみは追加と数えず5(軽)。 |
| 3 要約・統合で対応消失 | 複数文が1文に要約/統合され、英文と日本語の文単位の対応が取れない | 内容は概ね含むが、英文の文数・文境界・順序・修飾関係が日本語から読み取れない(英文N文→日本語が要点のみ) |
| 4 意味・ニュアンス変化 | 語・時制・モダリティ・程度・極性・指示対象・比喩の指す意味が変わる | 肯定/否定、程度(clearly/definitely)、推量(may/seem)、主体の取り違え等。命題が真偽として変わる場合は重大。 |
| 5 自然だが対訳として不適切 | 意味はほぼ同じだが、言い換え・比喩の差替え・語順再構成・文体付加(意訳)が大きく、学習者が英語の語句/構造と対応づけにくい | 自然で読みやすいが、英単語→日本語語の対応が取れない/英文にない修辞が付く |
| 6 適切 | 意味・情報が保たれ、文(群)の対応が取れ、日本語として自然。機械的直訳である必要はない | 語順の自然な入替え・代名詞省略・「、」での連結・慣用的処理は6 |

分類は主因1つ。複数該当する場合は **重大度が高い方、同じなら 2>1>4>3>5** の順で主因を取り、副因を note に書く。

## 3. 重大度(分類1〜5に付与。6は`-`)
- **重大**: 意味の誤り(命題の真偽/極性/数値/主体が変わる)・事実情報の追加・主要命題の欠落(結論が変わる)。
- **中**: 対応消失(分類3)・情報欠落(分類1で命題の一部)・文単位で対応が取れない。
- **軽**: ニュアンス差・意訳・文体付加・比喩の差替えだけで命題は同じ。
- 問題率の二重定義: **問題(広義)=分類1〜5すべて**、**問題(中以上)=重大+中**。

## 4. 訳種別ごとの補則
- **kp_ja / gloss / vocab_meaning**(語句の訳語): 本文中の意味として妥当な短い訳語ならば6。定義文化・辞書第一義へのずれ・別義は4。英語の語義の一部のみは1。
- **vocab_sentence / grammar_sentence**(英文1文↔訳): 文単位の訳としての照合。英文末の句読点欠落(表示崩れ)は無視。
- **title**: 英題と日本語題は別言語タイトル(topic_enはAdv/Std共通の英題)。内容が同じならば6、題の意味が変われば4。
- **oneline / comment / preview(Adv)**: 英文N文↔日本語の群。文数を統合したら3。
- 群の日本語区間が隣接群の英文の訳である(alignのずれ)場合も、**表示された組合せとして**分類し、note に `shift` と書く(Production表示の事実を優先)。
- 日本語のみの部分(Stdのpreview/comment/jtitle等、英語対が無いもの)は対象外(棚卸しで別掲)。

## 5. 出力形式
`id|分類(1-6)|重大度(重大/中/軽/-)|note(第1判定のみ。第2判定では書かない)`
