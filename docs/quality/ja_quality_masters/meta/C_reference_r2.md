その電話、AIに頼んだはずなのに、受話器の向こうは人でした

AIに「この電話、お願い」と頼んだら、電話口に出るのはAI、と思いきや、実際に用件を片づけていたのは人間だった。そんな、ちょっとした“配役変更”がMetaのMuseをめぐって起きていた。

Metaは、Museを通じてかける電話の一部を、人間に引き継ぐテストを実施。依頼を受け取ったのは訓練を受けた契約スタッフで、電話をかけ、相手とのやり取りを終えるところまで担当していたという。AIが依頼を受け、スタッフが電話をする。舞台裏ならともかく、頼んだ側には「え、あなたが電話してくれるの？」という驚きがありそうだ。

もちろん、人間が助けに入ること自体は、悪い話とは限らない。AIが困ったときに人が引き継いでくれるなら、むしろ頼もしい。自動運転の車に補助ブレーキがあるようなもの、と言いたいところだが、今回はその仕組みを先に知らされていたか、という話でもある。

Metaの担当部門の副社長は、契約スタッフが電話をかけることをきちんと知らせないままテストを始めたのは「ミス」だったと、社内向けの投稿で認めた。さらに、人間に電話を任せる機能は当面引っ込めたと説明している。便利さの実験が、いつのまにか「その説明、ありましたっけ？」の確認テストになったわけだ。

ここで問われるのは、「AIと人間、どちらが上手に電話できるか」だけではない。誰が担当するかも、頼む側が知っておきたい情報なのではないか。人が関わるなら安心する人もいれば、先にひと言ほしい人もいる。どちらが正解というより、知ったうえで選べることが大事だ。

人間が助けることと、その事実を伝えることは、別の話。AIに頼んだつもりだったのに、実は人が電話していたと知れば、受け止め方は変わるかもしれない。

次にAIが「できました」と言ったら、成果だけでなく名札も確かめたい。「担当者は誰ですか？」便利さの裏側に、その一問。案外、いちばん人間らしい確認かもしれない。
