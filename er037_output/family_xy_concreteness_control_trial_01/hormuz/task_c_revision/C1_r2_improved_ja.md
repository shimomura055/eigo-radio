# 「20％」は消えた。なのに原油は、何事もなかったように高値へ戻った

相場が、いったんブレーキを踏んだ。

だが次の瞬間には、何事もなかったかのようにアクセルを踏み直した。

そんな動きを見せたのが、今回の原油市場です。

発端は7月13日。トランプ氏は、米国がホルムズ海峡の安全を守るために負担している費用を返してもらう名目で、海峡を通るすべての貨物に20％を求めると投稿しました。

「20％」。

数字だけを見ても、かなり強烈です。ニュースの見出しとしては、十分すぎるほど目立ちます。

ただし、この時点では肝心の設計図がありませんでした。

誰が払うのか。どうやって徴収するのか。どんな法的根拠があるのか。

細かな仕組みは示されないまま、まず大きな数字だけが市場に飛び込んできた格好です。いわば、料金表だけが先に掲げられ、受付も支払い方法もまだ決まっていない状態でした。

ところが、約25時間後の7月14日。

トランプ氏は、その「20％の償還料」案を、湾岸諸国による対米貿易・投資案件に置き換えると発表しました。背景には、中東の指導者たちとの「非常に生産的な協議」があったと説明しています。

さらに記者団には、ホルムズ海峡を通る船に誰も料金を課すべきではない、そもそも料金という考え方を好まない、という考えも示しました。

前日は「20％」。

翌日は「料金は好まない」。

方向転換としては、かなり大きいものです。

普通に考えれば、ここで原油価格も勢いを失いそうです。追加コストへの警戒が後退し、政策リスクも薄まる。ならば価格も下がる――。そんな筋書きが浮かびます。

実際、発表直後のBrent原油先物は、上げ幅を一時的に縮めました。

相場も一瞬、「これは材料が消えたのか」と立ち止まったように見えます。

しかし、その時間は長くありませんでした。

Brentはほどなく、発表前に近い高い水準へ復帰。報道時点では前日比約2.6％高の1バレル85ドル超でした。その日の清算値も84.73ドル。前日より1.7％高となりました。

20％案は消えた。

それでも、原油は高値に戻った。

まるで相場が一度だけ急ブレーキを踏み、後続車の様子を確認したあと、何事もなかったように走り出したかのようです。

なぜか。

20％の料金案が撤回されても、米国とイランの間の攻撃、海上封鎖、タンカーの安全をめぐる懸念まで消えたわけではないからです。

その不安は、前日からすでに価格に表れていました。

7月13日、Brentは9.59％上昇し、83.30ドルで清算されました。Reutersはこの値上がりについて、海上封鎖やエネルギー輸送への懸念と結び付けて報じています。

つまり、今回の原油相場を押し上げていた材料は、「20％」だけではなかったということです。

派手な政策案がひとつ消えても、その背後にある安全保障上の不安や、エネルギー輸送が滞るかもしれないという恐怖までは消えない。

市場は、その違いをかなり正直に映しました。

政策の撤回が無意味だったわけではありません。発表直後、実際に値動きは鈍りました。

ただ、相場が見ていたのは、ニュースの一番目立つ数字だけではなかった。

「20％」が消えたあとも、ホルムズ海峡をめぐる不安は残っている。

原油価格は、まるでそう言うように、静かに、そしてしれっと高値へ戻っていきました。
