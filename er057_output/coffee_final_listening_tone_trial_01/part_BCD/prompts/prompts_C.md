# Prompt一覧 C: Key Phrase日本語意味(Standard・Aoede)

送信方式: `generate_content`、`Part(text=<原稿逐語>, speech_metadata=SpeechMetadata(style=<下記style>))`、model=`gemini-3.8-flash-lite-tts`、voice=`Aoede`、language_code=ja-JP(Production同一)、Standard同期(DEV)。

原稿(逐語、tts_safe後): `焙煎する前のコーヒー豆` / `値段を引き上げる` / `時間がかかる` / `すぐに` / `定期的に`

## Baseline(現行Production Style = JA_J2_BRIGHT、逐語)

```
明るく、温かみのある親しみやすい話し方で。聞き手に楽しく語りかけるように、自然な抑揚と軽やかなリズムをつけてください。ニュース番組としての明瞭さを保ち、演技がかった話し方は避けてください。
```

## M1 語尾を上げず自然に言い切る(K1対応)

style(逐語):

```
短い言葉の意味を伝える自然な話し言葉で。語尾を上げず、自然に音程を下げて言い切ってください。明るさは保ちつつ、演技がかった話し方は避けてください。
```

## M2 ひとまとまりの意味として滑らかに(K2対応)

style(逐語):

```
一つの意味のまとまりとして、途切れさせずに滑らかに、ひと息で読んでください。単語ごとに区切らず、抑揚の上下も小さく自然にしてください。
```

## M3 落ち着いて穏やかに終える(K3対応)

style(逐語):

```
落ち着いた穏やかな声で、文のように大げさに読まず、短い言葉として静かに言い終えてください。終わりで声が持ち上がらないようにしてください。
```

## M4 淡々とした辞書の意味説明(K4対応)

style(逐語):

```
辞書の意味の説明を読むように、淡々と自然に。特定の語を強調せず、抑揚も控えめにしてください。ただし暗くならず、聞き取りやすい声で。
```

## M5 学習者向けの明瞭さ(K5対応)

style(逐語):

```
日本語学習者や英語学習者にも聞き取りやすいよう、一語一語の発音をはっきり、標準的な速さで読んでください。語尾は自然に収め、上げすぎないでください。
```
