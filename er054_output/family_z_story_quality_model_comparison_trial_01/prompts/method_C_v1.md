# 方式C v1: Story魅力重視(4軸: 引き込み/展開/余韻/独自性)

目的: 「物語として面白いか」を直接数値化する。短編化適性は含めない(別方式Dで評価)。軸は必要最小限の4つ。
## DEVELOPER_ADDENDUM
評価は4項目(hook, development, aftertaste, originality)それぞれ1〜5の整数で採点する。5=非常に優れる、4=優れる、3=標準的、2=弱い、1=ほぼ満たさない。
本文が示す通りに採点し、差を付ける必要も、高得点・低得点を避ける必要もない。英語短編への再話しやすさは考慮せず、原作そのものの物語としての魅力だけを評価する。
各項目に本文からの根拠引用(1〜2個)と日本語の理由(2〜3文)を付ける。overallは総合1〜5点(平均の機械的な丸めでなくてよい)。

## USER_CRITERIA
[方式C: 物語としての魅力を4軸×1〜5点で採点]
hook(引き込み): 冒頭から読者を引き込み、読み進めさせる力(状況設定・謎・緊張・人物の魅力・語りの面白さ)。5=強く引き込まれる / 3=普通 / 1=ほぼ引き込まれない。
development(展開): 出来事・関係・認識が動き、読み進めるほど状況が変わる力。5=展開が巧みで意外性や必然性がある / 3=展開はあるが平板 / 1=ほぼ動きがない。
aftertaste(余韻): 読後に残る感情・解釈・問いの強さ。5=強く長く残る / 3=少し残る / 1=ほぼ残らない。
originality(独自性): 発想・視点・状況・表現が他の物語と区別できる独自さ。5=際立って独自 / 3=よくある型に独自の工夫が少しある / 1=ありふれている。

[手順]
1. key_facts に中心事件・主要人物・転換点・結末を書く(自分の言葉でよい)。
2. 4項目を採点する(score, evidence_quotes, reason)。
3. memorable_point: この作品で最も印象に残る点を日本語1文で書く。
4. overall(score, comment)を書く。
5. 出力はJSONのみ。
