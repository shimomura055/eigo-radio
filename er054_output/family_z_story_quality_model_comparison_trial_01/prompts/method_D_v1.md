# 方式D v1: 短編化適性重視(280〜420語で原作の魅力を再現できるか)

目的: 英語短編(280〜420語、A2〜B1)への再話素材として使えるかを重点評価する。「縮めたら何が失われるか」を明示させる。
## DEVELOPER_ADDENDUM
評価は4項目(extractability, loss_severity, reproducibility, style_independence)それぞれ1〜5の整数で採点する。**すべて高いほど再話に適する**向きに統一する。5=非常に適する、3=標準的、1=ほぼ適さない。
本文が示す通りに採点し、差を付ける必要も、高得点・低得点を避ける必要もない。この方式では原作の物語的な魅力そのものの高低は問わず、280〜420語の英語短編へ再話したときに原作の魅力がどれだけ残るかを評価する。
各項目に本文からの根拠引用(1〜2個)と日本語の理由(2〜3文)を付ける。overallは総合1〜5点(平均の機械的な丸めでなくてよい)。

## USER_CRITERIA
[方式D: 短編化適性を4軸×1〜5点で採点し、短縮で失われるものを明示する]
extractability(中核事件の抽出可能性): 1〜2文で言える中核事件・変化を本文から抜き出せるか。5=中核が明確で他の部分を削っても成立する / 3=抜き出せるが周辺に依存 / 1=中核が特定しにくい。
loss_severity(失われる要素の重大度の低さ): 短縮で失われる要素が作品の魅力にとって致命的か。5=失われるものは軽微 / 3=重要な要素が一部失われる / 1=魅力の中心が失われる(高いほど損失が小さい)。
reproducibility(280〜420語での再現可能性): 登場人物・場面・展開を280〜420語に収めて、読み物として成立する形に再現できるか。5=無理なく収まる / 3=大幅な取捨選択が必要 / 1=収めるとほぼ別物になる。
style_independence(語り手・文体依存の低さ): 魅力が文体・語り口・長い描写・心理描写・語彙に依存せず、英語A2〜B1の平易な再話でも保てるか。5=依存が低い / 3=一部依存 / 1=文体そのものが魅力の中心(高いほど依存が低い)。

[手順]
1. key_facts に中心事件・主要人物・転換点・結末を書く(自分の言葉でよい)。
2. 4項目を採点する(score, evidence_quotes, reason)。
3. lost_in_compression: 280〜420語へ縮めると失われる要素を最大6個、各severity(low/medium/high)付きで列挙する。失われるものがなければ空配列。
4. must_keep: 再話で必ず残すべき要素を1〜5個。
5. retelling_sketch: 再話の骨子を3〜6個の短い箇条(日本語)で書く。
6. overall(score, comment)を書く。
7. 出力はJSONのみ。
