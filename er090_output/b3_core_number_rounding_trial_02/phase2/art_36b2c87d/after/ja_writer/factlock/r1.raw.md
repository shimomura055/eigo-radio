# ブロードコム決算、見逃せないのは「本編のあと」

映画館で、本編が終わっても席を立てないことがある。次回作の予告が始まり、「えっ、その先どうなるの？」と引き戻されるからだ。ブロードコムの決算も、そんな読み方をすると面白い。今回の成績を確認したら、そのまま次の四半期の「予告編」まで見ていこう。

まずは本編。発表された四半期の会社全体の売上高は、295億9,100万ドルだった。これが、すでに売れた金額を示す成績表。大きな数字だが、ここで「なるほど」と資料を閉じるのは、まだ早い。

続いて会社が示したのは、次の四半期の会社全体の売上高が約348億ドルになるという見通しだ。実績の295億9,100万ドルから、次は約348億ドルへ。数字を二つ並べるだけで、話は「どうだった？」から「次はどうなる？」に切り替わる。

そこで登場するのが、AI半導体だ。売上高は167億ドル。ただし、ここは字幕を読み飛ばしてはいけない。295億9,100万ドルは会社全体、167億ドルはAI半導体についての数字。別々の売上として足し算するのではなく、全体とその中のAIを分けて見るのが大事だ。

さらに、予告編のナレーション役ともいえるCEOの発言が続く。顧客に合わせて作るAI半導体や、ネットワーク関連の製品への需要は、引き続き非常に強いという。金額だけでは見えてこない、会社側の手応えが伝わる言葉ではある。

ただし、ここで期待のBGMを最大音量にするのは待ちたい。「非常に強い」は、同社のトップによる評価だ。需要についてのその言葉と、実際に計上された売上高は、同じ種類の情報ではない。

約348億ドルという数字にも、「会社の見通し」という札を付けておこう。すでに売れた金額ではなく、実際の結果は違う可能性がある。予告編で名場面が続いたからといって、本編の出来まで確定したわけではないのだ。

ふだんの買い物に置き換えれば、「この商品、よく売れました」と「次も売れそうです」は別の話。どちらも店を知る材料になるけれど、受け止め方まで同じにはしない。その感覚で読むと、決算もぐっと身近になる。
