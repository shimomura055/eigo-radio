# AIの決算劇場、「売れた！」の次は「売れそう！」

AIのニュースを聞くたび、「それで、私の残業は何分減るの？」と思うあなたへ。今回は便利な使い方ではなく、売り場の裏側へご案内。主役は、AIを支える半導体などを売るブロードコムだ。電卓を片手に、決算劇場の幕を開けよう。

まず登場するのは、会社全体の売上高295億9,100万ドル。そのうち、AI半導体の売上高は167億ドルだった。桁が大きすぎて、財布の中のポイントカードが急に無口になる。でも、本日の見どころは「大金ですね」で終わらない。

CEOの説明によると、AI半導体の売上高は前の四半期から54％増えた。単に「売れました」ではない。「前の回より、かなり売れました」なのだ。成績表を受け取ったら、裏面にも大きな花丸があったような勢いである。

売る側の手応えも強い。CEOは、顧客に合わせて作るAI半導体と、ネットワーク関連製品への需要が、引き続き非常に強いと説明した。ここで勢いよく「AI市場、全面絶好調！」と叫びたくなるが、いったんマイクを置こう。これは、あくまで同社の製品に対する説明だ。

さて、舞台は第二幕へ。会社は次の四半期の全体の売上高を、約348億ドルと見込んでいる。さっきまで見ていたのは「売れた」という実績。ここからは「売れそう」という見通しだ。似た顔で登場するが、役柄は違う。

しかも、この348億ドルはAI半導体だけの数字ではない。会社全体の売上高の見通しである。ここを取り違えると、脇役まで全員まとめて主役だと思い込むようなもの。数字の大きさに驚く前に、名札を確認したい。

さらに、見通しはまだ実績ではない。会社も、実際の結果は見通しと大きく違う可能性があるとしている。予告編がどれほど景気よくても、本編の興行成績まで決まったわけではない。「期待できそう」と「達成しました」の間には、ちゃんと時間が流れている。

だから面白い。すでに売れた数字には、結果としての重みがある。一方、次にどれだけ売れると考えているかには、売る側の期待がにじむ。両方読むと、決算は過去の採点表であり、未来に向けた作戦会議の窓にもなる。ただし、席は分けておこう。

AIを見るとき、「何ができる？」に加えて、「支えるものは売れている？」と聞いてみる。未来を当てる占いではない。実績にはうなずき、見通しには少し身を乗り出す。そのくらいの距離感で眺めると、巨大な数字にも、人間くさいドラマが見えてくる。
