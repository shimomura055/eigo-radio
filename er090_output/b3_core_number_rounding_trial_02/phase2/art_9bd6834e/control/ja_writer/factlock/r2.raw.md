# 請求書は撤回、海の不安は据え置き

20％の支払いを求める提案が、取り下げられた。ならば「原油もお安く？」と期待したくなる。ところが相場は、簡単にはうなずかなかった。いったん上げ幅を縮めたのに、また高い水準へ。値札の裏には、まだ別の問題が隠れていた。

発端は、トランプ大統領の投稿だ。ホルムズ海峡を通るすべての貨物に、20％の支払いを求めるという。米国が海峡の安全を守るためにかかる費用を、返してもらう。いわば「警備代のご負担を」という提案だった。

同日、原油の国際的な目安となるブレント先物は9.59％上昇。ここで「20％の料金に市場が仰天！」と見出しを打ちたくなるが、ちょっと待った。数字が目立つからといって、それだけで筋書きは決まらない。

ロイターが上昇と結びつけて伝えたのは、翌日に予定されていた米国の対イラン海上封鎖と、ホルムズ海峡を通るエネルギー輸送への懸念だ。「いくら払うか」だけでなく、「そもそも安全に運べるのか」という難問が横たわっていた。

翌日、トランプ氏は方針を変更。20％の料金を、湾岸諸国による米国との貿易や、米国への投資の案件に置き換えると発表した。貨物に支払いを求める提案は取り下げに。請求書から、あの「20％」が消えたわけだ。

ここで相場も拍手喝采、原油安へ一直線――とはいかなかった。発表後、ブレント先物はいったん上げ幅を縮めたものの、ほどなく発表前に近い高い水準へ戻った。料金撤回だけでは、値下がりは続かなかった。

米国とイランの間の攻撃や海上封鎖、タンカーの安全をめぐる心配は、発表後も残っていた。料金の話が退場しても、海の不安まで一緒に席を立ってはくれない。

ネット通販なら、こうだ。「送料の件は解決しました。ただ、荷物が無事に届くかは心配です」。それでは、ほっとする前に配送状況を何度も確認したくなる。支払いの問題と、輸送の問題は別なのである。

今回、派手な主役に見えたのは「20％」。だが市場につきまとったのは、その先を進む船への心配だったのかもしれない。請求書は書き換えられる。でも、それだけで海に「安全です」の札は立たない。
