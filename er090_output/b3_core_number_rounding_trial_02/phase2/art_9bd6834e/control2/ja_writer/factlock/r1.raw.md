# 請求書は変わった。でも、タンカーの不安は消えない

追加料金の話がなくなれば、値段も落ち着く。お財布の感覚では、そう考えたくなる。ところが今回の原油市場は、そんな素直な筋書きに乗ってくれなかった。お金の話は変わったのに、原油は高いまま。いったい、何が引っかかっていたのか。

発端は、トランプ大統領の投稿だ。ホルムズ海峡を通るすべての貨物に、20％の支払いを求めるという。米国が海峡の安全を守るためにかかる費用を、返してもらおうという提案だった。運ぶ側には、気になる「追加の請求書」だ。

同じ日、ブレント原油の先物価格は9.59％上昇した。数字だけ見れば、追加請求に市場がびっくりしたようにも見える。ただし、ここで原因を一つに絞るのは早い。値札の横には、もう一つ、見逃せない問題があった。

ロイターは、この上昇を、米国によるイランへの海上封鎖の方針や、ホルムズ海峡を通るエネルギー輸送への懸念と結びつけて報じていた。いくら払うのか。それ以前に、そもそも船は安全に通れるのか、という心配だ。

翌日、話は動く。トランプ氏は20％の支払いを、湾岸諸国による米国との貿易や、米国への投資の計画に置き換えると発表した。貨物にお金を求める話から、別の取引の話へ。これなら原油価格もひと息つくだろうか。

実際、ブレント先物は発表後、いったん値上がり幅を縮めた。ただし、「値上がり幅が縮む」と「全面的に値下がりする」は別の話だ。しかも、ほどなく発表前に近い高い水準へ戻った。安くなる展開を期待しても、そうすんなりとは進まなかった。

なぜなのか。発表後も、米国とイランの攻撃、海上封鎖、タンカーの安全への心配は続いていた。請求の仕組みが変わっても、航路の不安まで一緒に消えるわけではなかったのだ。

身近なたとえなら、配送の追加料金がなくなっても、荷物が無事に届くか心配なら、手放しでは喜べない。料金の問題と、届けられるかどうかの問題は、似ているようで別物。今回の原油も、その二つを分けて見ると、値動きの見え方が変わってくる。

「追加のお金の話がなくなったのに、なぜ高い？」。その疑問の先で確かめたいのは、発表の言葉だけではない。請求書の向こう側で、タンカーは安心して進めるのか。お金の話が一段落しても、海の心配はまだ残っていた。
