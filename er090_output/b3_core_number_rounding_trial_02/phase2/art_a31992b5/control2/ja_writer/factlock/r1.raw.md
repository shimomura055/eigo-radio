# 給料が上がると、まじめになる？ 比べる相手は「いつもの自分」

給料明細を開いて、ため息。「もっとまじめに働けば、数字も変わるのかな」。そんなとき、頭の中で始まりがちなのが、同僚との勝手なランキング大会だ。でも、今回の研究を読むなら、その大会はいったん中止。注目する相手は隣の誰かではなく、「いつもの自分」である。

研究チームは11件の調査をまとめ、働いている人の性格と、仕事から得る収入のデータを分析した。分析ごとに人数は異なるが、最大で134,515人。なかなかの大所帯だ。

ただし、見どころは人数の迫力だけではない。研究では、収入と性格を３回以上測った調査を使い、もともとの人と人との差と、同じ人の中で起きる変化を分けて調べた。いわば、「あの人はずっと高収入」と「私はいつもより高収入」を、別々の引き出しにしまう作戦だ。似た話に見えて、ここを混ぜると話が違ってくる。

そこで登場するのが、物事にきちんと取り組む傾向を示す「勤勉性」。同じ人の変化を見ると、収入が普段より高いことは、その後の勤勉性が高いことと、小さく結びついていた。逆方向も同様で、勤勉性が普段より高いことは、その後の収入が高いことと、小さく結びついていた。

お金とまじめさ、まさかの二人三脚？

……と盛り上がる前に、ここで一度、待ったの笛を吹きたい。見えたのは小さな結びつきであって、「収入アップでまじめ人間に変身！」という法則ではない。もちろん、「まじめになれば給料アップ確定！」という攻略本でもない。

先に起きたことが、後のことの原因とは限らない。この分析だけでは、「お金が増えたから、まじめになった」とも、その逆とも言い切れない。収入と性格の両方に関わる、別の要因がある可能性も残っている。時間の順番が分かることと、理由が分かることは、別の話なのだ。

だから、給料明細をそのまま「性格の成績表」にするのは、ちょっと待とう。数字を見て「自分はまじめさが足りない」と採点する前に、比べ方そのものを点検してみる。誰かとの順位ではなく、いつもの自分から、どう動いたか。この研究の面白さは、収入を上げる必勝法よりも、そんな「ものさしの持ち替え」にあるのかもしれない。
