# 給料が上がると、まじめスイッチも入る？ 比べる相手は「いつもの自分」

給料明細を開く。数字を見る。そっと閉じる。「もっとまじめに働けば、ここも増えるのか？」。つい始まる、同僚との脳内ランキング大会。でも今回、その開催はいったん見送りだ。主役は隣のエース社員ではなく、「いつもの自分」である。

研究チームが分析したのは、働く人の性格と、仕事から得る収入に関する11件の調査。分析によって人数は異なるが、最大で134,515人だ。なかなかの大所帯である。

ただし、本当の見どころは人数より「分け方」。収入と性格を３回以上測った調査を使い、もともとの人と人との差と、同じ人の中で起きる変化を切り分けた。「あの人はずっと高収入」と「私はいつもより高収入」は、似ているようで別の話。同じ鍋で煮込まないのがポイントだ。

ここで注目するのが、物事にきちんと取り組む傾向を表す「勤勉性」。同じ人の変化を見ると、収入が普段より高いことは、その後の勤勉性が高いことと、小さく結びついていた。逆に、勤勉性が普段より高いことも、その後の収入が高いことと、小さく結びついていた。

お金とまじめさ、まさかの相互応援団？　給料明細が心のネクタイまで締めてくれる……と、話を進めるのは早い。見えたのは、あくまで小さな結びつき。「昇給すればまじめになる」でも「まじめになれば昇給確定」でもない。

先に起きたからといって、後のことの原因とは限らない。この分析だけでは、収入が勤勉性を変えたとも、その逆とも言い切れない。両方に関わる別の要因がある可能性も残る。時間の順番は分かっても、その舞台裏まで全部見えたわけではないのだ。

だから、給料明細を「性格の成績表」にするのはやめておこう。数字を見て「自分はまじめさ不足」と赤ペンを入れる前に、ものさしを持ち替えてみる。誰かとの順位ではなく、いつもの自分からどう動いたか。今回の研究がくれるのは、給料アップの裏技よりも、そんな比べ方のヒントなのかもしれない。
