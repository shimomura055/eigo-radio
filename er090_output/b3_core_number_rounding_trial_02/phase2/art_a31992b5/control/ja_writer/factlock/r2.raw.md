# 「稼げる性格」選手権、いったん中止！ 主役は“過去のあなた”

「稼ぐ人って、結局どんな性格？」。まじめな努力家か、顔の広い社交家か。始まりました、脳内「稼げる性格」選手権！……と、盛り上がる前に、ひと言。今回スポットライトを当てたいのは、隣の成功者ではありません。“過去のあなた”です。

研究チームがまとめたのは、同じ人を追跡した11件の研究データ。対象は、働いていて、性格と仕事からの収入を回答した人たちです。分析に含まれた人数は最大134,515人。ただし、調べる内容によって人数は異なります。

この研究、カメラの向きがちょっと違います。「あの人は、もともと収入が高い」という人それぞれの安定した違いと、「自分の収入が、前より増えた」という同じ人の中の変化を分けて分析。集合写真の立ち位置比べだけでなく、一人ひとりの連続写真も見よう、というわけです。

そこで登場するのが「勤勉性」。まじめに物事に取り組む性格です。同じ人の中で見ると、収入が増えることと、その後に勤勉性が高まることには、小さな関連がありました。さらに逆向きにも、勤勉性が高まることと、その後に収入が増えることに、小さな関連が見られました。

おっと、矢印が両方向に！ では「まじめになれば、お財布も育つ」？ ここで成功法則の看板を出すのは、まだ早い。関連は小さく、原因と結果が確定したわけでもありません。

「収入が増えたから、まじめになった」とも、「まじめになったから、収入が増えた」とも断言できないのです。別の何かが、両方に関わっている可能性もあります。「その後に起きた」と「それが原因で起きた」の間には、飛び越えてはいけない溝があります。

それでも、この視点は面白い。「私はこういう性格だから」で話を終えず、収入と性格を、同じ人の中で動くものとして眺められる。他人の“稼げるキャラ”を探すのとは、違う景色が見えてきます。

今回の持ち帰り品は、収入アップの必勝マニュアルではなく、自分を見るカメラの切り替えスイッチ。「あの人はいくら？」をひと休みして、「あの頃の自分と、今の自分はどう違う？」。さて、あなたの連続写真には、どんな変化が写っているでしょう。
