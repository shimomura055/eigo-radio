# 石を5分見たら、他人の50セントが危ない？

画面には石。しゃべらない。事件も起きない。マジシャンが登場してハトを出すこともない。それを、ただ5分間見る。「そろそろ何か起きる？」――いいえ、石です。

これは、米国で参加者を集めたオンライン実験の一場面だ。参加者は無作為にグループに分けられ、退屈する条件では石の動画を、比較する条件ではマジシャンの動画を5分見るなどした。

研究の問いは、「退屈すると、人は意地悪になるのか」。ただし、この話の隠れた主役は、石でも性格でもない。目の前の「選択メニュー」である。

ある実験では、動画を見ながら、別の参加者の報酬を減らす、増やす、何もしない、の三つを選べた。金額は10セント刻みで、最大50セント。いわば「ちょっと意地悪」「ちょっと親切」「現状維持」の三択だ。石は何もしないが、こちらには、できることがある。

ここで関係したのが、他人を苦しめることを楽しむ傾向、「サディズム」だった。研究者の分析では、この傾向が高い人は、退屈する条件で報酬を減らす行動が増えた。一方、低い人には、その増加は認められなかった。

なるほど、性格の問題か。……と思ったところで、話はもう一段ひねられる。

別の実験では、「報酬を増やす」が選べなかった。できるのは、減らすか、減らさないか。すると今度は、サディズムの高低にかかわらず、退屈する条件で報酬を減らす行動が増えたのだ。

おや、性格だけでは話が終わらない。「誰が退屈したか」に加えて、「退屈した人に、何ができたか」も気になってくる。

ただし、ここで「親切のボタンを設置すれば、世界は平和！」と駆け出すのは早い。二つは別々の実験なので、結果の違いが選択肢だけによるとは言えない。調べたのも、短時間の退屈と、オンラインで他人の報酬を減らす行動だ。日常の意地悪全般や、長く続く退屈に、そのまま当てはめることはできない。

それでも、暇つぶしを見る目は変わりそうだ。「あの人は意地悪だから」で話を閉じる前に、その場のメニューをのぞいてみる。暇な人に並んでいるのは、どんな選択肢だろう。

石は最後まで何もしていない。なのに、人間のほうから、なかなか厄介で面白い問いが出てきた。
