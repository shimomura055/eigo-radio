# 暇だ。さて、誰かの報酬をどうする？

何も起きない石の動画を、5分間。ただ見る。マジシャンも登場しないし、石が突然しゃべりだすわけでもない。……さて、あなたなら何をしたくなるだろう。

これは、米国で参加者を集めたオンライン実験の一場面だ。参加者は無作為にグループに分けられ、退屈する条件では石の動画を5分見た。比較するグループでは、マジシャンの動画を5分見るなどした。

退屈すると、人は意地悪になるのか。気になる問いだ。でも、今回の結果で面白いのは、性格だけでなく、目の前の「選択メニュー」にも目が向くところだ。

ある実験では、動画を見ながら、別の参加者の報酬を減らすことも、増やすことも、何もしないことも選べた。金額は10セント刻み、最大50セント。つまり、「ちょっと意地悪」「ちょっと親切」「何もしない」が並んでいたわけだ。

ここで関係したのが、他人を苦しめることを楽しむ傾向、「サディズム」だ。研究者の分析では、この傾向が高い人は、退屈する条件で報酬を減らす行動が増えた。一方、低い人には、その増加は認められなかった。

では、メニューから「増やす」を消したら？

別の実験では、報酬を増やす選択肢がなく、減らすかどうかを選んだ。すると、こちらではサディズムの高低にかかわらず、退屈する条件で報酬を減らす行動が増えた。

おや。見ておくべきなのは、「どんな人か」だけではなさそうだ。「その人の前に、何が並んでいたか」も、見逃したくない。

ただし、ここで「親切のボタンを置けば、意地悪は防げる！」と結論づけるのは早い。別々の実験なので、選択肢の違いだけが原因だとは言えない。調べたのも、短時間の退屈と、オンラインで他人の報酬を減らす行動だ。日常の意地悪全般や、長く続く退屈にも同じことが言えるかは分からない。

それでも、暇つぶしを見る目は少し変わる。「何をしたい？」だけでなく、「何が選べる？」。性格のせい、と片づける前に、まずは選択メニューをのぞいてみたい。退屈な石の動画から、案外、退屈ではない問いが転がり出てきた。
