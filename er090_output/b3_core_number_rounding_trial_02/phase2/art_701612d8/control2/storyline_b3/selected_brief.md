# Selected Fact Brief

## Storyline
2021年の二つの無作為割付実験では、短時間の退屈による他者の報酬減額の増加は、増額も選べる課題では特性サディズムが高い参加者でのみ認められ、増額できない別の課題では特性の高低にかかわらず認められた。

## Selected Facts
【F05：増額も選べる実験】Study 7は米国MTurk参加者634人のオンライン実験。無作為割付により、退屈条件では何も起きない石の動画、対照条件ではマジシャンの動画を各5分間視聴した。視聴中、別の参加者の報酬を10セント刻みで最大50セント減らす、増やす、または何もしない選択ができた。著者らの分析では、退屈条件による報酬破壊の増加は特性サディズムが高い参加者で認められ、低い参加者では条件間の差は有意でなかった。

【F06：増額できない実験】Study 8は米国MTurk参加者1,332人を、石の5分動画、マジシャンの5分動画、動画視聴前に選択する対照条件の3条件に無作為割付したオンライン実験。他者の報酬は10セント刻みで最大50セント減らせたが、増額の選択肢はなかった。著者らは、退屈条件では対照条件より報酬を減らす可能性が高く、特性サディズムの高低にかかわらず報酬破壊が増加したと報告した。

【Writerへの解釈上の制約】因果表現は、各実験の短時間の退屈操作と報酬減額行動に限定する。二つは別々の実験であり、その対照だけから『増額の選択肢をなくしたことが結果の違いを生んだ』とは断定しない。低特性群で有意差がなかったことを、効果が完全にない証明とはしない。人への身体的暴力や日常生活全般の攻撃性に一般化しない。著者らは、短時間の実験的誘発から長時間・継続的な退屈の効果は推定できないと述べている。未確認の心理的機序や将来予測は加えない。
