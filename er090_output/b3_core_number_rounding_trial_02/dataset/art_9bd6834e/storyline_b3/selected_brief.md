# Selected Fact Brief

## Storyline
トランプ大統領がホルムズ海峡を通るすべての貨物への20％償還を提案した後、7月13日のBrent上昇は米国の対イラン海上封鎖とホルムズ海峡のエネルギー輸送懸念に関連付けられ、翌14日の置換発表後も価格は一時的に上げ幅を縮めただけで、攻撃・封鎖・タンカー安全上の懸念が続く中、発表前に近い高い水準へ戻った。

## Selected Facts
- 7月13日午前10時16分（米東部夏時間）、ドナルド・トランプ米大統領は、米国がホルムズ海峡の安全確保に要する費用について、同海峡を通るすべての貨物に20％の率で償還を求めると投稿した。投稿は手続きと体制づくりを直ちに開始するとした。
- Brent原油先物は7月13日に7.29ドル、9.59％上昇し、1バレル83.30ドルで清算された。Reutersはこの上昇を、翌日に始まる予定とされた米国の対イラン海上封鎖と、ホルムズ海峡を通るエネルギー輸送への懸念に関連付けた。7月13日の上昇全体を20％料だけが原因とは断定しない。
- トランプ大統領は7月14日午前11時4分（米東部夏時間）、20％の米国償還料を、湾岸諸国による対米貿易・投資案件に置き換えると投稿した。
- Yahoo Financeは、7月14日の撤回・投資案件への置換発表後、Brent先物が一時的に上げ幅を縮小したものの、ほどなく発表前に近い高い水準へ戻ったと報じた。記事掲載時点ではBrent先物は約2.6％高で、1バレル85ドルを上回っていた。撤回発表以外にも、米・イラン間の攻撃、海上封鎖、タンカー安全上の懸念が継続していた。
