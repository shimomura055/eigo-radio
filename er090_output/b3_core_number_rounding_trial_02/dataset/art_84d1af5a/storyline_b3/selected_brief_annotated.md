# Selected Fact Brief

## Storyline
米空軍長官が2026年9月【周辺数値】、敵対的な相手の行動から統合軍を守るため米国が軌道上のspace control weaponsを配備していると初めて公認したことを軸に、米側のロシア対衛星能力評価を関連する脅威認識として示しつつ、counterspaceは軌道・通信リンク・地上を含む広い概念で、実際の攻撃や具体的システムまで確認されたわけではないと整理する。

## Selected Facts
- 【事実1】2026年9月14日【中核数値】、米空軍長官Troy Meinkは、米国が「敵対的な相手の行動から統合軍を防護できる軌道上のspace control weapons（宇宙管制兵器）」を配備していると述べた。米政府機関の公式記事は、これをSpace Forceが宇宙に兵器を配備したことを初めて認めた発言として記録している。（範囲：米空軍・米宇宙軍。条件：敵対的な相手の行動から統合軍を防護する用途と説明）
- 【事実2】米国防総省は、ロシアが2024年5月16日【中核数値】に低軌道へ衛星を打ち上げ、その衛星を米政府衛星と同じ軌道に配置したと説明し、他の低軌道衛星を攻撃できる可能性があるcounter-space weaponと評価した。米側評価では、2019年【周辺数値】および2022年【周辺数値】に配備されたcounterspace payloadsと類似する特徴がある。（範囲：ロシアの低軌道衛星、米政府衛星との軌道関係。条件：米国防総省による評価。攻撃能力は『likely』『presumably』との評価で、実際の攻撃は確認されていない）
- 【事実3】米宇宙軍の2025年【周辺数値】Space Warfighting frameworkは、counterspace operationsを軌道、リンク、地上の各セグメントで行う攻撃・防御行動の総称と定義している。（範囲：軌道、通信リンク、地上セグメント。条件：米宇宙軍の作戦用語・計画枠組み）
