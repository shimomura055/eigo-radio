# Selected Fact Brief

## Storyline
MetaはMuseの一部の電話を人間の契約業者に引き継ぐテストで、適切な説明を欠いていたことを問題と認めて当面ロールバックし、説明を用意できるまで公開展開しない方針を示した。

## Selected Facts
ReutersはMetaの社内投稿に基づき、Museが行う一部の電話を訓練を受けた人間の契約業者が代わりに処理するテストが行われていたと報じた。MetaのSuperintelligence Labs担当副社長は、適切な説明をしないままテストを始めたのは問題だったと認め、機能を当面ロールバックしたと社内投稿で述べた。Metaの広報担当者は、テストの目的は安全・プライバシー保護策の実装に向けたフィードバック収集と機能改善であり、適切な説明を用意できるまで公開展開しないと説明した。ロールバックは当面の措置として扱い、恒久的な中止とは記述しない。
