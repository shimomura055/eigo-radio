# Selected Fact Brief

## Storyline
MetaはMuseの一部の電話を人間の契約業者に引き継ぐテストで、適切な説明を欠いていたことを問題と認めて当面ロールバックし、説明を用意できるまで公開展開しない方針を示した。

## Selected Facts
- 【事実1】Reutersが確認したMeta社内投稿によると、Museが行う一部の電話を、訓練を受けた人間の契約業者が代わりにかけて処理する「human concierge／human agent calls」のテストが行われていた。（範囲：Muse経由の電話のうち一部。全ての電話が人間に引き継がれたとは確認されていない。条件：Museから訓練を受けた人間の担当者へ依頼を引き継ぐ仕組み）
- 【事実2】MetaのSuperintelligence Labs担当副社長は、適切な説明をしないまま契約業者が電話をかけるテストを始めたのは問題だったと認め、機能を当面ロールバックしたと社内投稿で述べたとReutersが報じた。（範囲：human concierge／human agent callsの社内テスト。条件：ロールバックは「当面」と報じられた。恒久的な中止や将来の再開の有無を示すものではない）
- 【事実3】Metaの広報担当者は、テストの目的を安全・プライバシー保護策の実装に向けたフィードバック収集と機能改善だと説明し、適切な説明を用意できる段階になるまで公開展開しないと述べたとReutersが報じた。（範囲：Museの電話機能と、人間担当者が関与する可能性のある機能の公開展開。条件：Meta広報担当者による説明・方針表明）
