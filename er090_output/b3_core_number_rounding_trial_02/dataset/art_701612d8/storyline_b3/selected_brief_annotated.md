# Selected Fact Brief

## Storyline
2021年【周辺数値】の二つの無作為割付実験では、短時間の退屈による他者の報酬減額の増加は、増額も選べる課題では特性サディズムが高い参加者でのみ認められ、増額できない別の課題では特性の高低にかかわらず認められた。

## Selected Facts
- 【事実1】Study 7【周辺数値】では、参加者が動画を見ている間、別の参加者の報酬を減らす、増やす、または何もしない選択をできるようにした。著者らの分析では、退屈条件による報酬破壊の増加は、特性サディズムが高い参加者で認められ、低い参加者では認められなかった。（範囲：米国MTurk参加者N=634【中核数値】、平均年齢31.3歳【周辺数値】、女性50.5%【周辺数値】。条件：オンライン実験。退屈条件では、何も起きない石の5分【中核数値】動画を視聴しながら、別の参加者の報酬を10【中核数値】セント刻みで最大50【中核数値】セント減らすか増やすか選べた。対照条件では、マジシャンの5分【中核数値】動画を視聴。無作為割付）
- 【事実2】Study 8【周辺数値】では、別の参加者の報酬を減らす選択肢のみを設けた実験で、著者らは退屈条件の参加者が対照条件より報酬を減らす可能性が高かったと報告した。著者らの分析では、この条件では特性サディズムの高低にかかわらず退屈条件で報酬破壊が増加した。（範囲：米国MTurk参加者N=1,332【中核数値】、平均年齢31.0歳【周辺数値】、女性47.2%【周辺数値】。条件：オンライン実験、3【周辺数値】条件に無作為割付。退屈条件は石の5分【中核数値】動画、第一対照条件はマジシャンの5分【中核数値】動画、第二対照条件は動画視聴前に選択を行う条件。参加者は別の参加者への報酬を10【中核数値】セント刻みで最大50【中核数値】セント減らせ、増額という向社会的選択肢はなかった）
