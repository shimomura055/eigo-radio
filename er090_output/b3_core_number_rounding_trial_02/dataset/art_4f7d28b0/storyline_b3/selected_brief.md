# Selected Fact Brief

## Storyline
サウジの民間インフラへの攻撃が続き、10月10日のリヤド空港攻撃では多数が死傷し、国連イエメン担当特使は継続攻撃が地域の安全保障を脅かし、イエメンの和平努力を難しくすると警告した。

## Selected Facts
・F04｜中心事象：GACAは2026年10月11日の続報で、前日のキング・ハーリド国際空港への攻撃による死者を12人、負傷者を309人と発表した。人数はこの続報時点の発表値として扱う。
・F11｜事象の意味付け：国連イエメン担当特使は10月11日、サウジの民間インフラへの継続攻撃を非難。同週のリヤド・アブハ空港での民間人の死傷にも言及し、攻撃が地域の安全保障を脅かし、イエメンの和平努力を一層困難にすると評価した。

執筆上の制約：死傷者の報告と特使の評価を分ける。和平への影響は特使に帰属させ、実証済みの因果関係として断定しない。攻撃主体や攻撃の背景・動機は採用Factから特定しない。
