# Selected Fact Brief

## Storyline
MetaはMuse経由の一部の電話を契約スタッフに担わせる人間コンシェルジュ実験を、プライバシー懸念が示される中で適切な開示なしに始めたことを「ミス」と認めてロールバックし、今後は適切な開示が整うまで公開展開しないと説明した。

## Selected Facts
- 【事実1】MetaはMuse経由の電話の一部について、AIではなく訓練を受けた人間の契約スタッフが電話をかけ、相手とのやり取りを完了させる「human concierge」「human agent calls」のテストを実施した。（範囲：Muse経由で発信された電話の一部。条件：Museから人間の訓練済みエージェントへ依頼が引き渡されるテスト条件）
- 【事実2】Meta従業員は、人間の契約スタッフが電話を担当すると、電話中にユーザーの機微情報がコールセンターの契約スタッフへ意図せず共有される可能性があるとして、社内でプライバシー上の懸念を示した。（範囲：人間の契約スタッフがMuse経由の電話を担当するテスト。条件：電話の遂行にユーザー情報が必要となる場合）
- 【事実3】MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに契約スタッフが電話をかけるテストを開始したことを「ミス」だったと認め、機能を当面ロールバックしたと社内投稿で説明した。（範囲：Meta社内テストの人間コンシェルジュ機能。条件：適切な開示なしで契約スタッフが電話を担当していたテスト）
- 【事実4】Metaは、電話機能について、商業者との改善を続け、準備が整い、適切な開示ができる場合にのみ公開展開すると広報担当者を通じて説明した。（範囲：Museの電話機能および人間コンシェルジュを含む可能性のある運用）
