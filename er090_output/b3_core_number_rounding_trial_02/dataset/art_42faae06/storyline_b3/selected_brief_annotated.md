# Selected Fact Brief

## Storyline
全国で標準耐用年数を超える下水道管路が今後増える見込みで、人口減少で使用料収入も減るなか、喜多方市は集合処理区域外を合併処理浄化槽の個別処理区域に見直し、設置補助を行う方針とした。

## Selected Facts
- 【事実1】全国の下水道管路総延長は約50万【中核数値】kmで、標準耐用年数50年【中核数値】を経過した管路は約4万【中核数値】km（約7%【中核数値】）である。10年【中核数値】後には約11万【周辺数値】km（約22%【周辺数値】）、20年【周辺数値】後には約23万【周辺数値】km（約45%【周辺数値】）に増加する見込みである。（範囲：全国、都市下水路を除く下水道管路。条件：標準耐用年数50年【中核数値】を経過した管路を老朽管路として集計）
- 【事実2】国土交通省は、人口減少等による下水道使用料収入の減少と、施設老朽化に伴う改築更新費の増大が、下水道事業の経営環境を厳しくする要因になると説明している。（範囲：日本の公共下水道、特定環境保全公共下水道、農業集落排水事業。条件：長期収支見通しの把握を目的とした国土交通省の説明）
- 【事実3】環境省の汚水処理システムの説明では、住宅が分散する地域では個別処理の浄化槽、住宅が密集する地域では公共下水道等の集合処理が経済的に有利になり得るため、地域特性に応じた方式選択が必要とされている。（範囲：自治体が生活排水処理計画を策定する際の一般的な比較。条件：住宅密度、整備費、維持管理費、既存施設等を総合的に評価）
- 【事実4】喜多方市は、施設老朽化に伴う更新等による維持管理費の増加と、人口減少に伴う使用料収入の減少を踏まえ、汚水処理構想を見直した。見直し後、集合処理区域以外を合併処理浄化槽による個別処理区域とし、浄化槽設置費の上乗せ補助を実施するとした。（範囲：喜多方市全域の汚水処理構想。条件：公共下水道、特定環境保全公共下水道、農業集落排水、小規模集合排水の区域を見直した後の区域設定）
