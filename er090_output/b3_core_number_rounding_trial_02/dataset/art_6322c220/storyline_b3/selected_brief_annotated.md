# Selected Fact Brief

## Storyline
下水道の老朽化と人口減少で維持更新負担が増すなか、自治体は地域特性に応じて公共下水道と合併処理浄化槽を使い分ける計画の見直しを進めている。

## Selected Facts
- 【事実1】全国の下水道管路総延長は約50万【中核数値】kmで、標準耐用年数50年【中核数値】を経過した管路は約4万【中核数値】km（約7%【中核数値】）である。10年【中核数値】後には約11万【中核数値】km（約22%【周辺数値】）、20年【周辺数値】後には約23万【周辺数値】km（約45%【周辺数値】）に増加する見込みである。（範囲：全国、都市下水路を除く下水道管路。条件：標準耐用年数50年【中核数値】を経過した管路を老朽管路として集計）
- 【事実2】国土交通省の推計では、下水道の維持管理・更新費は2018年度【周辺数値】の約0.8兆円【周辺数値】から2048年度【周辺数値】には約1.3兆円【周辺数値】となり、約1.6倍【周辺数値】に増加する見込みである。（範囲：国土交通省所管の下水道施設を対象とした全国推計。条件：管路施設、処理施設、ポンプ施設を対象。施工条件等により推計値には幅がある）
- 【事実3】国土交通省は、人口減少等による下水道使用料収入の減少と、施設老朽化に伴う改築更新費の増大が、下水道事業の経営環境を厳しくする要因になると説明している。（範囲：日本の公共下水道、特定環境保全公共下水道、農業集落排水事業。条件：長期収支見通しの把握を目的とした国土交通省の説明）
- 【事実4】環境省の汚水処理システムの説明では、住宅が分散する地域では個別処理の浄化槽、住宅が密集する地域では公共下水道等の集合処理が経済的に有利になり得るため、地域特性に応じた方式選択が必要とされている。（範囲：自治体が生活排水処理計画を策定する際の一般的な比較。条件：住宅密度、整備費、維持管理費、既存施設等を総合的に評価）
- 【事実5】松山市は、下水道施設の老朽化、自然災害、人口減少による財政面の厳しさを踏まえ、公共下水道全体計画を見直し、市街化区域は原則として公共下水道、市街化調整区域は原則として合併処理浄化槽で汚水処理する方針とした。（範囲：松山市の全体計画区域。条件：市街化区域と市街化調整区域で方針を分ける。『原則』であり、区域内の個別事情を排除する記載ではない）
