# Selected Fact Brief

## Storyline
MetaはMuseが発信する一部の電話を人間の請負業者に処理させる社内実験を行ったが、機微情報が請負業者に共有され得るとの懸念が出る中、適切な開示なしに始めたとして機能を当面ロールバックした。

## Selected Facts
- Metaは、Museを通じて発信される電話の一部を人間の請負業者が処理するhuman conciergeを、従業員向けに試験していた。
- 社内では、人間が電話を処理すると機微情報がコールセンターの請負業者に意図せず共有される可能性があるとの懸念が示された。これは従業員の懸念であり、情報漏えいが一般的に発生したとの確定事実ではない。
- Metaの副社長は、適切な開示なしに請負業者が電話をかけるテストを始めたことを問題として認め、human concierge機能を当面ロールバックした。
