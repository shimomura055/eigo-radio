# Selected Fact Brief

## Storyline
MetaはMuseが発信する一部の電話を人間の請負業者に処理させる社内実験を行ったが、機微情報が請負業者に共有され得るとの懸念が出る中、適切な開示なしに始めたとして機能を当面ロールバックした。

## Selected Facts
- 【事実1】Metaは、パーソナルAIアシスタント「Muse」を通じて発信される電話の一部を、人間の請負業者が処理する「human concierge」を試験していた。（範囲：Meta社内の従業員向けテスト。条件：Muse経由で発信される電話の一部が対象）
- 【事実2】社内投稿では、一部の従業員が、人間が電話を処理すると、機微情報がコールセンターの請負業者に意図せず共有される可能性があると懸念を示した。（範囲：human concierge機能をめぐるMeta社内の反応。条件：人間の請負業者がMuseの電話を処理する場合）
- 【事実3】MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに請負業者が電話をかけるテストを始めたことを「miss」と認め、human concierge機能を当面ロールバックしたと社内投稿で述べた。（範囲：human concierge機能の社内テスト。条件：請負業者が電話をかけるテストを、適切な開示なしに開始した状況）
