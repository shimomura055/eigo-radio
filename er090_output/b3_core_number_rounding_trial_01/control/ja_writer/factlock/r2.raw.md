# 給料が上がると、まじめになる？ 比べる相手は「前の自分」

「あの人、きっちり働くから給料も高そう」「いや、あの先輩は自由すぎるのに羽振りがいいぞ」。収入と性格の話になると、脳内で始まる職場の人物評。しかし今回、その品評会はいったん閉店だ。研究のスポットライトが当たるのは、隣の同僚ではなく「前の自分」である。

研究者たちは、収入と性格を繰り返し調べた11件の大規模調査をまとめて分析した。対象は、仕事をしていて、性格と仕事からの収入を報告した人たち。人数は分析によって異なるが、最大134,515人。なかなかの大所帯だ。

ただし、見どころは人数だけではない。「もともと人によって違う部分」と「同じ人の中で変わった部分」を分けたのが、この研究のポイントだ。高収入の誰かと自分を比べるのではなく、自分の変化を追いかける。カメラの向きが、職場の集合写真から、一人ひとりの連続ドラマに切り替わったのである。

そこで見つかったのが、収入と、まじめさに関わる性格「勤勉性」との小さな関連だった。同じ人の中で、収入が高くなることは、その後の勤勉性が高くなることと結びついていた。しかも逆向きにも、勤勉性が高くなることは、その後の収入が高くなることと結びついていたのだ。

「つまり、給料が上がれば、私の先延ばし癖も直る？」

おっと、その結論には待った。研究者たちは、この研究では原因と結果の関係までは確かめられないと明記している。時間を追って二つの変化が結びついていても、収入が性格を変えたとも、性格が収入を増やしたとも断定できない。関連があることと、原因であることは別の話だ。

年齢の影響を考えた追加分析でも、結論は大きく変わらなかった。ただし、年齢以外の何かが関わっている可能性は残る。「その後に起きた」と「それが原因で起きた」の間には、まだ橋が架かっていない。

だから、これは「昇給でまじめ人間に変身！」という攻略本ではない。お金と性格の関係を、他人との順位表ではなく、自分の時間の流れから眺めた研究だ。よその財布が気になる日もある。でも、ときには比較相手を「前の自分」に替えてみる。見慣れた給料明細も、自分の連続ドラマの一場面として、少し違って見えるかもしれない。
