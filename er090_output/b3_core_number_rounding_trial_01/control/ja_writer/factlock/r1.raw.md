# 収入と性格の意外な関係。ライバルは「前の自分」

「まじめな人ほど、よく稼ぐ？」。そう聞くと、職場のあの人を思い浮かべたくなる。きっちり仕事をする同僚、なぜか羽振りのいい先輩……。でも、今回の研究で注目したい比較相手は、隣の席の誰かではない。「前の自分」だ。

研究者たちは、収入と性格を繰り返し調べた11件の大規模調査をまとめて分析した。対象は、仕事をしていて、性格と仕事からの収入を報告した人たち。人数は分析によって異なり、最大134,515人にのぼる。

ただし、大人数を並べて「高収入の人はこんな性格！」と仕分けた、というだけの話ではない。ポイントは、人による安定した違いと、同じ人の中で起きる変化を分けたこと。「人と人の比較」と「自分の変化の追跡」を、ごちゃ混ぜにしなかったのだ。いわば、他人とのランキング表から、自分自身の連続ドラマへ、カメラを切り替えたわけだ。

すると、同じ人の変化では、収入と、まじめさに関わる性格「勤勉性」の間に、小さな関連が見つかった。収入が高くなることは、その後の勤勉性が高くなることと結びついていた。逆向きにも、勤勉性が高くなることは、その後の収入が高くなることと結びついていたのだ。

「なるほど、給料が上がれば、私もまじめになるのか！」と思った人、ここで一時停止。この研究は、原因と結果の関係までは確かめられない。研究者たちも、その点を明記している。二つの変化が時間を追って結びついていても、一方が他方を引き起こしたとは言えない。

年齢の影響を考えた追加分析でも、結論は大きく変わらなかった。ただ、年齢以外の何かが関わっている可能性は残る。「後から変わった」と「それが原因で変わった」の間には、まだ越えられない線がある。

だから、これは「収入アップで性格改善」という攻略本ではない。お金と性格を、誰かとの順位ではなく、自分の時間の流れで眺めた研究だ。収入が気になったら、よその財布ばかり見ずに、前の自分にも目を向けてみる。比較の主役を替えるだけで、見える景色はちょっと変わる。
