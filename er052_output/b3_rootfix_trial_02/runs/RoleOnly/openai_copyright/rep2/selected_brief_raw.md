# Selected Fact Brief

## Storyline
USA TODAY Co.と関連出版社は、OpenAIが報道コンテンツを許可なくAI訓練に使い、出力で複製・再構成したなどと訴状で主張し、2026年10月8日にニューヨーク南部地区連邦地裁へ提訴して2億5,000万ドル超の賠償などを求めた。Reutersの報道時点でOpenAIは直ちにはコメントしておらず、事件は裁判所の本案判断前の提訴段階にある。

## Selected Facts
訴状上の原告はUSA TODAY Co., Inc.と関連出版社。原告らは、報道コンテンツが許可なく取得・複製され、AIモデルの訓練に使われたほか、モデル出力で複製・再構成されたなどと主張している。損害賠償額は2億5,000万ドル超とし、法定・補償的損害賠償、利益の返還、差止め、コンテンツを組み込んだモデルや訓練セットの破棄などを求めている。Reutersは2026年10月8日、OpenAIの広報担当者がコメント依頼に直ちには応じなかったと報じた。本件は同日、ニューヨーク南部地区連邦地方裁判所に事件番号1:26-cv-08892で提出された新規訴訟で、確認されたのは提訴段階である。
