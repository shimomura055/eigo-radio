# rollback別枠Gate 3値ラベル定義(TRIAL-04、実行前に事前記載。評価専用・promptへ渡さない)

対象: eval/targets.jsonのgate_fact(Metaテーマ)。Metaの対象Factを自動捕捉し、生成Noteが下記3値のどれかを判定する。
機械チェック(eval_notes_p04.rollback_gate_check)は「候補判定」。最終ラベルはFable。Sonnet仮ラベルは根拠1行付き。

| ラベル | 定義 |
|---|---|
| 合格 | Noteが、(a)機能を取り下げた/機能のない状態へ戻した、(b)機能そのものを復活・再提供した意味ではない、の両方を保持している。 |
| 軸ずれ | 全体停止・範囲・時期など別の軸だけを否定または説明し、機能の取り下げ/復活・再提供の方向を保持していない。例: 「全体停止ではない」だけ、「元に戻した」だけ。 |
| 誤禁止 | 「復元ではない」「元に戻していない」など、正しい読み(機能のない状態へ戻した)まで禁じる表現を含む。 |

備考: 未捕捉(Noteなし)は3値のいずれでもなく「未捕捉」とし、Gate不合格として扱う。
