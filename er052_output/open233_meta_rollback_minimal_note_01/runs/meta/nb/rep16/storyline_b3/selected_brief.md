# Selected Fact Brief

## Storyline
MetaはAIエージェントMuseの電話機能の一部を訓練済みの契約スタッフが代行する「人間コンシェルジュ」として試したが、ユーザー情報の共有や開示をめぐる懸念を受け、機能をロールバックした。

## Selected Facts
・Muse経由の電話の一部で、AIではなく訓練を受けた人間の契約スタッフが電話をかけ、相手とのやり取りを完了させる「human concierge」「human agent calls」のテストを実施した。
・Meta従業員は、人間の契約スタッフが電話を担当すると、電話中にユーザーの機微情報がコールセンターの契約スタッフへ意図せず共有される可能性があるとして、社内でプライバシー上の懸念を示した。
・MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに契約スタッフが電話をかけるテストを開始したことを「ミス」だったと認め、2026年9月22日までに人間コンシェルジュ機能を当面ロールバックしたと説明した。
