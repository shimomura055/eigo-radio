# Selected Fact Brief

## Storyline
MetaはAIエージェントMuse経由の電話の一部を訓練済み契約スタッフが代行する「人間コンシェルジュ」を適切な開示なしに試験したが、ユーザー情報がスタッフに共有され得るプライバシー懸念が示され、機能を当面ロールバックし、適切な開示が整うまで公開展開しない方針を示した。

## Selected Facts
- MetaはMuse経由の電話の一部について、AIではなく訓練を受けた人間の契約スタッフが電話をかけ、相手とのやり取りを完了させる「human concierge」「human agent calls」をテストした。
- Meta従業員は、契約スタッフが電話を担当すると、電話中にユーザーの機微情報がコールセンターの契約スタッフへ意図せず共有される可能性があるとして、社内でプライバシー上の懸念を示した。これは懸念の存在を示す事実であり、大規模な情報漏えいが発生したという意味ではない。
- MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに契約スタッフが電話をかけるテストを開始したことを「ミス」だったと認め、人間コンシェルジュ機能を当面ロールバックしたと説明した。

- Metaは、電話機能について、商業者との改善を続け、準備が整い、適切な開示ができる場合にのみ公開展開すると説明した。
