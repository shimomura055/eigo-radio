## 0. 先に確認した前提(重要)
1. 台帳notes行は実際には大半が「〜と書かない/断定しない/区別する」型の禁止・限定指示で、「未提示」「確認できていない」型の記述は少数。「支払義務者は未提示」は HF-003 の**fact本文**(notesではない)であり、**HF-003はhormuz P2 rep1/rep2のbriefに選定されていない**(rep1=HF-002,007 / rep2=HF-002,007,009)。よって hormuz の「支払方式の具体化」NG(fact_id=HF-003表記)は、「未提示」という記述自体がWriterに渡っていない。
2. P2 briefへの転記は、各factについて台帳notes行全文(「注意: …」+「注意(多義): …」)の逐語転記。notesの内容がbriefに乗っていること自体は確認できた。

4. JA初稿での存否: NG文の逐語は多くR2でのみ一致(言い回しが改稿で変わるため)。意味レベルでR0(初稿)から存在するかを下表に記載(R1/R2=改稿で出現)。
