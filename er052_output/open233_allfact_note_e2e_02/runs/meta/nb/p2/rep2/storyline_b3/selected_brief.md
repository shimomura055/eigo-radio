# Selected Fact Brief

## Storyline
MetaはMuseで一部の電話を人間の契約スタッフが代行するテストを実施したが、適切な開示なしに行ったことをミスと認めて人間コンシェルジュ機能をロールバックし、適切な開示が整うまで公開しないとした。
