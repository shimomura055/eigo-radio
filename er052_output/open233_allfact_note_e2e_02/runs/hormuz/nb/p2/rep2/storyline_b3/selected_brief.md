# Selected Fact Brief

## Storyline
トランプ氏は中東指導者との「非常に生産的な協議」を踏まえ、7月13日に表明したホルムズ海峡通航貨物への20％償還料案を翌14日に湾岸諸国による対米貿易・投資案件へ置き換えたが、撤回後のBrentは一時上げ幅を縮めた後、海上封鎖・軍事攻撃・タンカー安全への懸念が続く中で高い水準に戻った。
