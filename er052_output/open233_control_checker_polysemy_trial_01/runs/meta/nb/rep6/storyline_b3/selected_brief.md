# Selected Fact Brief

## Storyline
MetaはMuseの一部の電話を訓練済み契約スタッフが代行する「人間コンシェルジュ」を適切な開示なしに試験し、ユーザーの機微情報がスタッフに共有され得るとのプライバシー懸念が出る中、担当幹部が開始を「ミス」と認めて機能をロールバックした。

## Selected Facts
- Muse経由の電話の一部について、AIではなく訓練を受けた人間の契約スタッフが相手とのやり取りを完了させる「human concierge」「human agent calls」のテストを実施した。すべての電話を人間が担当したわけではない。
- Meta従業員は、契約スタッフが電話を担当すると、電話中にユーザーの機微情報がコールセンターの契約スタッフへ意図せず共有される可能性があるとして、社内でプライバシー上の懸念を示した。実際の大規模な情報漏えいが発生したとは断定しない。
- MetaのSuperintelligence Labs部門の副社長は、適切な開示なしに契約スタッフが電話をかけるテストを開始したことを「ミス」と認め、人間コンシェルジュ機能を当面ロールバックした。ロールバック対象は人間コンシェルジュ機能であり、Muse全体の停止を意味しない。
