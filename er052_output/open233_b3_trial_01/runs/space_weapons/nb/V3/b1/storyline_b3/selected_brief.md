# Selected Fact Brief

## Storyline
米国が敵対的な相手の行動から統合軍を防護する軌道上のspace control weaponsの配備を初めて公式に認めたことで、今回の「兵器を宇宙に配備」という動きを、広義のcounterspace、地上発射型ASAT試験、従来の監視・防護活動から切り分けて捉えることが中心課題になった。

## Selected Facts
- F-001：2026年9月14日、米空軍長官Troy Meinkは、米国が「敵対的な相手の行動から統合軍を防護できる軌道上のspace control weapons（宇宙管制兵器）」を配備していると述べた。米政府機関の公式記事は、これをSpace Forceが宇宙に兵器を配備したことを初めて認めた発言として記録している。
- F-003：ロシアは2021年11月15日、地上発射型の直接上昇式ASATミサイルでロシアの衛星COSMOS 1408を破壊し、1,500個超の追跡可能な軌道デブリを発生させた。これは地上から発射したASATミサイルによる破壊試験であり、兵器を軌道上に恒久配備した事例とは区別する。
- F-012：米宇宙軍の2025年frameworkは、攻撃側のcounterspace行動として軌道攻撃、space link interdiction、地上攻撃を挙げ、space link interdictionには電磁攻撃とサイバー攻撃を含めている。counterspaceはASATミサイルなどの軌道攻撃だけを意味しない。
- F-015：米宇宙軍は、GPS機能、ミサイル追跡、宇宙領域認識、衛星アーキテクチャのレジリエンスを継続的な任務・優先事項として説明している。これらは衛星を軍事・社会インフラとして運用・保護する活動であり、任務説明だけから攻撃兵器の軌道上配備を意味するとは確認できない。
