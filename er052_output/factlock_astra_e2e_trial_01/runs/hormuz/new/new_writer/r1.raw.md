# 20％案は退場。でも、Brent先物は安心しなかった

派手な料金案が引っ込めば、相場もすっと落ち着く。そんな筋書きなら話は早い。ところが今回のBrent先物は、そう簡単には幕を下ろさなかった。発言は変わった。それでも、海峡をめぐる警戒は舞台に残った。

発端は、トランプ氏の投稿だった。ホルムズ海峡を通るすべての貨物に、米国の安全確保費用として20％の償還を求めるという。「償還」とは、かかった費用を埋め合わせてもらうこと。数字の迫力に目を奪われるが、ここで示されたのは、安全確保の費用を理由にした請求案だ。

その日のBrent先物は、7.29ドル、9.59％上昇し、83.30ドルで清算された。なかなか強烈な上げ方だ。ただし、ここで「20％案で急騰！」と一本の線を引くのは早い。Reutersは、翌日に始まる予定とされた米国の対イラン海上封鎖と、海峡を通るエネルギー輸送への懸念に、この上昇を関連付けている。

そして翌日、話は急展開する。トランプ氏は、償還料案を湾岸諸国による対米貿易・投資案件に置き換えると投稿した。海峡を通る貨物への請求から、米国との貿易や投資へ。料金案は表舞台を去り、別の案件に出番が回った。

ならばBrent先物も一気に下落か。実際の動きは、そんなに素直ではなかった。発表後、一時は上げ幅を縮めた。ところが、ほどなく発表前に近い高い水準へ戻った。いったん緩んだ緊張の糸が、また張り直されたような値動きだった。

海上封鎖や攻撃、タンカーの安全をめぐる懸念も続いていた。料金案が置き換わっても、エネルギー輸送への心配まで一緒に退場したわけではない。そう読むことができる。請求の話が変わることと、船が安全に通れるかどうかは、別の問題なのだ。

ここで見ているのは、原油価格全般ではなくBrent先物だ。しかも、撤回後にずっと下げ続けたのではなく、上げ幅を縮めてから戻している。派手な発言は見出しの主役になりやすい。でも、相場を読むなら、封鎖や輸送の安全という話も脇に置けない。料金案が消えたことと、海峡の不安が消えたことは、同じニュースではない。見出しが幕を下ろしても、相場の物語には続きがあった。
