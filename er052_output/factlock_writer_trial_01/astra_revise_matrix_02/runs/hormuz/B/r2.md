# 海峡の「20％」はどこへ？　一夜で変わった筋書きと、下がらない原油

海峡を通るすべての貨物に、20％を求める。トランプ氏が打ち出した提案は、数字だけでも目を引く。ところが翌日、その話は早くも別の筋書きへ。海峡に向けられた「請求書」は、いったいどこへ行ったのか。

舞台はホルムズ海峡。トランプ氏の説明では、20％は米国が海峡の安全を確保する費用を償うためのものだった。ここで大事なのは、まだ提案だったという点。「新しい通行料が導入された」と受け取ると、物語の出発点からずれてしまう。

そして翌日、急展開が訪れる。トランプ氏は、中東の指導者との協議に基づき、その償還料を湾岸諸国による対米貿易や投資の案件に置き換えると投稿した。貨物から料金を取る話が、米国との商取引や投資の話へ。一夜にして、交渉のテーブルに載るものが変わった。

ただし、ここで「商談成立！」と幕を下ろすのは早い。伝えられているのは、料金案と、それを別の案件に置き換えるという発言まで。貿易や投資が実際にまとまった、という話ではない。

では、原油市場は安心したのか。ここからが、もう一つの見どころだ。

Brent原油先物は、発表後に一時、上げ幅を縮めた。ところが、そのまま落ち着くかと思えば、ほどなく発表前に近い高い水準へ戻った。報道時点では約2.6％高、1バレル85ドル超。料金案は引っ込んでも、原油価格まで一緒に引き下がったわけではなかった。

一度は上げ幅を縮め、また戻る。この往復を見落とすと、ニュースはずいぶん単純になる。「20％案を撤回、だから原油安」。だが、実際の相場は、その一行では収まらない動きを見せた。

そのころも、米・イラン間の攻撃や海上封鎖、タンカーの安全への懸念は続いていた。政治の発言が次の場面へ進んでも、海の上の不安まで場面転換するわけではない。請求の仕組みと、船が安全に航行できるかどうかは、別の問題なのだ。

もちろん、この値動きだけで、何が価格をどれだけ動かしたかは断定できない。料金案だけを相場の主役にするのも無理がある。見るべきは、発表直後の反応と、その後の戻り。その両方だ。

遠い海峡の話も、原油価格を通せば暮らしにつながる。政治の言葉は一日で切り替わった。それでも、安全への不安は同じ速さでは晴れない。今回、最後まで目が離せなかったのは「20％」の行方だけではない。高い水準へ戻ってきた原油価格もまた、このニュースの続きを問いかけている。
