# AIに電話を頼んだら、人がかけていた——Museの「舞台裏」

AIが代わりに電話をして、用件を済ませてくれる。気になるのは、声の自然さ？　返答の速さ？　Museを通じた電話のテストで浮かび上がったのは、その一歩手前の問いでした。「そもそも、誰が電話をかけているのか？」

実際、テストでは電話の一部をAIではなく、訓練を受けた人間の契約スタッフが担当し、相手とのやり取りを完了させていました。AIの話を聞いていたはずが、舞台の中央に現れたのは人間。ここが、この話の意外なポイントです。

もちろん、人が手伝ったから即アウト、という話ではありません。大切なのは、AIの機能として見えるものの裏で人間が動くとき、その切り替わりを利用者にどう伝えるかです。

今回のテストは、適切な開示なしに始まりました。Metaの副社長は、これを「ミス」と認めています。問題は人間の登場そのものよりも、その登場がきちんと知らされていなかったことでした。

そして、話は電話の担当者だけでは終わりません。もう一つの焦点は、情報の行き先です。Metaの従業員からは、人間の契約スタッフが電話を担当すると、やり取りに必要なユーザーの機微情報が、コールセンターの契約スタッフに意図せず共有される可能性がある、との懸念が示されました。

ここで、早合点は禁物です。大規模な情報漏えいが起きた、という話ではありません。示されたのは、そうした共有が起こりうるというプライバシー上の懸念。ただ、「用件を済ませるための情報を、誰が見るのか」は、利用者にとって小さくない問いです。電話が無事に終われば、それですべて解決——とはいかないわけです。

Metaは、人間コンシェルジュ機能を当面ロールバックしました。対象はこの機能であり、Muse全体を止めたわけではありません。問われているのは、便利な機能を残すか消すかだけでなく、人間の関与と情報の扱いをどう知らせるかです。

AIがどれだけ自然に話せるか。その進歩は、たしかに気になります。でも、任せる側が知りたいのは、上手な話し方だけではないはずです。誰が担当し、どんな情報を扱うのか。次に「電話をお願い」と頼むときは、その舞台裏の説明まで聞いておきたくなりませんか。
