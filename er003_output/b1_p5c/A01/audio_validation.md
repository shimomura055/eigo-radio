「なんが」誤読の原因が、TTSエンジン自体ではなく全文ひらがな入力方式にあるかを

## 9. 対象句ごとのASR診断

Azure STT(連続認識、診断用途のみ)による認識結果に対し、読み正規化を行わず
漢字かな表記のまま照合した(P4D/P5Bのひらがな正規化パイプラインとは別方式)。

| 対象句 | 結果 |
|---|---|
| 何が起きる | **検出**(P5Bでは「みなみがおきる」に誤認識されていたが、今回は文字列としてそのまま検出) |
| 選手を交代で下げる | **検出** |
| 目印という決断で | **検出** |
| 守備を固め | **検出** |
| 最後の数分 | 未検出(下記参照) |
| わずかなリード | **検出** |
| 「目印」出現回数 | **5回(想定通り)** |

ASR認識結果(該当箇所抜粋):

> …イングランドは選手を交代で下げる目印という決断で守備を固め、わずかなリード目印を守ろうとします。…

**「選手を交代で下げる」「目印という決断で」「守備を固め」が、句読点の混入や
語順の乱れなく連続して検出された。** これはP5B(全文ひらがな)で見られた
「めじるしというけつだん。でしゅびをかため」という句点混入とは異なる結果である。

「最後の数分」が未検出だった理由: ASR認識結果は「最後のカズフン。」であり、
「数分」(すうふん)が「カズフン」と認識された。「数」という漢字は「すう」
「かず」の両方の読みを持つため、TTSがどちらで発話したか、あるいはASRが
誤認識しただけなのかは、本レポートでは断定していない。
