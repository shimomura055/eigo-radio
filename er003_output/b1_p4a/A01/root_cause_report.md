# ER-003-B1-P4A 根本原因レポート

## 結論: Case B(TTS入力は正しく、Gemini TTSが該当マーカーを英語で発話した)

P4で実際にGemini TTSへ渡した入力原稿(`er003_output/b1_p4/A01/source/
pattern_a_tts_with_katakana_markers.txt`、sha256
`5288a85b346a22277d5256e8c5e64d50a7a64b77735a04ee996ce4da31c7f016`)を
静的に監査した結果、以下を確認した。

| 監査項目 | 結果 |
|---|---|
| 5つの英語used formの残存数 | すべて0 |
| 5つのマーカーの出現数 | すべて1 |
| ASCII英字[A-Za-z]の残存数 | 0 |
| マーカー総数 | 5 |

TTS入力原稿には英語のused form(`shot on target`等)は一切残っておらず、
`close the door to the final`に対応するカタカナマーカー
「クローズ・ザ・ドア・トゥ・ザ・ファイナル」も、他の4マーカーと同様に
正しく1回だけ置換済みだった。原稿全体にASCII英字は1文字も含まれていない。

**したがって、原因は置換処理の不一致(Case A)ではなく、正しく日本語
カタカナ化された入力に対して、Gemini TTSモデル自身がこの特定のマーカー
だけを英語で発話したこと(Case B)である。**

## 修正内容

Case Bの対応方針に従い、問題のマーカーだけを、ASCII英字・カタカナ英語を
一切含まない日本語固有表現へ変更した。

| 項目 | 変更前 | 変更後 |
|---|---|---|
| `close the door to the final`のマーカー | クローズ・ザ・ドア・トゥ・ザ・ファイナル(カタカナ) | 第四の合図(漢字・ひらがなのみ) |

他の4マーカー(ショット・オン・ターゲット/テイク・プレイヤーズ・オフ/
ア・ナロー・リード/ストッページ・タイム)は、P4で日本語として生成された
実績を踏まえ、無変更のまま維持した。

「第四の合図」は、Pattern A原文中に元々存在しないこと、ASCII英字・
カタカナのいずれも含まないことを機械的に確認済み。

## 修正後の確定チェック(API call前)

| チェック項目 | 結果 |
|---|---|
| 5 used form残存数すべて0 | 合格 |
| 5 marker出現数すべて1 | 合格 |
| marker総数5 | 合格 |
| ASCII英字残存数0 | 合格 |
| Pattern Aの日本語部分の変更0(マーカーを戻すと原文と完全一致) | 合格 |

全項目合格を確認したうえで、日本語Preview rawを1回だけ再生成した。

## 再生成後の内容確認結果

診断用ASR(Azure STT連続認識、境界決定には未使用)による確認結果:

| マーカー | 判定 | 備考 |
|---|---|---|
| ショット・オン・ターゲット | 検出(1回) | 問題なし |
| テイク・プレイヤーズ・オフ | 検出(1回) | 問題なし |
| ア・ナロー・リード | 未検出(認識結果は「アンナローリード」、「ン」が1文字多い) | 英語化ではない。日本語のまま。ASR転記のわずかな揺れの可能性が高い |
| **第四の合図** | **検出(1回)** | **P4で問題だった箇所。今回は正しく日本語として発話されたことを確認** |
| ストッページ・タイム | 未検出(認識結果は「ストップページタイム」、「プ」が1文字多い) | 英語化ではない。日本語のまま。P4の初回生成時にも同じ差異が生じており、TTSの発音の癖である可能性がある |

**本ステージの主目的である「close the door to」マーカーの英語化は解消されたことを確認した。**
一方、`ア・ナロー・リード`と`ストッページ・タイム`について、完全一致ベースの
機械チェックでは「1文字多い」という理由で不一致と判定されている。いずれも
英語への言い換えではなく、日本語のカタカナとして認識されており、`close the
door to the final`で見られたような言語自体の置き換えとは性質が異なる。
ASRの転記揺れである可能性が高いが、本レポートでは断定していない
(機械的に判定できない領域のため)。
