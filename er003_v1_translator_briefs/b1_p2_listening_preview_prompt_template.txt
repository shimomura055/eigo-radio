B1英語学習者向けPodcastの、本文の前に流す「概要＋Key Words統合コーナー」の台本を、役割が異なる3パターン(A/B/C)作成してください。

【役割】
独立した単語リストではなく、記事の背景・状況・注目点を日本語で自然に伝えながら、指定された5つの英語表現を自然に耳へ入れるコーナーです。

【言語順】
各Key Word / Phraseは必ず、日本語の意味 → 英語表現、の順で紹介してください。
例: 「枠内シュート、shot on target」

【英語の使用】
- 指定された5件を、各パターン内で1回ずつ、全て使ってください。
- 同じ英語表現をパターン内で繰り返さないでください。
- 指定された5件以外の英単語・英語表現を意図的に混ぜないでください(人名・国名などの固有名詞の英語表記は問題ありません)。
- 「英語では」「覚えてください」のような教材的な案内は入れないでください。

【語形の扱い】
canonical formの意味と中核表現は必ず維持してください。日本語文へ自然に組み込むために必要な範囲でのみ、時制・三人称単数の-s・単数複数・冠詞・代名詞・必要最小限の語順や目的語の調整を許容します。
例: canonical "take a player off" → used "took a player off"(可)
別の同義表現への置き換えは禁止します。
例: "take a player off" → "make a substitution"(禁止)

各パターンで実際に使った英語表現(used_form)を、5件それぞれについてcanonical formと対にして記録してください。

【長さ】
各パターンは3〜4文にしてください。日本語部分はおよそ140〜220文字を目安にしてください(厳密な合否条件ではありません)。不自然に詰め込んで短くしないでください。

【内容に含めてよいもの】
- 対戦の背景
- 前半・後半の空気の変化
- 本文で注目すべき人物や戦術
- 交代策など、2つのPointへつながる観点
- 本編への興味を高める問いかけ

【内容に含めてはいけないもの】
- 最終スコア
- 勝者
- 決勝点を決めた人物
- 決定的な結末の詳細
- 本文にない事実
- 5表現の辞書的な長い説明
- 単語リストのような形式

【3パターンの目的】

Pattern A — Story / Drama
目的: 試合の緊張感と物語性を高め、本編を聞きたい気持ちを作る。時系列の流れを感じさせ、緊迫感を重視し、結果を明かさず引きを作る。5表現を物語の中へ自然に組み込む。

Pattern B — Comprehension / Structure
目的: 本文の理解負荷を下げ、何に注目して聞けばよいかを明確にする。試合の背景と大きな変化を整理し、Messiの役割と両チームの交代策へ注意を向ける。2つのPointを説明しすぎずに予告する。B1学習者が本文の流れを追いやすくする。

Pattern C — Keyword Salience
目的: 5つの英語表現を本文中で認識しやすくする。日本語の意味と英語表現の対応を他パターンよりも少し明確にするが、単語リストにはしない。5表現が自然に耳へ残る文構造にする。教材的・説明的になりすぎないようにする。

3パターンは単なる言い換えにせず、上記の目的の違いが分かるようにしてください。
