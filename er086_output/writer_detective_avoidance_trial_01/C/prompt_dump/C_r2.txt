# 「攻撃しない戦闘機」――でも、支援の話はそこで終わらない

戦闘機が出る。でも、相手を攻撃するためではない。そんな発表をしたのが英国だ。では、「英国の支援は、すべて守るためのもの」と考えていいのか。実は、話はそこで終わらない。もう一つの支援に目を移すと、違う役割が見えてくる。

まず、サウジアラビアが率いる連合軍の報道官は、フーシ派がリヤドに向けて発射した弾道ミサイル１発を迎撃し、破壊したと発表した。これは、連合軍側からの発表として押さえておきたい。

このニュースで注目したいのが、英国の戦闘機「タイフーン」だ。英国防省によると、任務はサウジの都市や重要施設を空からの攻撃から守ること。「戦闘機を使う」という言葉から想像しがちな、相手の拠点へ攻め込む仕事ではない。

英国は、タイフーンの任務を防御に限り、フーシ派への攻撃は行わないとしている。今回、この機体に渡された仕事は「どこを攻めるか」ではなく「どこを守るか」。戦闘機という名前だけでは、実際の役目は決まらないわけだ。

なるほど、防御のための出動なのか。そう納得して記事を閉じようとすると、もう一つ、見逃せない発表がある。空中で燃料を補給する支援の延長だ。

英国は、サウジの防空作戦に向けた空中給油支援も延長するとしている。そして、その支援の対象には、イエメン国内のフーシ派の軍事目標を弱める作戦も含まれる。サウジとイエメンの人々を脅かす軍事目標が、その対象だ。

ここで、二つの役割が分かれる。タイフーン自身はフーシ派を攻撃しない。一方、給油で支える作戦には、フーシ派の軍事目標を弱めるものもある。同じ英国の支援でも、戦闘機に課された制限と、給油が支える作戦の範囲は同じではない。

だから、「英国は攻撃しない」と一言でまとめると、給油支援の対象が見えなくなる。逆に、「英国の戦闘機がフーシ派を攻撃する」と読むのも、発表とは違う。短く言い切ろうとするほど、肝心の違いが抜け落ちてしまう。

このニュースの読みどころは、戦闘機が登場することだけではない。「攻撃しない」という説明が、どの任務にかかっているのか。そして、別の支援は何を可能にするのか。主役の飛行機だけでなく、それを取り巻く仕事まで見ると、同じ発表の輪郭が変わってくる。

「参加するのか」の次は、「何を任せ、何は任せないのか」。今回、見逃したくないのは、その境界線だ。
