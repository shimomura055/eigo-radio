# AIの電話を切られたら、人間が登場？　Metaが試した“最後の切り札”

AIが電話をかけてくれる。そんな未来のサービスを試していたMetaで、少し意外な作戦が登場しました。

AIの「Muse」が電話をかけ、相手に切られたら――人間が代わりに電話する。

もちろん、すべての通話を人間が担当したわけではありません。Metaの内部テストで、一部の電話依頼を、訓練を受けた人間のエージェントに引き渡す仕組みが試されました。人間のエージェントは、Museの代わりに実際の電話をかけます。Metaはこの機能を「human concierge」、つまり人間のコンシェルジュと呼んでいました。

なぜ、そんな仕組みが必要になったのでしょうか。

Reutersによると、MuseがAIだと分かると、相手が電話を切ってしまう例がありました。そこでMetaは、AIだと警戒される場面への対応として、人間のエージェントを登場させたのです。

ここが、この話のいちばん面白いところです。AIは人間らしく話そうとしているのに、相手に「AIです」と見抜かれると通話が終わる。すると今度は、本物の人間が裏から出てくる。未来の電話サービスの最終兵器が、人間そのものというわけです。

ただ、その瞬間に別の問題が顔を出しました。Metaの従業員の一部は、人間の契約作業員が電話を処理すると、個人情報や機微な情報が、意図せずコールセンターの作業員に共有される可能性を心配しました。情報漏えいが起きたと報じられたわけではありません。誰が電話を聞き、何を知ることになるのかが、十分に見えていなかったのです。

Metaの副社長は、適切な説明をしないまま契約作業員による電話を始めたのは問題だったと認めました。その後、この機能はいったんロールバックされました。永久に中止したという意味ではなく、2026年9月22日時点での対応です。

AIに任せるのか、人間に任せるのか。どうやら本当の課題は、その二択ではなさそうです。AIの裏側に人間がいるなら、その事実と、見られる情報まできちんと説明できるか。便利な電話ほど、そこをごまかせない時代になりそうです。
