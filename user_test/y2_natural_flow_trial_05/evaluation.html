冒頭から結末までの話の展開

  • 姓A: 親が息子に「寂しい」と伝えたら反対に聞こえるか→言うのをためらう→困らせないか気になる→黙ると気にしていないと思われるか→どんな言葉なら伝わるか。一つの話題で最後まで進む。
  • 姓B: Voiceの親の言葉→「選んだ姓への気持ちと知らされ方への気持ちは別」→決める前と後の二つの場合を比べる→賛成か反対かだけでは分からない。主張は一つだが、抽象的な比較を挟む。
  • 姓C: 法律の年→九割以上が夫の姓→姓を聞く場面→「どうして？」と聞きたくなるのはどちらか→その問いは何を知りたいのか。話の種類が、歴史→統計→仮の場面→問いと切り替わる。
  • AI面接A: 一つの答えを思い浮かべる→事前にAIと練る場合→面接中にAIの案を見る場合→その場の案を自分で直す場合→どこまでが本人の答えか。三つの場合を次々に比べる。
  • AI面接B: 応募者がAIと準備→AIの案は「中心になって進めた」→実際は手伝いなので書き直す→控えめな答えになる→面接官には直した後の言葉しか聞こえない→直したのは本人が考えたから。一つの場面を順に追う。
  • AI面接C: AIが整えた答え→応募者が「人に助けてもらった」と一文足す→話の印象が変わる→消すか残すか考えている。一つの場面を順に追うが、何を伝える話かは最後まで言わない。
  • SNS A: 親子で使い始める年齢を決めた→子「今日から使っていいんだよね」→親「いいよ」→親が思い浮かべること/子が思っていること→「いつから」はそろった→「何をしてよいか」は同じか。一つの場面を順に追い、最後の一文が話の要点になる。
  • SNS B: Voiceの高校生の言葉→助けてほしいという願い→「自分で決める」を「一人で何とかする約束」と受け取ったら→食い違って聞こえる→自分で決めたいと言っても助けを断ったことにはならない。結論は明快だが、そこまでの道筋が抽象的。
  • SNS C: 大人「ひとりでできる？」→子「できる」(連絡のやり方のつもり)→大人は「困った時も自分で」と受け取る→後で助けを求めたらどう受け止めるか。一つの場面を順に追う。

理解負荷が高い箇所の原文

  • AI面接A:「その答えを、面接中のAIの案を見て話したらどうか。口にする言葉が同じでも、助けを借りたときは違う。聞こえた言葉だけでは、その違いは分からない。」
  • 姓B:「たとえば、夫婦が選ぶ姓は同じだとする。親に話すのが、姓を決める前の場合と、決めたあとの場合を考えてみる。夫婦には同じ選択でも、親には同じ知らせにならないかもしれない。」
  • SNS B:「もし、自分で決めることを、困ったときも一人で何とかする約束だと受け取ったら。助けてほしいという願いが、食い違って聞こえてくる。」

共通点: いずれも、場面ではなく「二つの場合・二つの概念の違い」を言葉だけで比べさせている。

面白さ・新たな視点

  • SNS A: 「いつから使ってよいか」はそろっても「何をしてよいか」は親子で別のことを考えている、という気づきが、場面だけで自然に伝わる。Voiceに無い視点で、12本中で最も面白い。
  • SNS C: 同じ「できる」を親子が別の意味で受け取る、という着眼。SNS Aと近い。
  • AI面接B: AIの案を本人が控えめに直す、という具体例。AIを使うと話を盛る、という先入観と逆の場面で興味を引く。最後の一文は直前の内容の言い直しに近く、締めとしてはやや弱い。
  • AI面接C: 「人に助けてもらった」と一文足すかどうか、という場面は面白いが、なぜ足したのかが語られず、何の話かをつかみにくい。
  • 姓C: 「どうして？」と聞きたくなるのはどちらか、という問いは面白い。展開の切り替わりが多いのが難点。
  • 姓A: 分かりやすいが、Voice(寂しさを語った母親)の内容に近く、新しい視点は弱い。

ワンパターン化のリスク

  • 冒頭が「たとえば/仮に〜とする」の原稿が12本中7本。AI面接は3案とも「たとえば」で始まる。
  • 末尾の「〜だろう/だろうか」は12本中6本で、A案は4本すべてがこの型で終わる。
  • B案は「AとBは別だ/同じではない/〜だけでは分からない」という区別の型が4本中3本。
  • 「かもしれない」の連続は減ったが、姓Aで2回ずつ残る。
  • 「到達に近い」5本のうち4本が「一つの仮の場面を順に追う」型である。分かりやすさには効いているが、量産すると毎回同じ作りに聞こえるおそれがある。

推奨案とその理由

  • そのまま採用を推奨できる案は無い。3案とも、同じPromptで4記事すべてを分かりやすくすることはできなかった(汎用性が未達)。原文§11に従い、無理に推奨案を選ばない。
  • 相対的にはA案が最も良い(4記事中3記事が到達に近い。SNS Aは12本中で最良)。ただしAI面接Aは12本中で最も理解負荷が高く、A案でも崩れることがある。
  • B案は「伝えたいことを一つ決める」指示が、抽象的な区別を述べる原稿につながった(4記事中3記事)。そのままでは推奨しない。AI面接Bだけは具体的な一場面になり成功している。
  • 分かったこと: 分かりやすかった原稿に共通するのは「一つの具体的な場面を、主語を毎文書いて、順番に語る」こと。分かりにくかった原稿に共通するのは「二つの場合や概念を言葉だけで比べる」こと。Promptの案(A/B/C)の違いよりも、この書き方の違いのほうが結果を分けている。
  • 次に取りうる方向(未実施・ユーザー判断事項): (1)A案を基に、上の共通点をPromptへ反映した改訂版で再Trialする。(2)A案のまま各記事を複数回生成し、揺れの幅(崩れる頻度)を測る。(3)ユーザーが12本を読み、基準に達している原稿・達していない原稿を示す(Fableの見立てとの差を次のPromptへ反映する)。
  • 限界: 原稿ベースの評価であり聴感は未検証。4記事・各1回の生成。冒頭ブロック以外の共通Prompt(事実の扱い・結論を示さない・1段落などの既存条件)は前回と同じで、これらが分かりやすさに与える影響は切り分けていない。
