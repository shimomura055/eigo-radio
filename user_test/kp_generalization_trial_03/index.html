Key Phrase候補の一般化: 本文と意味・用法が違う候補を出さなくなったか(Before/After)

Trial(検証)です。Productionは変更していません。採用はユーザー判断です。 ○=本文と同じ意味・用法の自然な表現としてそのまま選べる / △=意味・用法に疑義(境界)または日本語訳が軽微にずれる / ×=修正が必要、またはそのまま選ぶと誤った英語・意味を覚えるおそれ。「戻し」=一般化すると意味が変わるおそれがあるため、本文の形に戻した候補。「本文中の根拠表現」は記事に出てくる形です(例: hear it out)。評価はAI(Sonnet)が本文と照合して実読したものに、別系列AIの独立評価(ds-v4-pro)を併記しています(別系列AIの指摘は参考情報で、最終ラベルは実読)。
