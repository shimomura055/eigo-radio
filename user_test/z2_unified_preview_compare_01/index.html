Family Z2 統合Preview Trial 新旧比較(2作品×Standard/Advanced=4本)

Trial(試作)の比較です。未採用・Production未配線。A=従来のPreview+Comment 1、B=Comment 1の役割(本文を聞くときの注目点)をPreviewへ吸収した統合Preview。本文・Comment 2・Comment 3は同じものを使い、変更していません。Key Phraseの紹介は追加していません。音声はAもBも同じ声・同じ読み方の指示・同じ速度処理です。
Promptの変更の要旨(4点・旧Zの既存Previewの文面を土台にした差分)
1. Comment 1が担っていた「本文を聞くときの注目点」もPreviewが兼ねる、と明記。注目点は独立した指示文にせず、具体的な人物・状況・出来事の流れに織り込む。
2. あらすじの羅列や、物語についての抽象的な評論・解説にならないよう明記。
3. 「Comment 1・Comment 2と内容が重複しない」という旧指示のうち、Comment 1に関する部分を削除。
4. Comment 2とは「同じ話題に触れてよい。ただし同じ具体的な情報(場面・数字・固有名詞・言い回し)を不必要に繰り返さない」へ変更。
5. (修正1ラウンド・1文のみ追記) 統合Previewの末尾が後に流れるComment 2と同じ問いかけ・締めの言い回しになる例(開いた窓Standardで「どう受け止めるのでしょうか」が重複)があったため、「Comment 2と同じ問いかけや締めの言い回しをPreviewの最後で繰り返さない」を1文だけ追記しました。開いた窓Standardの統合Previewだけ、この修正後Promptで作り直した版です(他の3本は最初のPromptの版)。
長さ・先出し禁止・難易度の指示は旧方式のまま変えていません。Prompt全文の差分は非公開の制作リポジトリに保存しています。
音声の作り方の違い: 新しく作った音声(StandardのA・B、AdvancedのB)はGemini TTSのBATCH実行、再利用したAdvancedのA音声はSTANDARD実行で作られたものです(モデル・声は同じ)。
