ホルムズ海峡の「お会計」が翌日変更。原油市場は安心できず

「通る貨物すべてに20％お願いします」。そんな“海峡のお会計”が、翌日には「湾岸諸国の対米貿易・投資案件で」に早変わり。ホルムズ海峡の安全確保をめぐる負担の話は、料金所の窓口から商談テーブルへ。看板の掛け替えは素早かったが、原油市場まで「はい、安心」とはいかなかった。

発端はトランプ大統領の投稿だ。米国が海峡の安全と警備を提供する費用として、通過するすべての貨物に20％の償還を求め、手続きと体制づくりを始めると表明。ところが翌日、その償還料を湾岸諸国による対米貿易・投資案件に置き換えると投稿した。中東指導者との「非常に生産的な協議」に基づく決定だという。請求書を書き始めたと思ったら、もう商談の出番である。

では、「結局、同じ金額を別の財布から出すだけ」なのか。そこは電卓を出す前に待った。記事には投資案件の金額も条件も示されていない。「置き換え」と「同額」は別物だ。誰に、どんな形で負担を求めるかは動いたが、総額の答え合わせはまだできない。

その間、原油相場は派手に動いていた。提案当日、Brent原油先物は7.29ドル、9.59％上昇し、83.30ドルで清算された。ただし、ここで「犯人は20％案！」と決めつけるのは早い。この上昇は、翌日に始まる予定の米国による対イラン海上封鎖や、海峡を通るエネルギー輸送への懸念と結びつけて報じられた。相場の現場は、単純な一話完結ミステリーではない。

ならば、置き換え発表は市場への安心材料になったのか。Brentは一時、上げ幅を縮めた。ところが、そのまま落ち着く展開にはならず、ほどなく発表前に近い高い水準へ。記事掲載時点では約2.6％高で、85ドルを上回っていた。

記事が挙げたのは、攻撃や海上封鎖、タンカーの安全への懸念が続いていたことだ。お会計の相談が進んでも、タンカーの航路に「安全確認済み」の札が出たわけではない。

今回の肝はここにある。「誰が払うか」と「原油が無事に届くか」は別の問題。負担の求め方が変わっても、供給への不安は残る。今回の値動きは、その違いを映したように見える。請求書は一晩で書き換えられても、海の不安まで翌日配送で解消、とはいかない。

通行料案は一晩で投資話に衣替え。それでも原油相場は「安心」とはいかなかった

ホルムズ海峡をめぐる話が、わずか一晩で「通行料」から「投資商談」へ。政策案は早変わりしたが、原油相場は拍手喝采で幕を下ろしたわけではなかった。

トランプ大統領がまず打ち出したのは、ホルムズ海峡を通るすべての貨物に、米国が安全確保や警備にかける費用として20％の償還を求める案だ。手続きや体制づくりにも、すぐ着手すると投稿した。海峡を通る貨物に、安全確保の費用を結び付ける構想である。

ところが翌日、舞台の筋書きが変わる。トランプ氏は償還料案を、湾岸諸国による対米貿易・投資案件に置き換えると投稿。その理由には、中東指導者との「非常に生産的な協議」を挙げた。

通行料の話が、翌日には商談へ。料金表が投資提案書に差し替わったような展開だ。ただし、ここで確認できるのは、トランプ氏が「置き換える」と投稿したことまで。投資案件が実際に成立したかどうかは、このニュースからは分からない。案の衣替えと契約成立は、別の話として見ておきたい。

では、原油市場は「通行料案が消えたなら安心」と受け止めたのか。そう単純ではなかった。発表後、Brent先物は上げ幅を一時縮めたものの、ほどなく発表前に近い高い水準へ戻った。記事掲載時点では約2.6％高、1バレル85ドル超だった。

背景には、米国とイランの攻撃や海上封鎖、タンカーの安全をめぐる懸念が続いていた。政策案の看板が掛け替わっても、供給への心配まで一緒に消えたわけではない。相場の動きも、「案が変わったから一件落着」とは言い切れない様子を映している。

遠い海峡のニュースも、エネルギー価格を気にする暮らしと無縁とは限らない。見出しの変化と、供給不安の変化は同じではない。その二つを分けて読むのが、今回のポイントだ。

20％案は翌日撤回！でも原油は「安心モード」に入らなかった

追加料金はなくなりました！、それなら原油も値下がりして、一件落着。そう思った人には、相場から「ちょっと待った」がかかった。消えたのは20％の支払い案。心配まで、まとめてキャンセルされたわけではない。

発端は、トランプ米大統領の投稿だった。ホルムズ海峡を通るすべての貨物に、20％の支払いを求めるという案だ。米国が海峡の安全を守るために使う費用を返してもらう、という説明。海の重要ルートに、突然レジが出現したような話である。

ところが翌日、そのレジは早くも撤去へ。トランプ氏は案を撤回し、湾岸諸国による米国との貿易や、米国への投資の案件に置き換えると投稿した。理由に挙げたのは、中東の指導者たちとの「非常に生産的な協議」だった。

昨日は20％、今日は撤回。展開が速すぎて、ニュースを追う側も息をつく暇がない。だが、本当の見どころは、このあと。原油相場は、すんなり「安心しました」とはならなかった。

ヤフー・ファイナンスによると、国際的な原油価格の目安となるブレント原油の先物は、撤回発表後、いったん上げ幅を縮めた。ところが、ほどなく発表前に近い高い水準へ戻った。記事が出た時点では約2.6％高で、85ドルを上回っていた。

一度は上昇の勢いが弱まった。でも、そのまま落ち着いたわけではない。ハッピーエンドの音楽を流しかけたら、まだ次の場面が残っていた、という展開だ。

ここで分けたいのが、「いくら払うか」と「無事に運べるか」。どちらも原油をめぐる不安だが、中身は別物。追加の支払い案がなくなっても、輸送の安全まで自動的に保証されるわけではない。

実際、米国とイランの間の攻撃、海上封鎖、タンカーの安全への心配は続いていた。20％という目立つ数字が退場しても、原油の供給をめぐる不安は、舞台に残ったままだった。

買い物なら、こういうことだ。「追加料金は取りません」と言われれば、財布はほっとする。けれど続けて、「ただし、商品が無事に届くかは、まだ心配です」と言われたら？　喜びかけた手は止まり、配送状況を何度も確認したくなる。

今回の相場を見る鍵も、料金表だけでなく、荷物が通る道にあった。「20％案の撤回」は大きなニュース。しかし「安全に運べるのか」という問いには、それだけで答えが出たわけではない。

案の撤回と、安心の回復はセットとは限らない。派手な数字が消えたあと、原油がどこへ戻ったか。ニュースの続編は、発表文の外側で動いていた。

20％の通行料は消えた。では、海の不安も？

「ホルムズ海峡を通る貨物に20％の料金を」。そんな案が飛び出した翌日、トランプ米大統領は、料金の代わりに湾岸諸国が米国と貿易をしたり、米国に投資したりする形にすると発表した。

料金表は書き換わった。けれど、海峡を通る船にとって、いちばん気になるのは「いくら払うか」だけだろうか。船が安全に通れるか。荷物を積んだタンカーが、無事に目的地へ向かえるか。そちらの心配は、まだ残っている。

原油価格の国際的な目安となるブレント先物は、発表後、いったん上げ幅を縮めた。ところが、その後は発表前に近い高い水準へ戻った。値上がりが一服する場面はあったものの、価格がすーっと下がり続けたわけではない。20％の案が消えたからといって、原油安の合図が鳴ったわけではなさそうだ。

もちろん、短い時間の値動きだけで、市場の人たちの考えを言い切ることはできない。それでも、料金の話を取り下げるだけでは解けない心配があった、と見ることはできる。

発表後も、米国とイランの間では攻撃が続いていた。海上では船の行き来を止める封鎖があり、石油を運ぶタンカーの安全も懸念されていた。支払いの形が変わっても、船が安心して進めるかどうかは別問題。通行料の話が幕を引いても、海の通行まで「はい、解決」とはいかなかった。

買い物にたとえるなら、送料が変わることと、注文した品が無事に届くことは別々の心配だ。送料が安くなったからといって、荷物の到着まで保証された気分にはならない。海峡も同じ。料金の仕組みが変わっても、船の安全が自動でついてくるわけではない。

今回変わったのは、お金をどう受け取るかという話。残ったのは、攻撃や封鎖、タンカーの安全をめぐる不安だ。原油価格が高い水準へ戻ったことも、そこに目を向けるきっかけになる。20％の案は消えた。けれど、海までひと安心、とは、まだ言えなさそうだ。
