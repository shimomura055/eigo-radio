状態: Trial（Production採用ではありません）。前回『賢者の贈り物』の試聴で差が分かりづらかったため、追加の2作品で同じ比較をしています。同じ英文・同じ声・同じAIモデル・同じ生成設定で、A=現行方式、B=改善方式（Style［話し方の指示］に「話者の気持ち／場面／前後の会話／地の文の演出」を足した方式）を聞き比べます。生成のたびに声は少し変わるため、同じ方式をもう一度生成した A'・B' も添えています（A と A' の違いが『偶然のゆれ』の目安です）。
聴いていただきたい観点: 感情が伝わるか / 抑揚の自然さ / 会話としての自然さ / 場面に合った演出 / 聞き取りやすさ / 大げさすぎないか。
機械の指標だけでは最終判断せず、ここでの試聴による比較判断を残します。
本番でも各セリフの音量は揃えられるため、音量の大小ではなく、声の柔らかさ・息づかい・速さ・抑揚で比べてください。（音声は本番と同じ約6%の速度加工と音量調整をした形です。）
